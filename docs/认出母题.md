# 认出这是哪道母题

孩子卡住，常常不是算错，是**认错题**。把和倍当成和差，把鸡兔同笼当成平均分，后面每一步都在给错的骨头套衣服。

这一页只做一件事：看着题目给了什么，对上那根骨头。

## 题目给了什么

| 同时看见这些 | 就是这道母题 | 口诀 | 先做哪道例题 |
| --- | --- | --- | --- |
| 「一共」「共」+「多」「少」「相差」 | [和差](知识点/和差问题.md) | （和 ± 差）÷ 2 | [兄弟分糖](题目/兄弟分糖.md) |
| 「一共」「共」+「是几倍」 | [和倍](知识点/和倍问题.md) | 和 ÷（倍数 + 1）= 1 份 | [甲乙两堆书](题目/甲乙两堆书.md) |
| 「多」「少」「相差」+「是几倍」 | [差倍](知识点/差倍问题.md) | 差 ÷（倍数 − 1）= 1 份 | [倒油问题](题目/倒油问题.md) |
| 「从甲拿出给乙」「倒过去就相等」 | [移多补少](知识点/移多补少.md) | 倒过去 1 份，差距缩小 2 份 | [倒油问题](题目/倒油问题.md) |
| 两种东西混在一起，只给**总个数**和**另一个总数** | [鸡兔同笼](知识点/假设法.md) | 先当全是鸡，少的脚两只两只添 | [鸡兔同笼](题目/鸡兔同笼.md) |
| △ ○ □ 代表数，几个算式求每个是几 | [图形推理](知识点/简单推理.md) | 两个算式摆一起，划掉一样多的 | [图形算式](题目/图形算式.md) · [三种图形](题目/三种图形.md) |
| 同一份东西**分两次**，一次**多**、一次**少** | [盈亏](知识点/盈亏问题.md) | 多了加少了，除以两次分的差 | [分苹果](题目/分苹果.md) |

| 「过桥」「过隧道」「车头进、车尾出」 | [过火车](知识点/过火车问题.md) | 车头进、车尾出，两段路加在一起 | [过桥](题目/过桥.md) |
| 「买几送几」「每人一瓶，最少买多少」 | [买赠](知识点/买赠问题.md) | 送的那瓶也要喝，5 加 1 才是一组 | [买五送一](题目/买五送一.md) |

{% hint style="warning" %}
「甲比乙多 2 倍」不是差，是倍。多 2 倍 = 是 3 倍。看见「倍」就先别往和差上靠。
{% endhint %}

## 三道最容易认错的

{% tabs %}
{% tab title="和差 还是 和倍" %}
两道题都有「一共」。分开它们的是第二个条件：

{% columns %}
{% column %}
**和差**

一共 60，哥哥比弟弟**多 12**。

第二个条件是一段**差**。
{% endcolumn %}

{% column %}
**和倍**

一共 48，甲是乙的 **3 倍**。

第二个条件是一个**倍数**。
{% endcolumn %}
{% endcolumns %}

记法：有「差」就减了再分；有「倍」就数份再分。
{% endtab %}

{% tab title="和倍 还是 差倍" %}
两道题都有「是几倍」。分开它们的是另一个数：

{% columns %}
{% column %}
**和倍**

两数**相加** 48，大的是小的 3 倍。

`48 ÷ (3 + 1)`
{% endcolumn %}

{% column %}
**差倍**

两数**相差** 24，大的是小的 3 倍。

`24 ÷ (3 − 1)`
{% endcolumn %}
{% endcolumns %}

记法：求和就加，求差就减。
{% endtab %}

{% tab title="平均分 还是 鸡兔同笼" %}
{% columns %}
{% column %}
**不是鸡兔同笼**

8 只动物，一共 16 只脚。

脚数刚好是头数的 2 倍，全是鸡。不用假设。
{% endcolumn %}

{% column %}
**是鸡兔同笼**

8 个头，**26** 只脚。

脚数对不上「全是鸡」也对不上「全是兔」，两种混在一起。
{% endcolumn %}
{% endcolumns %}

看见两种东西、两个总数，先假设全是少的那种，再看差多少。
{% endtab %}
{% endtabs %}

## 衣服换了，骨头还在

同一道母题，出题人会换成糖、油、车、硬币、绳子。认题只看条件，不看故事。

| 故事里写的 | 骨头其实是 |
| --- | --- |
| 哥哥弟弟分糖、两班人数、绳子剪两段 | 和差 |
| 两堆书、大小绳子、两个人的年龄 | 和倍 |
| 两桶油、大小绳子「长多少」 | 差倍 |
| 倒油、两堆糖互相拿 | 移多补少 |
| 鸡和兔、龟和鹤、自行车和三轮车、2 分和 5 分 | 鸡兔同笼 |
| △ + ○ = 9，一串图形算式 | 图形推理 |
| 三种记号、几串一样长 | 图形推理 |
| 路边种树、报数、握手、锯木头 | 植树 |
| 卖桃子、剪布、给糖，求原来有多少 | 还原 |
| 火车过桥、过隧道、队伍过门洞 | 过火车 |
| 买五送一、买三送一、满几送一 | 买赠 |

{% hint style="success" %}
合上这一页，随便拿一道作业题，先不计算，只说「这是哪道母题」。说对了，再翻开对应的母题页对口诀。
{% endhint %}
