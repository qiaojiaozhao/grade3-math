# 竖式填空

## 题目

> 下面的加法竖式里，两个 □ 各是几？
>
> ```
>     □ 6
>   + 2 □
>   ------
>     5 3
> ```

{% hint style="info" %}
母题是 [数字谜](../知识点/数字谜.md)。从个位看起。个位对不上，就是进了 1。
{% endhint %}

点「自动播放整段动画」，个位会先亮。要让孩子看见的是这两件事：

- 6 加一个一位数，要在个位留下 3，只能是 13；
- 进上去的 1 加进十位，十位的 □ 才是 2。

## 一步步想

{% stepper %}
{% step %}
## 先看个位

6 加 □，个位是 3。6 本身比 3 大，所以一定进位：6 + 7 = 13。个位的 □ 是 **7**，向十位进 1。
{% endstep %}

{% step %}
## 再看十位

十位是 □ + 2，还要加上进位的 1，得 5。

    □ + 2 + 1 = 5
    □ = 2
{% endstep %}
{% endstepper %}

## 答案

**26 + 27 = 53。** 十位的 □ 是 2，个位的 □ 是 7。

## 验算

26 + 27 = 53。个位 6 + 7 = 13，写 3 进 1。十位 2 + 2 + 1 = 5。✓

## 孩子容易错在哪

- **先猜十位。** 十位有进位，个位没确定时，十位算不准。
- **6 加 3 写成个位 3。** 6 + 3 = 9，个位是 9，不是 3。要对上 3，得是 13。
- **进了 1 却不加到十位。** 十位就会算成 2 + 3 = 5，把上面的 □ 填成 3，竖式变成 36 + 27 = 63，不是 53。
