# 五个点

## 题目

> 一条直线上有 **5** 个点，这些点一共可以连成多少条线段？

{% hint style="info" %}
母题是 [数线段、数角](../知识点/数线段数角.md)。从左边第一个点出发，能连到的都数上；数完换下一个，数过的不再数。
{% endhint %}

点「自动播放整段动画」，弧线从左边第一个点一条条长出来。要让孩子看见的是这两件事：

- 只数挨着的，只有 4 条，隔着点的长线段被漏掉了；
- 每个点只往右连，4 + 3 + 2 + 1 = 10，同一条不会数两次。

## 一步步想

{% stepper %}
{% step %}
## 从第 1 个点往右

右边还有 4 个点，连出 4 条。
{% endstep %}

{% step %}
## 换点，只往右

第 2 个点 3 条，第 3 个点 2 条，第 4 个点 1 条。往左的已经数过。
{% endstep %}

{% step %}
## 加起来

    4 + 3 + 2 + 1 = 10（条）
{% endstep %}
{% endstepper %}

## 答案

**一共 10 条线段。**

## 验算

挨着的 4 条，隔一个点的 3 条，隔两个点的 2 条，从头到尾 1 条。4 + 3 + 2 + 1 = 10。✓

## 孩子容易错在哪

- **只数挨着的 4 条。** 隔着点的也是一条线段。第 1 个点到第 5 个点，是最长的那一条，最容易漏。
- **每个点都往两边数，数成 20 条。** 同一条被两头各数了一次。规定只往右数，就不会重。
- **5 个点就写 5 条。** 线段是两个点连出来的，不是点的个数。
