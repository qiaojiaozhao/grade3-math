# 甲乙两堆书

## 题目

> 甲、乙两堆书一共有 **48** 本，甲堆是乙堆的 **3** 倍。甲、乙两堆各有多少本？

{% hint style="info" %}
母题是 [和倍](../知识点/和倍问题.md)。给了「一共」和「是几倍」，和 ÷（倍数 + 1）= 1 份。
{% endhint %}

## 一步步想

{% stepper %}
{% step %}
## 数出一共几份

乙是 1 份，甲是 3 份，一共 4 份：

    3 + 1 = 4（份）
{% endstep %}

{% step %}
## 求 1 份

    48 ÷ 4 = 12（本）
{% endstep %}

{% step %}
## 还原两堆

    乙 = 12（本）
    甲 = 12 × 3 = 36（本）
{% endstep %}
{% endstepper %}

## 答案

**甲堆 36 本，乙堆 12 本。**

## 验算

1. 一共：`36 + 12 = 48` ✓
2. 倍数：`36 ÷ 12 = 3` ✓

## 孩子容易错在哪

- **48 ÷ 3 = 16。** 和要除以「倍数 + 1」，不是只除以倍数。
- **和倍、差倍混用。** 这题给的是「共 48」，用加；若给「相差 24」才用减。
- **「多 2 倍」当成 2 倍。** 甲比乙多 2 倍，意思是甲是乙的 3 倍。
