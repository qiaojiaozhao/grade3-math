# 凑整

## 题目

> 计算：**347 + 158 + 253**

{% hint style="info" %}
母题是 [巧算](../知识点/巧算问题.md)。先把凑成整百的两个圈在一起，再算剩下的。
{% endhint %}

<a class="button primary" href="https://qiaojiaozhao.github.io/grade3-math/demos/%E5%87%91%E6%95%B4-%E5%B7%A7%E7%AE%97%E9%97%AE%E9%A2%98.html">打开互动动画：先圈好朋友</a>

点「自动播放整段动画」，会看到 347 和 253 的个位先亮起来。要让孩子看见的是这两件事：

- 7 和 3 凑成 10，末两位 47 + 53 = 100，这两个先加，是 600；
- 从左边先加 347 + 158，好朋友被拆开，进位又多又容易错。

## 一步步想

{% stepper %}
{% step %}
## 看个位

7 和 3 凑成 10。中间的 8 和谁都凑不成 10。347 和 253 是好朋友。
{% endstep %}

{% step %}
## 先加这一对

末两位 47 + 53 = 100，整百是 300 + 200。

    347 + 253 = 600
{% endstep %}

{% step %}
## 再加剩下的

    600 + 158 = 758
{% endstep %}
{% endstepper %}

## 答案

**758**

## 验算

从左边加：347 + 158 = 505，505 + 253 = 758。✓

## 孩子容易错在哪

- **从左边加，347 + 158 先算。** 答案能算对，可是 158 把好朋友隔开了，进位多，数字一大就错。先看个位再决定先加谁。
- **只看见 7 + 3 = 10，就把 347 + 253 当成 10。** 凑成 10 的是个位。还要看十位：4 + 5 再加进位 1，末两位才是 100，整百另外加。
- **158 的 8 也想找朋友，找不着就乱凑。** 三个数里只有一对。凑不上的那个最后再加。
