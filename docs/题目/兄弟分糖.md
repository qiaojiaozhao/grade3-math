# 兄弟分糖

## 题目

> 哥哥和弟弟一共有 **60** 颗糖，哥哥比弟弟多 **12** 颗。哥哥、弟弟各有多少颗糖？

{% hint style="info" %}
母题是 [和差](../知识点/和差问题.md)。给了「一共」和「多多少」，先去掉差再平分。
{% endhint %}

## 一步步想

{% stepper %}
{% step %}
## 去掉差，看剩下多少

哥哥比弟弟多 12，先把这 12 颗从「一共 60」里拿掉，剩下两份一样多：

    60 − 12 = 48
{% endstep %}

{% step %}
## 求弟弟（小数）

    48 ÷ 2 = 24（颗）
{% endstep %}

{% step %}
## 求哥哥（大数）

    24 + 12 = 36（颗）
{% endstep %}
{% endstepper %}

## 答案

**哥哥 36 颗，弟弟 24 颗。**

## 验算

1. 一共：`36 + 24 = 60` ✓
2. 相差：`36 − 24 = 12` ✓

## 孩子容易错在哪

- **直接 60 ÷ 2 = 30。** 忘了两人不相等，必须先去掉「差」再平分。
- **大数用（和 + 差）÷ 2 算反了。** 差是给大数多加的那截，大数 =（和 + 差）÷ 2，小数 =（和 − 差）÷ 2。
- **只算出一个就停。** 题目问「各有多少」，两个都要写。
