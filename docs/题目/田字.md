# 田字

## 题目

> 「田」字由横线和竖线搭成。笔不离纸、每条线只画一次，能不能一笔画成？

{% hint style="info" %}
母题是 [一笔画](../知识点/一笔画.md)。数单数条线的点。0 个或 2 个，才能一笔画。
{% endhint %}

## 先看动画

{% embed url="https://qiaojiaozhao.github.io/grade3-math/demos/%E7%94%B0%E5%AD%97-%E4%B8%80%E7%AC%94%E7%94%BB.mp4" %}

<a class="button primary" href="https://qiaojiaozhao.github.io/grade3-math/demos/%E7%94%B0%E5%AD%97-%E4%B8%80%E7%AC%94%E7%94%BB.html">打开互动动画：先数单数点</a>

点「自动播放整段动画」，每个点上的线会被数出来。要让孩子看见的是这两件事：

- 从角上试画，走到一半卡住，换个角还是卡住；
- 四条边的中点各有 3 条线，单数点有 4 个，不能一笔。

## 一步步想

{% stepper %}
{% step %}
## 每个点数一数

四个角：各 2 条。四条边的中点：各 3 条。正中间：4 条。
{% endstep %}

{% step %}
## 只留下单数

3 是单数，这样的点有 4 个。
{% endstep %}

{% step %}
## 对照口诀

0 个或 2 个才能一笔画。4 个，不能。
{% endstep %}
{% endstepper %}

## 答案

**不能一笔画成。**

## 验算

「日」字只有 2 个单数点，可以画。「田」比「日」多了一条竖线，边上的单数点从 2 个变成 4 个。✓

## 孩子容易错在哪

- **从不同的角反复试。** 试错只说明这条路不通，不能说明别的路也不通。先数点。
- **把四个角也当成单数点。** 角上只有 2 条线，是双数，笔进得去出得来。
- **看见线很多就说不能。** 线多不要紧，单数点是 0 个或 2 个就可以。口字线少，日字也能画。
