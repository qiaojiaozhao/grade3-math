# 妈妈和小明

## 题目

> 妈妈今年 **36** 岁，小明今年 **8** 岁。几年后，妈妈的年龄是小明的 **3** 倍？

{% hint style="info" %}
母题是 [年龄问题](../知识点/年龄问题.md)。两个人一起长，差不变；「3 倍」说的是将来那一年，要先用差把那一年找出来。
{% endhint %}

点「自动播放整段动画」，两根年龄条会一起长高。要让孩子看见的是这三件事：

- 妈妈高出小明的那一截涂成**橙色**，时间怎么走，这一截都不变；
- 只让小明长到 12 岁是错的——这 4 年妈妈**也在长**，变成 40 岁；
- 到了 3 倍的那一年，妈妈是 3 份、小明是 1 份，橙色那截正好是 **2 份**。

## 一步步想

{% stepper %}
{% step %}
## 找出不会变的差

两个人每年各长 1 岁，差永远一样：

    36 − 8 = 28（岁）

今年差 28，6 年后差 28，20 年后还是 28。
{% endstep %}

{% step %}
## 到了「那一年」，差是几份

那一年小明是 1 份，妈妈是 3 份。妈妈比小明多出 `3 − 1 = 2` 份，这 2 份就是那不变的 28 岁：

    1 份 = 28 ÷ (3 − 1) = 14（岁）

所以那一年小明 14 岁，妈妈 `14 × 3 = 42` 岁。
{% endstep %}

{% step %}
## 倒回今年，数一数过了几年

小明从 8 岁长到 14 岁：

    14 − 8 = 6（年）
{% endstep %}
{% endstepper %}

## 答案

**6 年后，妈妈的年龄是小明的 3 倍。**

## 验算

1. 6 年后妈妈：`36 + 6 = 42`，小明：`8 + 6 = 14` ✓
2. 是 3 倍：`14 × 3 = 42` ✓
3. 差还是 28：`42 − 14 = 28` ✓

## 孩子容易错在哪

- **只让小明长：36 ÷ 3 = 12，12 − 8 = 4 年。** 这是最常见的错。他把妈妈钉在 36 岁不动了。4 年后妈妈是 40 岁，40 不是 12 的 3 倍。
- **差当成 3 份：28 ÷ 3。** 除不尽就慌了。妈妈 3 份、小明 1 份，多出来的只有 2 份，要减掉和小明对齐的那 1 份。
- **答成 14。** 14 是那一年小明几岁。题目问的是「几年后」，还要 `14 − 8`。
- **用今年的倍数去凑。** 今年 `36 ÷ 8` 是 4 倍多，不整。倍数每年都在变，只有差不变，别拿倍数当抓手。
