# 三种图形

## 题目

> 下面算式中，△、○ 和 □ 各代表多少？
>
> ```
> ① ○ + ○ = □ + □ + □
> ② □ + □ + □ = △ + △ + △ + △
> ③ ○ + □ + △ + △ = 80
> ```

{% hint style="info" %}
母题是 [图形推理](../知识点/简单推理.md)。先看出三串一样长，再换成同一种图形代进去。
{% endhint %}

点「自动播放整段动画」，会看到三串图形被圈成一样长。要让孩子看见的是这两件事：

- **两圆 = 三方 = 四三角**，是同一捆；
- 把 ③ 里的圆和三角都换成方块，才能算出这一捆是多少。

## 一步步想

{% stepper %}
{% step %}
## 先看出三串一样长

① 说两圆等于三方。② 说三方等于四三角。所以：

```
○ + ○  =  □ + □ + □  =  △ + △ + △ + △
```

三串一样长。先别急着猜每个是几。
{% endstep %}

{% step %}
## 一圆等于两三角

两圆 = 四三角，两边都除以 2：

    ○ = △ + △
{% endstep %}

{% step %}
## 把③里的圆换成三角

③ 是 `○ + □ + △ + △`。把 ○ 换成两个三角：

```
(△ + △) + □ + △ + △
= □ + △ + △ + △ + △
```

    □ + 4 × △ = 80
{% endstep %}

{% step %}
## 四三角再换成三方块

② 说四三角 = 三方块，再换一次：

```
□ + □ + □ + □ = 80
```

    4 × □ = 80
    □ = 20
{% endstep %}

{% step %}
## 求出另外两个

三方块是一捆：`3 × 20 = 60`。

```
4 × △ = 60  →  △ = 15
○ = 15 + 15 = 30
```
{% endstep %}
{% endstepper %}

## 答案

**△ = 15，□ = 20，○ = 30。**

## 验算

1. ①：`30 + 30 = 20 + 20 + 20` → `60 = 60` ✓
2. ②：`20 + 20 + 20 = 15 + 15 + 15 + 15` → `60 = 60` ✓
3. ③：`30 + 20 + 15 + 15 = 80` ✓

## 孩子容易错在哪

- **三种图形一起猜。** 不知道从哪下手。先圈出「一样长的三串」，再换成同一种。
- **只看见①②，忘了用③。** ①②只告诉你谁和谁一样长，真正的数要从 ③ 里求。
- **换的时候漏个数。** 一圆换两三角，③ 里原来已有两三角，换完一共四三角。
- **求出 □ 就收手。** 题要三个都求出来。
