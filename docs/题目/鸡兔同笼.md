# 鸡兔同笼

## 题目

> 笼子里关着鸡和兔。数一数，一共有 **8 个头**，**26 只脚**。鸡和兔各有几只？

{% hint style="info" %}
母题是 [鸡兔同笼 / 假设法](../知识点/假设法.md)。先当全是鸡，少的脚两只两只添。
{% endhint %}

## 先看动画

<a class="button primary" href="https://qiaojiaozhao.github.io/grade3-math/demos/%E9%B8%A1%E5%85%94%E5%90%8C%E7%AC%BC-%E5%81%87%E8%AE%BE%E6%B3%95.html">打开互动动画：把鸡一只只换成兔</a>

点「自动播放整段动画」，会看到 8 只鸡站成一排，然后一只一只被添上脚变成兔。要让孩子看见的是这两件事：

- 每添一次，脚数计数器只**跳 2**，不是跳 4；
- 添到第 5 次脚数正好是 26，**添了几次就是几只兔**。

## 一步步想

{% stepper %}
{% step %}
## 假设全是鸡，一共有多少只脚

先别管到底有几只兔，**假装 8 只全是鸡**。鸡有 2 只脚：

    2 × 8 = 16（只脚）
{% endstep %}

{% step %}
## 少了多少只脚

题目说真的有 26 只脚，可我们只数出 16 只：

    26 − 16 = 10（只脚）
{% endstep %}

{% step %}
## 一只兔能补几只脚

把一只鸡换成兔，**不是重新长 4 只脚**，而是在原有的 2 只上再添 2 只。所以每换一只，总脚数只多 2：

    10 ÷ 2 = 5（只兔）
{% endstep %}

{% step %}
## 鸡有几只

一共 8 个头，兔占了 5 个：

    8 − 5 = 3（只鸡）
{% endstep %}
{% endstepper %}

## 答案

**兔有 5 只，鸡有 3 只。**

## 验算

1. 头的数量：`3 + 5 = 8` ✓
2. 脚的数量：`3 × 2 + 5 × 4 = 6 + 20 = 26` ✓

## 孩子容易错在哪

- **拿少的脚去除以 4。** 忘了那只鸡本来就有 2 只脚，变兔子只是再添 2 只。动画里脚数尺每次只跳 2，就是对付这一条的。
- **把算出来的数安错动物。** `10 ÷ 2 = 5` 求出的是兔。假设全是谁，算出来的就是另一个。
- **算完兔就交卷。** 题目问「各有几只」，还得用 `8 − 5` 求鸡。
- **验算只对一个条件。** 头和脚都要对上。

## 换一身衣服

头可以换成「一共几辆」「一共几枚」，脚可以换成轮子、分。差几只，就几只几只添。
