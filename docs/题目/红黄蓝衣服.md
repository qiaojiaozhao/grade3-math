# 红黄蓝衣服

## 题目

> 小红、小兰、小芳分别穿**红、黄、蓝**三种颜色的衣服，每人一种，没有重复。小红**不穿红的，也不穿黄的**，小兰**不穿红的**。三人各穿什么颜色？

{% hint style="info" %}
母题是 [逻辑推理](../知识点/逻辑推理.md)。确定的打勾，不可能的打叉；打了勾，这一行这一列都叉掉。
{% endhint %}

点「自动播放整段动画」，表上一格一格出现叉和勾。要让孩子看见的是这两件事：

- 小红不穿红、不穿黄，只剩蓝，先打勾；
- 蓝打了勾，小兰和小芳的蓝都要叉掉。忘了这一步，就会把蓝又分给小兰。

## 一步步想

{% stepper %}
{% step %}
## 小红这一行

不穿红，不穿黄，两格打叉。只剩蓝，打勾。
{% endstep %}

{% step %}
## 蓝这一列叉掉

小兰、小芳都不能穿蓝。小兰又不穿红，红也打叉。只剩黄，打勾。
{% endstep %}

{% step %}
## 小芳是剩下来的

黄是小兰的，小芳的黄打叉。她的蓝早就叉了，只剩红，打勾。
{% endstep %}
{% endstepper %}

## 答案

**小红穿蓝，小兰穿黄，小芳穿红。**

## 验算

三种颜色各有一个人。小红不是红、不是黄。小兰不是红。✓

## 孩子容易错在哪

- **小红穿了蓝，小兰还能穿蓝。** 他只记了「小红穿蓝」，忘了把蓝这一列叉掉。一种颜色只有一个人。
- **看见「小红」就让她穿红。** 题目写的是不穿红。名字和颜色没有关系，以表上的叉为准。
- **小芳谁都没提到，就随便猜。** 红、黄、蓝里，黄和蓝都有人了，小芳只能是红，不用另给条件。
