# 图形算式

## 题目

> 下面算式中，△ 和 ○ 各代表多少？
>
> ```
> ① ○ + ○ + ○ + △ + △ = 54
> ② △ + △ + △ + ○ + ○ + ○ + ○ = 76
> ```

{% hint style="info" %}
母题是 [图形推理](../知识点/简单推理.md)。先消去得到一个短关系，再整包代换。
{% endhint %}

减完两种图形都还剩一个，不是白减。画面里会把「○ + △ = 22」剩出来给你看。

## 先数一数

动笔之前先把个数列清楚。这一步做扎实，后面就不会乱：

| | ○ 的个数 | △ 的个数 | 等于 |
| --- | --- | --- | --- |
| ① | 3 | 2 | 54 |
| ② | 4 | 3 | 76 |

## 一步步想

{% stepper %}
{% step %}
## 两式相减，看剩下什么

② 比 ① 大，用 ② 减 ①：

```
○ ：4 − 3 = 1 个
△ ：3 − 2 = 1 个
右边：76 − 54 = 22
```

    ○ + △ = 22

这次相减没有把哪个图形消光，两种图形都还剩一个。**这不是失败。** 原来要对付两个又长又乱的算式，现在变成一个特别短的关系，这就是最大的进展。
{% endstep %}

{% step %}
## 把「○ + △」整包换掉

回到 ①，重新分组，凑出整包的「○ + △」：

```
○ + ○ + ○ + △ + △
= (○ + △) + (○ + △) + ○
=    22   +    22   + ○
```

    44 + ○ = 54
{% endstep %}

{% step %}
## 两个都求出来

    ○ = 54 − 44 = 10
    △ = 22 − 10 = 12
{% endstep %}
{% endstepper %}

## 答案

**△ = 12，○ = 10。**

## 验算

两个算式都要代回去对一遍，缺一个都不算验过：

1. ①：`10 × 3 + 12 × 2 = 30 + 24 = 54` ✓
2. ②：`12 × 3 + 10 × 4 = 36 + 40 = 76` ✓

## 孩子容易错在哪

- **以为相减必须把某个图形消光。** 减完两种都还剩一个，孩子容易觉得「白减了」。其实 `○ + △ = 22` 已经是钥匙。
- **分组时凑不出整包。** 一个 ○ 配一个 △，配出两对，多出一个 ○。
- **减的时候右边忘了减。**
- **只算出 ○ 就交卷。**

## 换一身衣服

{% tab title="对称相加" %}
△ 和 □ 各代表多少？

```
□ + □ + △ = 16
□ + △ + △ = 14
```

<details>
<summary>点开看答案</summary>

两式相减得 `□ − △ = 2`；两式相加得 `□ + △ = 10`。于是 □ = 6，△ = 4。

相加也是一招。看到个数正好对称，就试试把它们加起来。

</details>
