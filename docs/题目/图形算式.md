# 图形算式

## 题目

> 下面算式中，△ 和 ○ 各代表多少？
>
> ```
> ① ○ + ○ + ○ + △ + △ = 54
> ② △ + △ + △ + ○ + ○ + ○ + ○ = 76
> ```

## 用到的知识点

- [简单推理](../知识点/简单推理.md)：消去法求出一个简单关系，再用等量代换算出答案

## 先数一数

动笔之前先把个数列清楚。这一步做扎实，后面就不会乱：

| | ○ 的个数 | △ 的个数 | 等于 |
| --- | --- | --- | --- |
| ① | 3 | 2 | 54 |
| ② | 4 | 3 | 76 |

## 一步步想

### 第一步：两式相减，看剩下什么

② 比 ① 大，用 ② 减 ①：

```
○ ：4 − 3 = 1 个
△ ：3 − 2 = 1 个
右边：76 − 54 = 22
```

    ○ + △ = 22

这次相减没有把哪个图形消光，两种图形都还剩一个。**这不是失败。** 原来要对付两个又长又乱的算式，现在变成一个特别短的关系，这就是最大的进展。

### 第二步：把「○ + △」整包换掉

回到 ①，重新分组，凑出整包的「○ + △」：

```
○ + ○ + ○ + △ + △
= (○ + △) + (○ + △) + ○
=    22   +    22   + ○
```

    44 + ○ = 54

### 第三步：两个都求出来

    ○ = 54 − 44 = 10

再用第一步那个关系：

    △ = 22 − 10 = 12

## 答案

**△ = 12，○ = 10。**

## 验算

两个算式都要代回去对一遍，缺一个都不算验过：

1. ①：`10 × 3 + 12 × 2 = 30 + 24 = 54` ✓
2. ②：`12 × 3 + 10 × 4 = 36 + 40 = 76` ✓

## 孩子容易错在哪

- **以为相减必须把某个图形消光**。这道题减完两种图形都还剩一个，孩子容易觉得"白减了"就放弃。其实 `○ + △ = 22` 已经把两个算式压成了一个，正是解题的钥匙。
- **分组时凑不出整包**。看到 `○ + ○ + ○ + △ + △`，要主动配对：一个 ○ 配一个 △，配出两对，多出一个 ○。配对这个动作要练熟。
- **减的时候右边忘了减**。左右两边必须一起减，否则等式就不成立了。
- **只算出 ○ 就交卷**。题目问的是 △ 和 ○ **两个**，别漏。

## 再练一道

同一招，换个样子（答案在最后）：

> 下面算式中，△ 和 □ 各代表多少？
>
> ```
> □ + □ + △ = 16
> □ + △ + △ = 14
> ```

这道题两式相减得 `□ − △ = 2`；两式相加得 `3□ + 3△ = 30`，即 `□ + △ = 10`。于是 **□ = 6，△ = 4**。

> 相加也是一招。看到两个算式里图形个数正好"对称"，就试试把它们加起来。
