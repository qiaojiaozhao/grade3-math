# 彩灯

## 题目

> 广场上的彩灯按**红、黄、蓝**的顺序一直重复。第 **51** 盏是什么颜色？

{% hint style="info" %}
母题是 [周期](../知识点/周期问题.md)。一组一组圈起来；一个不多，就是这一组的最后一个。
{% endhint %}

## 先看动画

<a class="button primary" href="https://qiaojiaozhao.github.io/grade3-math/demos/%E5%BD%A9%E7%81%AF-%E5%91%A8%E6%9C%9F%E9%97%AE%E9%A2%98.html">打开互动动画：余数是 0，停在最后一个</a>

点「自动播放整段动画」，会看到第 17 组的三盏灯写着 49、50、51。要让孩子看见的是这两件事：

- 51 盏不用一盏盏数，3 盏一组，正好 17 组；
- 余数是 0，第 51 盏是这一组的最后一盏蓝。再往后那个红，是第 52 盏。

## 一步步想

{% stepper %}
{% step %}
## 圈出一组

红、黄、蓝，3 盏一组。红是第 1 个，黄是第 2 个，蓝是最后一个。
{% endstep %}

{% step %}
## 51 里有几组

    51 ÷ 3 = 17（组）……0

一盏都没多出来。
{% endstep %}

{% step %}
## 停在最后一个

第 17 组的最后一盏是蓝。

    第 49 盏 红，第 50 盏 黄，第 51 盏 蓝
{% endstep %}
{% endstepper %}

## 答案

**第 51 盏是蓝色。**

## 验算

17 × 3 = 51，每一组的最后一盏都是蓝，第 51 盏刚好是第 17 个蓝。下一个红是第 52 盏。✓

## 孩子容易错在哪

- **余 0 就从下一个红开始。** 他觉得「剩下 0 个」等于没有位置，要再开一组。17 组已经把 51 盏用完了，再往后指就是第 52 盏。
- **51 ÷ 3 = 17，17 是蓝色。** 他把「17 组」当成颜色的编号。17 是组数，颜色要回到这一组里看第几个。
- **从 0 开始数，余 0 是红。** 这一组是第 1、第 2、最后一个，没有第 0 个。
