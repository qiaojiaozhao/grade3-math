# 联欢会握手

## 题目

> 有 **50** 名学生参加联欢会。第一个到会的女生同**全部男生**握过手，第二个到会的女生只差 **1** 个男生没握过手，第三个到会的女生只差 **2** 个男生没握过手，依次类推，最后到一个到会的女生同 **7** 个男生握过手。问这些学生中有多少名男生？

{% hint style="info" %}
两种想法都能到「男生多 6」，再用 [和差](../知识点/和差问题.md)。方法一偏 [植树](../知识点/植树问题.md)，方法二是选舞伴带走。
{% endhint %}

## 排成一列

    第 1 个女生 → 全部男生
    第 2 个女生 → 全部男生 − 1

## 最后一个是第几个

有几个女生，最后那个就是第几个。第几个，就比第 1 个少握「几个 − 1」。

    最后（第「女生人数」个）→ 男生 −（女生 − 1）= 7
{% endstep %}

{% step %}
## 挪一下，多 6

    男生 − 女生 + 1 = 7
    男生 − 女生 = 6
{% endstep %}

男生先到齐。女生一个一个来，跟还在的男生握手，**选一个舞伴带走**。每走一对，台上男生少 1 个。

{% stepper %}
{% step %}
## 最后来的时候还剩 7 个

前面的女生都已经选走舞伴了。最后一个女生上台，只剩 **7** 个男生。她跟这 7 个都握过手。
{% endstep %}

{% step %}
## 她也选走 1 个

7 个人里再带走 1 个舞伴：

    7 − 1 = 6

台上还剩 **6** 个男生，没有女生做舞伴。
{% endstep %}

{% step %}
## 剩下的就是多出来的

每个女生都带走了 1 个男生。现在还剩 6 个没舞伴——

    男生比女生多 6
{% endstep %}
{% endstepper %}
{% endtab %}
{% endtabs %}

## 收口：一共 50，多 6

两条路都走到这里。这是 [和差](../知识点/和差问题.md)：

    男生 − 女生 = 6
    男生 + 女生 = 50

    （50 + 6）÷ 2 = 28（男生）
    （50 − 6）÷ 2 = 22（女生）

## 答案

**28 名男生。**

## 验算

1. 方法一：女生 22 人，最后是第 22 个，少握 21 个：`28 − 21 = 7` ✓
2. 方法二：22 个女生各带走 1 个，剩 `28 − 22 = 6` 个没舞伴；最后来时是 6 + 1 = 7 个 ✓
3. 人数：`28 + 22 = 50` ✓

## 孩子容易错在哪

- **看见剩 7 个就说多 7。** 最后那个女生还要选走 1 个，剩下 6 个才是没舞伴的。
- **最后一个当成第 7 个。** 7 是她握到的人数，不是她排第几。
- **少握的个数写成「女生人数」。** 方法一里，第 1 个不少握，所以是女生 − 1。
- **算出差就停。** 还要加上「一共 50」，才是和差。
