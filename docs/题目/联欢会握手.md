# 联欢会握手

## 题目

> 有 **50** 名学生参加联欢会。第一个到会的女生同**全部男生**握过手，第二个到会的女生只差 **1** 个男生没握过手，第三个到会的女生只差 **2** 个男生没握过手，依次类推，最后到一个到会的女生同 **7** 个男生握过手。问这些学生中有多少名男生？

{% hint style="info" %}
母题是 [植树](../知识点/植树问题.md) 叠 [和差](../知识点/和差问题.md)。最后一个是第几个，少握几个减 1；挪出「多 6」，再用和差。
{% endhint %}

## 先看动画

<a class="button primary" href="https://qiaojiaozhao.github.io/grade3-math/demos/%E8%81%94%E6%AC%A2%E4%BC%9A%E6%8F%A1%E6%89%8B-%E6%A4%8D%E6%A0%91%E9%97%AE%E9%A2%98.html">打开互动动画：最后一个是第几个</a>

点「自动播放整段动画」，顺着纸上那几行看：

- 第 1 个握全部男生，第 2 个少 1，第 3 个少 2
- 最后那个是第「女生人数」个，所以少握了「女生 − 1」个

## 一步步想

{% stepper %}
{% step %}
## 排成一列

    第 1 个女生 → 全部男生
    第 2 个女生 → 全部男生 − 1
    第 3 个女生 → 全部男生 − 2
    ……
{% endstep %}

{% step %}
## 最后一个是第几个

有几个女生，最后那个就是第几个。第几个，就比第 1 个少握「几个 − 1」。

    最后（第「女生人数」个）→ 男生 −（女生 − 1）= 7
{% endstep %}

{% step %}
## 挪一下，多 6

括号拆开：

    男生 − 女生 + 1 = 7
    男生 − 女生 = 6

+1 挪到右边，7 − 1 = 6。男生比女生多 6。
{% endstep %}

{% step %}
## 再加上一共 50，这是和差

    男生 − 女生 = 6
    男生 + 女生 = 50

    （50 + 6）÷ 2 = 28（男生）
    （50 − 6）÷ 2 = 22（女生）
{% endstep %}
{% endstepper %}

## 答案

**28 名男生。**

## 验算

1. 女生 22 人，最后是第 22 个，少握 21 个：`28 − 21 = 7` ✓
2. 人数：`28 + 22 = 50` ✓
3. 第 1 个女生握 28 个（全部男生）✓

## 孩子容易错在哪

- **最后一个当成第 7 个。** 7 是她握到的人数，不是她排第几。
- **少握的个数写成「女生人数」。** 第 1 个不少握，从第 2 个才开始少，所以是女生 − 1。
- **括号拆不开。** 男生 −（女生 − 1）= 男生 − 女生 + 1。
- **算出差就停。** 还要加上「一共 50」，才是和差。
