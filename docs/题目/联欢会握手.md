# 联欢会握手

## 题目

> 有 **50** 名学生参加联欢会。第一个到会的女生同**全部男生**握过手，第二个到会的女生只差 **1** 个男生没握过手，第三个到会的女生只差 **2** 个男生没握过手，依次类推，最后到一个到会的女生同 **7** 个男生握过手。问这些学生中有多少名男生？

{% hint style="info" %}
母题是 [植树](../知识点/植树问题.md)。握手次数从「全部男生」一路少到 7，两头都算，就是两端都种。
{% endhint %}

## 一步步想

{% stepper %}
{% step %}
## 先看清楚 7 是什么

最后一个女生握了 7 个手，这是她碰到的男生，**不是**男生一共几人。

第一个女生握的才是全部男生。所以握手数排成一排：

    男生，男生 − 1，男生 − 2，……，7
{% endstep %}

{% step %}
## 从头数到尾，两头都算

这一排有几个数，就有几个女生。从「男生」数到 7，两端都算：

    女生 = 男生 − 7 + 1 = 男生 − 6
{% endstep %}

{% step %}
## 和 50 收口

男生加女生是 50 人：

    男生 +（男生 − 6）= 50
    2 × 男生 = 56
    男生 = 28

女生 = 28 − 6 = 22。
{% endstep %}
{% endstepper %}

## 答案

**28 名男生。**

## 验算

1. 握手数从 28 到 7：`28 − 7 + 1 = 22`，正好 22 个女生 ✓
2. 人数：`28 + 22 = 50` ✓
3. 第一个女生握 28 个（全部男生），最后一个握 7 个 ✓

## 孩子容易错在哪

- **看见最后握了 7 个，就答 7 个男生。** 7 是最后一个女生碰到的人数，不是男生总数。
- **「只差 1 个没握」看成只握了 1 个。** 第二个女生握的是「男生 − 1」。
- **从大数减到 7，忘了加 1。** 减完只剩中间的空档，两头的人还要算上。
- **算出女生就交卷。** 题目问的是男生。
