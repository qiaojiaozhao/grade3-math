# 联欢会握手

## 题目

> 有 **50** 名学生参加联欢会。第一个到会的女生同**全部男生**握过手，第二个到会的女生只差 **1** 个男生没握过手，第三个到会的女生只差 **2** 个男生没握过手，依次类推，最后到一个到会的女生同 **7** 个男生握过手。问这些学生中有多少名男生？

{% hint style="info" %}
母题是 [植树](../知识点/植树问题.md)。先用手点清「减完是空档」，再变成已经会的 [和差](../知识点/和差问题.md)。
{% endhint %}

- 最后：1 个女生、7 个男生，7 − 1 = 6

## 一步步想

{% stepper %}
{% step %}
## 7 不是全部男生

最后那个女生只握了 7 个手。第一个女生握的才是全部男生，所以男生比 7 个多。
{% endstep %}

{% step %}
## 先拿小数一遍

握手数一个比一个少 1，排起来就是一串连着的数：最后是 7，第一是「男生」。

先别管 50。假如从 7 点到 10，用手点：

    7、8、9、10

点了 **4** 下。10 − 7 = 3 只是中间 3 段空档。两头的人还站着，所以 3 + 1 = 4。
{% endstep %}

{% step %}
## 为什么少 6 个

先只看最后那个女生：

    1 个女生，7 个男生
    7 − 1 = 6

男生已经多 6 个。

往前加一个女生，她多握 1 个手，男生变成 8：2 个女生、8 个男生，还是多 6。再加一个：3 和 9，还是多 6。

**每加一个女生，男生也加 1，多出来的 6 一直不变。**
{% endstep %}

{% step %}
## 一共 50，多 6，这是和差

男生、女生一共 50 人，男生比女生多 6。把多的 6 拿掉，剩下两份一样长：

    （50 + 6）÷ 2 = 28（男生）
    （50 − 6）÷ 2 = 22（女生）
{% endstep %}
{% endstepper %}

## 答案

**28 名男生。**

## 验算

1. 从 28 点到 7：`28 − 7 + 1 = 22`，正好 22 个女生 ✓
2. 人数：`28 + 22 = 50` ✓
3. 第一个女生握 28 个（全部男生），最后一个握 7 个 ✓

## 孩子容易错在哪

- **看见最后握了 7 个，就答 7 个男生。** 7 是她碰到的人数，不是男生总数。
- **10 − 7 直接当人数。** 减完是空档，两头的人还要再点上。
- **「只差 1 个没握」看成只握了 1 个。** 第二个女生握的是「男生 − 1」。
- **算出女生就交卷。** 题目问的是男生。
