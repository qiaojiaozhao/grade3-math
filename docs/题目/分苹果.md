# 分苹果

## 题目

> 老师把一批苹果分给小朋友。如果每人分 **3** 个，会**多 2** 个；如果每人分 **5** 个，会**少 4** 个。有多少名小朋友？一共有多少个苹果？

{% hint style="info" %}
母题是 [盈亏](../知识点/盈亏问题.md)。两种分法，一多一少，先求人再求总数。
{% endhint %}

## 一步步想

{% stepper %}
{% step %}
## 两次每人差多少

从每人 3 个改成每人 5 个，每人要多拿：

    5 − 3 = 2（个）
{% endstep %}

{% step %}
## 一共要补多少

原来多 2 个，改成每人 5 个后还差 4 个，一共要补：

    2 + 4 = 6（个）
{% endstep %}

{% step %}
## 先求人数

这 6 个正好每人分 2 个：

    6 ÷ 2 = 3（名小朋友）
{% endstep %}

{% step %}
## 再求苹果总数

用第一种分法：

    3 × 3 + 2 = 11（个）

用第二种验：3 × 5 − 4 = 11 ✓
{% endstep %}
{% endstepper %}

## 答案

**3 名小朋友，11 个苹果。**

## 验算

1. 每人 3 个：`3 × 3 = 9`，加多出的 2，`9 + 2 = 11` ✓
2. 每人 5 个：`3 × 5 = 15`，少 4 个，`15 − 4 = 11` ✓

## 孩子容易错在哪

- **只用「多 2」或「少 4」去除**。要把多和少**加起来**，才是要补的总数。
- **除的是 5 或 3**。要除的是两次每人的**差**（5 − 3 = 2），不是其中的某一个数。
- **先算总数**。必须先求人数，再求苹果；顺序反了容易乱。
- **「正好分完」当少 0**。如果第二种正好分完，少的就是 0，公式一样用。

> 有一包铅笔，每人分 4 支还多 3 支，每人分 6 支就少 5 支。有多少名同学？多少支铅笔？

验算：4 人每人 4 支多 3 ✓；4 人每人 6 支少 5 ✓
