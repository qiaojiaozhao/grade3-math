# 书法和绘画

## 题目

> 三(1)班有 **42** 人。参加书法小组的有 **25** 人，参加绘画小组的有 **23** 人。每人至少参加一项。**两项都参加**的有多少人？

{% hint style="info" %}
母题是 [重叠](../知识点/重叠问题.md)。两圈加起来，比全班多几个，中间就有几个人。
{% endhint %}

点「自动播放整段动画」，会看到两个圈先分开再叠在一起。要让孩子看见的是这两件事：

- 25 + 23 = 48，比全班 42 多了 6，班上的人并没有变成 48 个；
- 多出来的 6 个人站在两圈中间，书法数了一次，绘画又数了一次。

## 一步步想

{% stepper %}
{% step %}
## 两圈加起来

    25 + 23 = 48
{% endstep %}

{% step %}
## 比全班多几个

    48 − 42 = 6

这 6 个人被数了两遍。
{% endstep %}

{% step %}
## 中间就是两项都参加的

    两项都参加 = 6（人）
{% endstep %}
{% endstepper %}

## 答案

**两项都参加的有 6 人。**

## 验算

只参加书法的 25 − 6 = 19 人，只参加绘画的 23 − 6 = 17 人。19 + 6 + 17 = 42，和全班一样多。✓

## 孩子容易错在哪

- **25 + 23 = 48，就说有 48 人参加。** 班上只有 42 人。48 是举手的次数，中间 6 个人举了两次。
- **42 − 25 = 17，说两项都参加的有 17 人。** 17 是不参加书法的人数，不是两样都参加的。
- **25 − 23 = 2。** 两个小组不是一个套着另一个，不能用大的减小的。
