# 大衣裤子和鞋

## 题目

> 李明 **420** 元买了一件大衣、一条裤子和一双鞋。大衣比裤子贵 **80** 元，大衣和裤子一共比鞋贵 **220** 元。每件东西多少钱？

{% hint style="info" %}
母题是 [和差](../知识点/和差问题.md)。先把大衣和裤子捆成一包，跟鞋做一次和差；解开再做一次。
{% endhint %}

点「自动播放整段动画」，会看到大衣和裤子被绳子捆住。要让孩子看见的是这两件事：

- 大衣+裤子先当成**一包**，这一包和鞋就是普通的和差；
- 求出一包是 320 之后，再解开，用差 80 分出大衣和裤子。

## 一步步想

{% stepper %}
{% step %}
## 把大衣和裤子捆成一包

三件一共 420。大衣和裤子比鞋贵 220，就是：

```
一包 + 鞋 = 420
一包 − 鞋 = 220
```

这就是和差。
{% endstep %}

{% step %}
## 求出一包和鞋

    一包 =（420 + 220）÷ 2 = 320（元）
    鞋 =（420 − 220）÷ 2 = 100（元）
{% endstep %}

{% step %}
## 解开一包，再做一次和差

一包里是大衣和裤子，和是 320，差是 80。

    大衣 =（320 + 80）÷ 2 = 200（元）
    裤子 =（320 − 80）÷ 2 = 120（元）
{% endstep %}
{% endstepper %}

## 答案

**大衣 200 元，裤子 120 元，鞋 100 元。**

## 验算

1. 一共：`200 + 120 + 100 = 420` ✓
2. 大衣比裤子贵：`200 − 120 = 80` ✓
3. 大衣和裤子比鞋贵：`200 + 120 − 100 = 220` ✓

## 孩子容易错在哪

- **三样一起猜。** 不知道从哪下手。先捆两件成一包，题目就变成普通和差。
- **把 220 当成鞋的价钱。** 220 是「一包比鞋多出来的」，不是鞋。
- **第一次和差做完就停。** 320 是大衣加裤子，还要再用差 80 拆开。
- **差加错边。** 大衣贵，80 加在大衣那边。
