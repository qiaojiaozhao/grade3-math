# 过桥

## 题目

> 一列火车长 **180** 米，每秒走 **15** 米。它要通过一座长 **120** 米的桥。从车头上桥到车尾离开桥，要多少秒？

{% hint style="info" %}
母题是 [过火车](../知识点/过火车问题.md)。过完才算过，车身和桥要加在一起。
{% endhint %}

点「自动播放整段动画」，火车会先过一根电线杆，再过桥。要让孩子看见的是这两件事：

- 车头刚出桥，整列火车还压在桥上，**还没过完**；
- 车尾也离开桥，走过的路才是 **180 + 120**。

## 一步步想

{% stepper %}
{% step %}
## 走过了多长的路

车头从桥的这一头进，一直走到车尾离开那一头。中间这一段 = 桥 + 车身。

    180 + 120 = 300（米）
{% endstep %}

{% step %}
## 要走几秒

每秒走 15 米，300 米要走多少秒。

    300 ÷ 15 = 20（秒）
{% endstep %}
{% endstepper %}

## 答案

**要 20 秒。**

## 验算

1. 20 秒走 `15 × 20 = 300` 米 ✓
2. 300 米刚好是 `180 + 120`，车身加桥 ✓

## 孩子容易错在哪

- **只拿桥去除：120 ÷ 15 = 8 秒。** 他以为车头走完桥就过完了。车头出桥时，车还在桥上。
- **只拿车身去除：180 ÷ 15 = 12 秒。** 那是过电线杆的算法。桥有厚度，要再加一段。
- **把速度和长度加起来。** 米和「每秒多少米」不能直接加，先加两段路，再去除。
