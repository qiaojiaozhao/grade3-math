# 两位数

## 题目

> 用数字 **1、2、3** 组成两位数，每个数字只用一次。一共能组成多少个？

{% hint style="info" %}
母题是 [枚举](../知识点/枚举问题.md)。先定十位，再定个位。一个十位写完，再换下一个。
{% endhint %}

点「自动播放整段动画」，两位数会按十位分成三列长出来。要让孩子看见的是这两件事：

- 想到哪写到哪，12、23、31 这样会漏掉一半；
- 十位钉死以后，个位只剩两个，三列加起来是 6 个。

## 一步步想

{% stepper %}
{% step %}
## 十位先写 1

个位不能再用 1，剩下 2 和 3：12、13。两个。
{% endstep %}

{% step %}
## 换十位

十位 2：21、23。十位 3：31、32。又是两列，每列两个。
{% endstep %}

{% step %}
## 数自己写下的

    2 + 2 + 2 = 6（个）
{% endstep %}
{% endstepper %}

## 答案

**能组成 6 个：12、13、21、23、31、32。**

## 验算

十位 3 种选择，个位在剩下的 2 个里选，3 × 2 = 6。和列出来的一样多。✓

## 孩子容易错在哪

- **想到哪写到哪。** 写出 12、23、31 就停，21、13、32 被漏掉。
- **同一个数写两遍。** 12 和 21 是两个数，但 12 不能再写一次。
- **个位又用了十位那个数字。** 题目说每个数字只用一次，11、22、33 不能算。
