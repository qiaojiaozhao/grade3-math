# 台阶

## 题目

> 一个台阶形的图形，最外面刚好能框进一个长 **12** 厘米、宽 **7** 厘米的长方形。每一级台阶都是横平竖直的。它的周长是多少厘米？

{% hint style="info" %}
母题是 [巧求周长](../知识点/巧求周长.md)。横的边往上推，竖的边往旁边推，推成一个长方形再算。
{% endhint %}

点「自动播放整段动画」，凹进去的边会被推成一个长方形。要让孩子看见的是这两件事：

- 顺着每一小段加，凹进去的地方容易漏；
- 横的推到上面、竖的推到旁边，周长还是 (12 + 7) × 2。

## 一步步想

{% stepper %}
{% step %}
## 先找外框

台阶再多，最外面还是长 12、宽 7。
{% endstep %}

{% step %}
## 把边推平

横着的边往上推，竖着的边往右推，拼成那个长方形。边只是挪了地方，没有变长变短。
{% endstep %}

{% step %}
## 算长方形的周长

    (12 + 7) × 2 = 38（厘米）
{% endstep %}
{% endstepper %}

## 答案

**周长是 38 厘米。**

## 验算

长方形对边相等。两条长 12 + 12 = 24，两条宽 7 + 7 = 14，24 + 14 = 38。✓

## 孩子容易错在哪

- **顺着台阶一段段加，凹进去的漏掉。** 周长是绕外面一圈，不是数里面有几级。
- **只加长加宽，忘了乘 2。** 12 + 7 = 19 只是半圈。
- **把台阶的级数列进去。** 有几级台阶，和周长没关系。
