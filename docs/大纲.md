# 三年级浅奥大纲

三年级奥数看起来题很多，骨架就这些。这一页是总目：**已经写成课的，点进去；还没写的，先对上骨头。**

{% hint style="info" %}
加新课之前先翻这一页。能挂到已有母题的「换一身衣服」里，就不要新开一课。
{% endhint %}

[倒油问题](题目/倒油问题.md) 是两根骨头叠在一道题上：先移多补少，再差倍。这种叠法以后会越来越多。

看不清手里这道是哪一类，去 [认出这是哪道母题](认出母题.md)。

## 建议下一层写的

和上面这些同一量级，作业和杯赛都常考。按加课的性价比排：

| 顺序 | 母题 | 骨头一句话 | 常见衣服 |
| --- | --- | --- | --- |
| 1 | 归一 | 先求出 1 份，再乘回去 | 3 盒 36 支，5 盒多少支 |
| 2 | 还原 | 从结果往回走 | 给了又拿、吃了又剩 |
| 3 | 周期 | 除一下看余数，余数落在第几个 | 星期、彩灯、排队报数 |
| 4 | 巧算 | 凑整、拆开再拼、换个位置 | 一长串加减乘 |

{% hint style="success" %}
**年龄**和**平均数**多数是和差、和倍换了衣服。先挂到已有母题上；孩子单独卡住了，再拆成一课。
{% endhint %}

## 计算和数

不是应用题，但是浅奥一半分数在这里。

| 母题 | 骨头一句话 |
| --- | --- |
| 巧算 | 先凑成整十整百，再算 |
| 定义新运算 | ★、△ 被规定成一种新算法，按规矩算 |
| 数字谜 | 竖式里挖空，每位只能 0–9 |
| 奇偶与余数 | 单双怎么变；除完剩几 |

## 计数和推理

| 母题 | 骨头一句话 |
| --- | --- |
| 枚举 | 不硬算，按顺序列完 |
| 简单排列 | 排队、握手、从 A 到 B 有几条路 |
| 重叠 | 两堆各有多少，重合的别数两遍 |
| 逻辑推理 | 谁是谁、哪句是真的 |
| 抽屉原理（浅） | 3 个抽屉 4 个苹果，至少有一个不少于 2 |

鸡兔同笼还不会除法时，也可以先用枚举：一只一只换，数到脚够了。

## 先别单独开课的

这些名字常出现在「三年级奥数」目录里，骨头其实偏四年级。碰到了，先挂到已有母题上：

| 名字 | 先挂到哪 |
| --- | --- |
| 行程（相向、追及） | 归一 + 画一条线 |
| 分数应用 | 等三年级下分数稳了再说 |
| 最大公约数 / 最小公倍数 | 多数教材在四年级 |
| 年龄「几年后是几倍」 | 先当和倍，差不变那一层再补 |

## 加课的时候怎么用这一页

1. 先在本页找到骨头。已经有课，就只补「换一身衣服」。
2. 新骨头：按 [AGENTS.md](https://github.com/qiaojiaozhao/grade3-math/blob/main/AGENTS.md) 的流程写母题页和例题，再把这一页表格里的那一行改成「已有」并补上链接。
3. 同时改 [认出这是哪道母题](认出母题.md) 那张认题表。
