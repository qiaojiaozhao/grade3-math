# 三年级上册浅奥体系

三年级上学期（秋季）的奥数，各家讲义排法不一样，骨头是同一套。这一页把它们排成**六个单元**，每个单元学会一张图，单元里列出母题，标清楚现在的状态。

{% hint style="info" %}
加新课之前先翻这一页。能挂到已有母题的「换一身衣服」里，就不要新开一课。
{% endhint %}

## 状态怎么看

| 记号 | 意思 |
| --- | --- |
| ✅ | 已经写成课，点进去就能看 |
| 🔜 | 新骨头，排进了下一批要写的课 |
| 🧥 | 不是新骨头，先当旧母题的一身衣服写一道例题 |
| ⏳ | 常出现在三年级目录里，但骨头偏难，先别单独开课 |

难度：⭐ 课内能跟上就会，⭐⭐ 秋季常考，⭐⭐⭐ 拔高或杯赛。

## 第一单元 画线段图

[单元导读](单元/画线段图.md) · [系统课：一张图，五种问法](单元/画线段图系统课.md)。三年级应用题的一半都在这里。工具只有一个：**把数量画成两根条子，比高矮**。

| 母题 | 骨头一句话 | 难度 | 状态 |
| --- | --- | --- | --- |
| 和差 | 一共 + 相差 →（和 ± 差）÷ 2 | ⭐⭐ | ✅ [母题](知识点/和差问题.md) · [兄弟分糖](题目/兄弟分糖.md) · [大衣裤子和鞋](题目/大衣裤子和鞋.md) |
| 和倍 | 一共 + 是几倍 → 和 ÷（倍 + 1） | ⭐⭐ | ✅ [母题](知识点/和倍问题.md) · [甲乙两堆书](题目/甲乙两堆书.md) |
| 差倍 | 相差 + 是几倍 → 差 ÷（倍 − 1） | ⭐⭐ | ✅ [母题](知识点/差倍问题.md) · [倒油问题](题目/倒油问题.md) |
| 移多补少 | 倒过去 1 份，差距缩小 2 份 | ⭐ | ✅ [母题](知识点/移多补少.md) · [倒油问题](题目/倒油问题.md) |
| 年龄 | 两个人一起长一岁，高出的那一截不变 | ⭐⭐ | ✅ [母题](知识点/年龄问题.md) · [妈妈和小明](题目/妈妈和小明.md) |
| 平均数 | 多的补给少的，补平了就是平均 | ⭐⭐ | 🧥 挂在移多补少 |
| 归一 | 先求出 1 份，再乘回去 | ⭐ | 🔜 |

**平均数**的卡点是「总数 ÷ 人数」会算，却想不到「把高的削下来填到矮的」，先在移多补少上讲清楚，孩子单独卡住了再拆出来。

[单元导读](单元/数清楚.md)。这一单元不考算，考**有没有漏、有没有多数一遍**。

| --- | --- | --- | --- |
| 植树 | 点过去，头和尾都要点 | ⭐ | ✅ [母题](知识点/植树问题.md) · [联欢会握手](题目/联欢会握手.md) |
| 买赠 | 送的那瓶也要喝，5 加 1 才是一组 | ⭐⭐ | ✅ [母题](知识点/买赠问题.md) · [买五送一](题目/买五送一.md) |
| 过火车 | 车头进、车尾出，两段路加在一起 | ⭐⭐⭐ | ✅ [母题](知识点/过火车问题.md) · [过桥](题目/过桥.md) |
| 周期 | 一组一组圈起来。多出来从头数；一个不多，就是最后一个 | ⭐⭐ | ✅ [母题](知识点/周期问题.md) · [彩灯](题目/彩灯.md) |
| 重叠 | 两圈加起来多出来的，就是中间数了两遍的 | ⭐⭐ | 🔜 |
| 枚举 | 按顺序列，先定第一个，再定第二个 | ⭐⭐ | 🔜 |

| --- | --- | --- | --- |
| 数线段、数角 | 从一个端点出发数，数完一个换下一个 | ⭐⭐ | 🔜 |

| 图形计数 | 大方形里有几个小正方形 | ⭐⭐ | 🧥 挂在数线段、数角 |

## 按这个顺序学

单元从一到六排，每个单元都用到前一个单元的本事：

{% stepper %}
{% step %}
## 画线段图

和差 → 和倍 → 差倍 → 移多补少 → 年龄。线段图练熟了，后面的题一半能自己画出来。「份」的想法也是在这里学会的。
{% endstep %}

{% step %}
## 倒推与假设

还原 → 鸡兔同笼 → 盈亏。线段图画不出来时的两种新想法。盈亏要用到第一单元的「份」。
{% endstep %}

{% step %}
## 数清楚

植树 → 买赠 → 过火车 → 周期，之后是重叠、枚举。学会「不漏、不重」。
{% endstep %}

{% step %}
## 巧算、图形、推理

巧算可以穿插在任何时候练，每天两三道；图形跟着课内「线和角」走；推理放在学期末，把前面的本事综合起来用。
{% endstep %}
{% endstepper %}

## 下一批写哪几课

按「秋季常考 × 孩子容易卡住 × 能做成动画」排，从上往下写：

| 顺序 | 母题 | 单元 | 孩子卡在哪 | 适合的例题 |
| --- | --- | --- | --- | --- |
| 1 | 重叠 | 数清楚 | 两项人数直接相加，比全班还多 | 书法 25 人、绘画 23 人，全班 42 人 |
| 2 | 数线段、数角 | 图形 | 只数最短的几段，长线段漏掉 | 一条线上 5 个点，有几条线段 |
| 3 | 巧求周长 | 图形 | 看见凹进去的台阶就一段段加，加漏 | 台阶形图形的周长 |
| 4 | 枚举 | 数清楚 | 想到哪写到哪，漏一种或重一种 | 1、2、3 能组成几个两位数 |
| 5 | 逻辑推理 | 推理 | 条件一多记不住，前后矛盾 | 三人三种颜色的衣服 |
| 6 | 归一 | 画线段图 | 不先求 1 份，直接拿总数乘 | 3 盒 36 支笔，5 盒多少支 |
| 7 | 奇偶 | 推理 | 只会一个个试，不会先看单双 | 1 到 10 能不能分成和相等的两组 |
| 8 | 一笔画 | 图形 | 画了半天画不出，不知道能不能画 | 「田」字能不能一笔画 |

## 和课内、讲义怎么对上

这张表给家长用：孩子在学校学到哪一单元，就可以顺手看哪一道母题。

| 2024 人教版三年级上册 | 顺手看的母题 |
| --- | --- |
| 二、混合运算 | 巧算、巧填算符 |
| 曹冲称象的故事（综合实践） | 图形推理（等量代换）——称象就是用石头代换大象 |
| 四、多位数乘一位数 | 巧算、归一、数字谜 |
| 数字编码（综合实践） | 枚举 |
| 五、线和角 | 数线段、数角 |
| 六、分数的初步认识 | 暂不开课，等三年级下分数稳了再说 |

旧版人教版三年级上册还有「长方形和正方形（周长）」和「数学广角——集合」两个单元，2024 新版上册里没有了。但奥数秋季班照样讲，分别对应**巧求周长**和**重叠**。

学而思三年级秋季两套讲义（常规班、超常班）列出的专题，这一页都有对应：平均数、巧求周长、和差倍、图形面积、逻辑推理、速算巧算、巧填算符、年龄、多笔画、周期、奇偶、最短路线；超常班另加鸡兔同笼、盈亏、等量代换、字典排列与树形图、整数分拆。

## 先别单独开课的

这些名字常出现在「三年级奥数」目录里，骨头偏四年级。碰到了，先挂到已有母题上：

| 名字 | 先挂到哪 |
| --- | --- |
| 行程（相向、追及） | 过桥过杆看 [过火车](知识点/过火车问题.md)；相向追及挂归一 + 画一条线 |
| 分数应用 | 等三年级下分数稳了再说 |
| 最大公约数 / 最小公倍数 | 多数教材在四年级 |

## 加课的时候怎么用这一页

1. 先在本页找到骨头和它所在的单元。已经 ✅，就只补「换一身衣服」。
2. 🧥 的，打开它挂的那道母题，在「换一身衣服」里加一题。
3. 🔜 的，按 [AGENTS.md](https://github.com/qiaojiaozhao/grade3-math/blob/main/AGENTS.md) 的流程写母题页和例题，写完把这一行的状态改成 ✅ 并补上链接，再从「下一批写哪几课」里划掉。
4. 同时改 [认出这是哪道母题](认出母题.md) 那张认题表，和所在单元的导读页。
