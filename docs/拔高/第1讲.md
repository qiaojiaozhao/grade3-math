# 第 1 讲 巧求周长

[奥数拔高](奥数拔高.md) · 第 1 讲「环顾四周」 · 本讲大纲：周长的定义；长正方形周长正反求；平移法（楼梯型、陷阱型、复合型）；标向法；靠墙围篱笆

> **横的推上去，竖的推出去；推不出去的，单独加上。**

## 这一讲学了什么

**周长**：封闭图形最外面一周的长度。就是沿着图形的边走一圈，一共走了多远。

长方形、正方形会算以后，碰到楼梯形、缺了一块的图形，不用一段一段去量：**把边挪一挪，拼成长方形再算**（平移法）。挪不动的，就**顺着边走一圈，数往哪个方向走了多远**（标向法）。最后还有一种变化：一边靠墙，那条边就不用围篱笆。

| 图形 | 周长 | 反过来求 |
| --- | --- | --- |
| 长方形 | (长 + 宽) × 2 | 长 = 周长 ÷ 2 − 宽　宽 = 周长 ÷ 2 − 长 |
| 正方形 | 边长 × 4 | 边长 = 周长 ÷ 4 |

## 卡在哪

楼梯形的图形，题目只给最下面和最左边两条边。孩子习惯一段一段加，一看每一级台阶都没写多长，就卡住了，以为题目少给了条件。

他缺的是一个画面：**边可以挪。** 把台阶上横着的边往上推、竖着的边往右推，长度一点没变，却正好拼成一个长方形。

点「自动播放整段动画」，会看到楼梯的边被一段段推到长方形的框上。要让孩子看见的是：

- 横着的三段推上去，接起来正好和下面那条一样长；竖着的三段推出去，正好和左边那条一样长。
- 标向法：定一个起点，顺着边走一圈。往右走的最后都要往左走回来，往下走的都要往上走回来。

## 平移法的三种图形

| 类型 | 长什么样 | 怎么推 |
| --- | --- | --- |
| 楼梯型 | 一级一级往下的台阶 | 全部推出去，周长 = 外面那个长方形 |
| 陷阱型 | 某条边的**中间**凹进去一块 | 能推的推出去，**夹在中间的两条推不出去，单独加上** |
| 复合型 | 又有台阶又有凹槽 | 台阶照推；凹槽两边照加 |

挖在**角上**的缺口不算陷阱：里面那两条边推出去正好补上，周长不变。

## 课上的例题

{% tabs %}
{% tab title="例 1 周长反着求" %}
> 一个长方形的周长是 **30 厘米**，长是 **9 厘米**，宽是多少厘米？

**画出来**

```
     长 9
 ┌─────────┐
 │         │ 宽 ?
 └─────────┘
 走一圈 = 长 + 宽 + 长 + 宽 = 30
 走半圈 = 长 + 宽      = 15
```

**一步步想**

1. 走一圈是两个长、两个宽。先求走半圈，就是一个长加一个宽：`30 ÷ 2 = 15`（厘米）
2. 半圈里去掉长，剩下的就是宽：`15 − 9 = 6`（厘米）

**答案：宽是 6 厘米。**

验算：`(9 + 6) × 2 = 30` ✓
{% endtab %}

{% tab title="例 2 楼梯型" %}
> 一个楼梯形状的图形，最下面一条边长 **12 厘米**，最左边一条边长 **9 厘米**，每个拐角都是直角。它的周长是多少厘米？

**画出来**

```
 ┌────┐ ← 横的往上推
 │    └───┐
 │        └──┐ ← 竖的往右推
 │           │
 └───────────┘
      12
```

**一步步想**

1. 台阶上横着的边往上推，接起来和下面一样长，是 12 厘米。
2. 台阶上竖着的边往右推，接起来和左边一样长，是 9 厘米。
3. 拼成长 12、宽 9 的长方形：`(12 + 9) × 2 = 42`（厘米）

**答案：周长是 42 厘米。**
{% endtab %}

{% tab title="例 3 陷阱型" %}
> 一个长 **10 厘米**、宽 **6 厘米** 的长方形，上边正中间挖掉一个宽 **4 厘米**、深 **3 厘米** 的缺口。剩下的图形周长是多少厘米？

**画出来**

```
 ┌───┐    ┌───┐
 │   │    │   │ ← 缺口两边，各 3
 │   └────┘   │
 │            │
 └────────────┘
       10
```

**一步步想**

1. 缺口底下那条横边往上推，正好补上上边缺的那 4 厘米。四周还是一个长方形：`(10 + 6) × 2 = 32`（厘米）
2. 缺口左右两条竖边夹在中间，往左推、往右推都碰不到外框，**推不出去**，要单独加上：`3 × 2 = 6`（厘米）
3. 合起来：`32 + 6 = 38`（厘米）

**答案：周长是 38 厘米。**

验算：一段段加，上边剩下 `10 − 4 = 6`，缺口底 4，缺口两边 `3 + 3`，下边 10，左右 `6 + 6`，`6 + 4 + 6 + 10 + 12 = 38` ✓
{% endtab %}

{% tab title="例 4 标向法" %}
> 下面这个图形每个拐角都是直角。左边高 **10 厘米**，下边长 **16 厘米**，上面有一个台子高出 **2 厘米**，台子右边往下落 **4 厘米**，再往上爬 **3 厘米**。求它的周长。

**画出来**

```
          ┌───────┐
          │       │     ┌───────────┐
    ┌─────┘       │     │           │
    │             └─────┘           │
    │                               │
    └───────────────────────────────┘
```

**一步步想**

高低不平，下去 4 又只上来 3，推不整齐，换标向法。

1. **定起点**：左下角。
2. **标方向**：顺着边走一圈，往上走的有 10、2、3；往下走的有 4 和右边那一长条（不知道多长）。
3. **求总和**：走一圈回到起点，往上走多少，往下就走多少。往上一共 `10 + 2 + 3 = 15`，所以往下一共也是 15。往右一共和往左一样，都是 16。
4. 周长 = 横着走的 + 竖着走的：`16 × 2 + 15 × 2 = 62`（厘米）

**答案：周长是 62 厘米。**

验算：右边那一长条是 `15 − 4 = 11`。一段段加：`10 + 3 + 2 + 4 + 4 + 3 + 3 + 6 + 11 + 16 = 62` ✓（台子宽 4，坑底宽 3，最右边一段宽 6，一共 `3 + 4 + 3 + 6 = 16`）
{% endtab %}

{% tab title="例 5 靠墙围篱笆" %}
> 用篱笆围一块长 **8 米**、宽 **5 米** 的长方形菜地，菜地一边靠墙。篱笆最少要多少米？

**画出来**

```
 ████████████████  ← 墙
 │              │
 │              │ 5
 └──────────────┘
        8
 长边靠墙：篱笆 = 8 + 5 + 5
```

**一步步想**

1. 靠墙的那条边不用围，篱笆只围另外三条。
2. 长边靠墙：`8 + 5 × 2 = 18`（米）；宽边靠墙：`8 × 2 + 5 = 21`（米）。
3. 让墙替我们挡掉最长的那条，篱笆最短。

**答案：长边靠墙，篱笆最少 18 米。**
{% endtab %}
{% endtabs %}

## 孩子容易错在哪

- **一段一段加，加到不知道多长的台阶就停了**。他以为题目少给了条件。其实台阶的边都能推到外框上，不用知道每一级多长。
- **挖掉一块，就觉得周长一定变小**。挖在**角上**的，周长**不变**；只有挖在**边的中间**（陷阱型），才会多出两条推不出去的边，周长**变大**。面积变小了，周长不一定。
- **陷阱型忘了加缺口两边**。推完拼成长方形就急着算，漏了夹在中间、推不出去的那两条。
- **周长反着求，忘了先除以 2**。`30 − 9 = 21` 是把两个宽和一个长当成了宽。走一圈有两个长，要先分成半圈。
- **靠墙围篱笆，算成整个周长**。靠墙那条边不用篱笆；而且要问清楚哪条边靠墙，最短要让长边靠墙。

## 给家长：这一讲在练什么

- **转化的眼光**：形状变了，边的长度没变。把不会算的图形挪成会算的长方形，这是后面巧求面积、等量代换都会用到的想法。
- **分清能推和推不出去**：同样是缺了一块，挖在角上和挖在中间结果不一样。推不动的，就换标向法：往上等于往下，往左等于往右。
- **正着想、反着想**：知道长和宽求周长会了，再反过来从周长求宽；靠墙围篱笆是再变一步，先想清楚「哪几条边要围」。

检验方法：合上页面，让孩子画一个楼梯形，边推边讲给你听为什么周长和长方形一样。讲得出「边挪了位置，长度没变」，这一讲就收下了。
