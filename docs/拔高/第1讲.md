# 第 1 讲 巧求周长

[奥数拔高](奥数拔高.md) · 第 1 讲 / 共 15 讲 · 本讲大纲：长正方形周长正反求；巧求周长方法：平移法、标向法

> **横的推上去，竖的推出去；推不出去的，单独加上。**

## 这一讲学了什么

周长就是沿着图形的边走一圈，一共走了多远。长方形、正方形会算了以后，再碰到楼梯形、缺了一块的图形，不用一段一段去量：**把边挪一挪，拼成长方形再算。**

## 卡在哪

楼梯形的图形，题目只给最下面和最左边两条边。孩子习惯一段一段加，一看每一级台阶都没写多长，就卡住了，以为题目少给了条件。

他缺的是一个画面：**边可以挪。** 把台阶上横着的边往上推、竖着的边往右推，长度一点没变，却正好拼成一个长方形。

点「自动播放整段动画」，会看到楼梯的边被一段段推到长方形的框上。要让孩子看见的是：

- 横着的三段推上去，接起来正好和下面那条一样长；竖着的三段推出去，正好和左边那条一样长。
- 沿着边走一圈，往右走的最后都要往左走回来，往下走的都要往上走回来。这就是标向法，也是「为什么能推」。

## 课上的例题

{% tabs %}
{% tab title="例 1 周长反着求" %}
> 一个长方形的周长是 **30 厘米**，长是 **9 厘米**，宽是多少厘米？

**画出来**

```
     长 9
 ┌─────────┐
 │         │ 宽 ?
 └─────────┘
 走一圈 = 长 + 宽 + 长 + 宽 = 30
 走半圈 = 长 + 宽      = 15
```

**一步步想**

1. 走一圈是两个长、两个宽。先求走半圈，就是一个长加一个宽：`30 ÷ 2 = 15`（厘米）
2. 半圈里去掉长，剩下的就是宽：`15 − 9 = 6`（厘米）

**答案：宽是 6 厘米。**

验算：`(9 + 6) × 2 = 30` ✓
{% endtab %}

{% tab title="例 2 楼梯形" %}
> 一个楼梯形状的图形，最下面一条边长 **12 厘米**，最左边一条边长 **9 厘米**，每个拐角都是直角。它的周长是多少厘米？

**画出来**

```
 ┌────┐ ← 横的往上推
 │    └───┐
 │        └──┐ ← 竖的往右推
 │           │
 └───────────┘
      12
```

**一步步想**

1. 台阶上横着的边往上推，接起来和下面一样长，是 12 厘米。
2. 台阶上竖着的边往右推，接起来和左边一样长，是 9 厘米。
3. 拼成长 12、宽 9 的长方形：`(12 + 9) × 2 = 42`（厘米）

**答案：周长是 42 厘米。**

验算：沿着边走一圈，往右一共 12、往左 12，往下一共 9、往上 9，`12 + 12 + 9 + 9 = 42` ✓
{% endtab %}

{% tab title="例 3 中间凹进去" %}
> 一个长 **10 厘米**、宽 **6 厘米** 的长方形，上边正中间挖掉一个宽 **4 厘米**、深 **3 厘米** 的缺口。剩下的图形周长是多少厘米？

**画出来**

```
 ┌───┐    ┌───┐
 │   │    │   │ ← 缺口两边，各 3
 │   └────┘   │
 │            │
 └────────────┘
       10
```

**一步步想**

1. 缺口底下那条横边往上推，正好补上上边缺的那 4 厘米。上下左右四条边还是一个长方形：`(10 + 6) × 2 = 32`（厘米）
2. 缺口左右两条竖边夹在中间，往左推、往右推都碰不到外框，**推不出去**，要单独加上：`3 × 2 = 6`（厘米）
3. 合起来：`32 + 6 = 38`（厘米）

**答案：周长是 38 厘米。**

验算：一段段加，上边剩下 `10 − 4 = 6`，缺口底 4，缺口两边 `3 + 3`，下边 10，左右 `6 + 6`，`6 + 4 + 6 + 10 + 12 = 38` ✓
{% endtab %}
{% endtabs %}

## 孩子容易错在哪

- **一段一段加，加到不知道多长的台阶就停了**。他以为题目少给了条件。其实台阶的边都能推到外框上，不用知道每一级多长。
- **挖掉一块，就觉得周长一定变小**。挖在**角上**的，里面的两条边推出去正好补上，周长**不变**；只有挖在**边的中间**，才会多出两条推不出去的边，周长**变大**。面积变小了，周长不一定。
- **中间凹进去的，忘了加缺口两边**。推完拼成长方形就急着算，漏了夹在中间、推不出去的那两条。
- **周长反着求，忘了先除以 2**。`30 − 9 = 21` 是把两个宽和一个长当成了宽。走一圈有两个长，要先分成半圈。

<details>

剪在角上，里面那两条 2 厘米的边推出去正好补上缺的角。周长还是 `(8 + 5) × 2 = 26`，**26 厘米，没变**。

## 给家长：这一讲在练什么

- **转化的眼光**：形状变了，边的长度没变。把不会算的图形挪成会算的长方形，这是后面巧求面积、等量代换都会用到的想法。
- **分清能推和推不出去**：同样是缺了一块，挖在角上和挖在中间结果不一样。练的是动手前先看清楚。
- **正着想、反着想**：知道长和宽求周长会了，再反过来从周长求宽。反着想时要先想清楚「走一圈里有几个长、几个宽」。

检验方法：合上页面，让孩子画一个楼梯形，边推边讲给你听为什么周长和长方形一样。讲得出「边挪了位置，长度没变」，这一讲就收下了。
