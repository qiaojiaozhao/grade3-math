# 第 2 讲 奇偶

[奥数拔高](奥数拔高.md) · 第 2 讲「独具慧眼」 · 本讲大纲：认识奇偶数；加减法奇偶性；乘法奇偶性

> **两个两个排成对，只数落单的。**

## 这一讲学了什么

**偶数**：除以 2 没有余数，个位是 0、2、4、6、8。**奇数**：除以 2 余 1，个位是 1、3、5、7、9。

把一个数的东西两个两个排成对：刚好排完是偶数，多出一个落单的是奇数。很多数加加减减，结果是奇是偶，**不用算出来，只要数落单的有几个。**

| 加减 | 结果 | 为什么 |
| --- | --- | --- |
| 奇 ± 奇 | 偶 | 两个落单的凑成一对 |
| 奇 ± 偶 | 奇 | 落单的那个还是没人陪 |
| 偶 ± 奇 | 奇 | 同上 |
| 偶 ± 偶 | 偶 | 没有落单的 |

**奇数个奇数相加减，结果一定是奇数；偶数个奇数，结果是偶数。** 偶数加进来多少个都不影响。

乘法：**有偶则偶，全奇才奇。** 乘法就是好几组一样多的相加：`3 × 4` 是 3 组 4，每组都没有落单的，结果是偶；`3 × 5` 是 3 组 5，每组落单 1 个，一共落单 3 个，结果是奇。

## 卡在哪

孩子能把四条规则背下来，可一看到「1 + 2 + 3 + … + 9 是奇数还是偶数」，还是老老实实从头加。规则在他脑子里是四句咒语，不是一个画面，所以一长串数摆在眼前，他想不到能用。

还有一个更隐蔽的错：他会去数「一共有几个数」，而不是「有几个奇数」。

## 课上的例题

{% tabs %}
{% tab title="例 1 认奇偶" %}
> 37、100、2468、1359、0 里面，哪些是奇数，哪些是偶数？

**一步步想**

只看个位：37 个位 7，1359 个位 9，是**奇数**；100 个位 0，2468 个位 8，0 本身个位就是 0，是**偶数**。

**答案：奇数 37、1359；偶数 100、2468、0。**

0 也是偶数：0 ÷ 2 = 0，没有余数。
{% endtab %}

{% tab title="例 2 一长串加法" %}
> **1 + 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9** 的结果是奇数还是偶数？

**画出来**

```
 1  2  3  4  5  6  7  8  9
 ●     ●     ●     ●     ●    ← 只有奇数带着落单的

 ●●    ●●    ●                ← 5 个落单的：配成 2 对，剩 1 个
```

**一步步想**

1. 偶数没有落单的，不用管。
2. 奇数有 1、3、5、7、9，一共 **5 个**，是奇数个。
3. 奇数个奇数相加，结果是奇数。

**答案：奇数。**

验算：`1 + 2 + … + 9 = 45`，45 是奇数 ✓
{% endtab %}

{% tab title="例 3 有加有减" %}
> **101 − 97 + 55 − 33** 的结果是奇数还是偶数？

**一步步想**

1. 减法和加法一样看：奇 − 奇也是偶，落单的照样两两配对。
2. 四个数全是奇数，一共 **4 个**，是偶数个，正好配成 2 对。

**答案：偶数。**

验算：`101 − 97 = 4`，`4 + 55 = 59`，`59 − 33 = 26`，26 是偶数 ✓
{% endtab %}

{% tab title="例 4 乘法" %}
> 判断奇偶：① **13 × 15 × 17**　② **3 × 5 × 7 × 8**

**一步步想**

1. ① 三个数全是奇数：全奇才奇，结果是**奇数**。
2. ② 里面有一个 8 是偶数：有偶则偶，不管别的是什么，结果是**偶数**。

**答案：① 奇数，② 偶数。**

验算：`13 × 15 × 17 = 3315` 是奇数；`3 × 5 × 7 × 8 = 840` 是偶数 ✓
{% endtab %}

{% tab title="例 5 独具慧眼" %}
> 小明买了 **3 本** 每本 **5 元** 的本子，又买了几支每支 **2 元** 的笔。他付了 **50 元**，售货员找回 **8 元**。售货员找得对吗？

**一步步想**

1. 找回 8 元，说明花了 `50 − 8 = 42` 元，是偶数。
2. 本子：`3 × 5`，全奇才奇，是奇数。笔：2 元一支，有偶则偶，不管几支都是偶数。
3. 奇 + 偶 = 奇。花的钱一定是奇数，不可能是 42。

**答案：找错了。**

不用知道买了几支笔，只看奇偶就能看出错。
{% endtab %}
{% endtabs %}

## 孩子容易错在哪

- **一长串数，从头硬加**。规则背下来了，却没想到用。先问自己：「我只要知道奇偶，不用知道等于几。」
- **数成了「一共几个数」**。1 + 2 + … + 10 一共 10 个数，有人就说是偶数。要数的是**奇数有几个**：1、3、5、7、9 是 5 个，结果是奇数（55）。
- **以为减法规则不一样**。加法和减法的奇偶规则一模一样，有加有减也照样只数奇数。
- **乘法照搬加法**。奇 + 偶 = 奇，可奇 × 偶 = **偶**。乘法里只要有一个偶数，结果就是偶数。
- **不知道 0 是奇是偶**。0 除以 2 没有余数，是偶数。

## 给家长：这一讲在练什么

- **看整体、不看细节**：不算出结果，也能判断它的一个性质。这是「独具慧眼」这个讲名的意思。
- **用奇偶排除**：例 5、练习 4 这类题，答案是「不可能」，理由是奇偶对不上。这是后面很多推理题的开门钥匙。
- **把规则变成画面**：四条加减规则、两条乘法规则，背后都是「落单的有没有人陪」这一个画面。

检验方法：合上页面，问孩子「1 加到 10 是奇是偶」，让他不动笔讲给你听。能说出「奇数有 5 个，配完剩 1 个」，这一讲就收下了。
