# 奥数拔高

**浅奥母题**学的是骨头，**拔高系列**往上走一格：跟着学而思三年级秋季的课，一讲一页。每一页有一句口诀、课上的例题、一个动画、几道回家练的题。

它只管一件事：**课上老师讲过去、孩子没跟上的那一步，回家能再看一遍画面。**

{% hint style="info" %}
怎么用：上完课当天，先让孩子看这一讲的动画 → 把口诀念出来 → 合上页面，把例 1 讲给你听 → 讲得出来，再做「回家练一练」。
{% endhint %}

## 每一讲的页面里有什么

| 一节 | 给谁看 | 写什么 |
| --- | --- | --- |
| 一句话口诀 | 孩子 | 一个能照着做的动作，背下来就能用 |
| 卡在哪 | 家长 | 这一讲孩子最可能想错的那一步 |
| 先看动画 | 孩子 | 专门把「卡在哪」那一步画出来 |
| 课上的例题 | 孩子 | 从讲义里挑两三道，先画图再列式 |
| 孩子容易错在哪 | 家长 | 至少三条，第一条就是卡点 |
| 回家练一练 | 孩子 | 换了数字和故事的同类题，答案折叠 |
| 给家长 | 家长 | 这一讲在练哪几种能力 |
