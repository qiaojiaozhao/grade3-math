# 和倍

浅奥母题。两堆书、大小绳子、两个人的年龄，只要同时给了**和**与**倍数**，骨头都是这一根。

## 一句话口诀

> **和 ÷ (倍数 + 1) = 1 份。**

{% hint style="success" %}
把小的看成 1 份。大的是 3 倍，就是 3 份。接起来一共 4 份——每一份都要算进「和」里。
{% endhint %}

## 为什么要加 1

关键是**把小的那个看成 1 份**。

假设乙是 1 份，甲是乙的 3 倍，那甲就是 3 份。两条线段接起来，一共是 `3 + 1 = 4` 份。

很多孩子看到「3 倍」就直接用和除以 3，那是错的：除出来的是甲的 3 份，不是 1 份。

## 画出来

```
乙：┃ 1份 ┃
甲：┃ 1份 ┃ 1份 ┃ 1份 ┃
     └──────── 和 = 4 份 ────────┘
```

所以：

    1 份 = 和 ÷ (倍数 + 1)
    小数 = 1 份
    大数 = 1 份 × 倍数

## 三步走

以「甲、乙共 48，甲是乙的 3 倍」为例：

{% stepper %}
{% step %}
## 数出一共几份

    3 + 1 = 4（份）
{% endstep %}

{% step %}
## 求 1 份

    48 ÷ 4 = 12
{% endstep %}

{% step %}
## 还原两个数

    乙（1 份）= 12
    甲（3 份）= 12 × 3 = 36

检查：`36 + 12 = 48` ✓，`36 ÷ 12 = 3` ✓。
{% endstep %}
{% endstepper %}

## 别和「差倍」搞混

{% columns %}
{% column %}
### 和倍

两数相**加** 48，大的是小的 3 倍。

`48 ÷ (3 + 1)`
{% endcolumn %}

{% column %}
### 差倍

两数相**差** 24，大的是小的 3 倍。

`24 ÷ (3 − 1)`
{% endcolumn %}
{% endcolumns %}

记法：**求和就加，求差就减。**

{% hint style="warning" %}
「甲比乙多 2 倍」= 甲是乙的 3 倍。多出来的是 2 份，加上原来那 1 份，一共 3 倍。
{% endhint %}

## 什么时候想到它

题目里同时出现这两样东西，就是它：

- 一个**和**：「共 X」「一共 X」
- 一个**倍数**：「甲是乙的 3 倍」「甲比乙多 2 倍」
