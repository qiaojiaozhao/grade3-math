# 逻辑推理

浅奥母题。谁穿什么颜色、谁拿哪本书、谁喜欢哪样运动，只要是**几个人、几种东西、每人一个、互不相同**，骨头都是这一根。

{% hint style="info" %}

## 一句话口诀

> **确定的打勾，不可能的打叉；打了勾，这一行这一列都叉掉。**

{% hint style="success" %}
一行只剩一个空格，那个空格就是勾。没被说到的人，往往是最后剩下来的那一格。
{% endhint %}

## 为什么不能记在脑子里

这是孩子最容易错的地方。小红、小兰、小芳各穿红、黄、蓝中的一种。小红不穿红、也不穿黄，小兰不穿红。很多孩子能说出「小红穿蓝」，接着又说「小兰也可以穿蓝」。

错在**蓝已经有人穿了，他没把这一列叉掉**。条件只有两三句，记在脑子里就会前后打架：一个人穿了，别人就不能再穿。

换个画面：三把椅子，三个人。小红坐下了蓝椅子，蓝椅子上就贴一张「有人了」。再给小兰找座位，不能把她也放到这张椅子上。

## 画出来

人写在左边，颜色写在上面。先把「不是」打成叉：

```
        红    黄    蓝
小红    ✗    ✗    ✓     不穿红、不穿黄，只剩蓝
小兰    ✗    ✓    ✗     蓝被小红拿走；又不穿红，只剩黄
小芳    ✓    ✗    ✗     红和黄都有人了，只剩红
```

两条规矩，整张表都靠它：

1. **一行、一列只能有一个勾。** 每人一种颜色，每种颜色只有一个人。
2. **打了勾，这一行、这一列剩下的格子全部打叉。** 叉到某一行只剩一格，那一格打勾。

## 三步走

以「小红不穿红也不穿黄，小兰不穿红」为例：

{% stepper %}
{% step %}
## 把「不是」打成叉

小红这一行：红 ✗，黄 ✗。只剩蓝，打 ✓。
{% endstep %}

{% step %}
## 勾了就把这一列叉掉

蓝是小红的，小兰、小芳的蓝都打 ✗。

小兰还有一句「不穿红」，红也打 ✗。红和蓝都没了，小兰只剩黄，打 ✓。
{% endstep %}

{% step %}
## 剩下的那个人不用猜

黄是小兰的，小芳的黄打 ✗。小芳的蓝早就叉了，只剩红，打 ✓。

小红蓝，小兰黄，小芳红。

检查：三种颜色各有一个人；小红确实不是红、不是黄；小兰确实不是红。✓
{% endstep %}
{% endstepper %}

## 这道母题在考什么

- **条件写下来，不靠记。** 每一句「不是」就是表上的一个叉。写完再看，不会和前面的结论打架。
- **一行一列只有一个勾。** 这就是「每人一个、每种一个」。漏掉这一步，两个人会抢同一种。
- **剩下的那格不用条件。** 别人都确定了，最后一个是推出来的。题目没提到的人，往往就是这一格。

## 什么时候想到它

题目里出现这些，基本就是它：

- 几个人，几种东西，**每人一个，互不相同**
- 「不穿」「不是」「不喜欢」「不拿」
- 问的是「各是什么」「分别是谁」

[图形推理](简单推理.md)是算式里的图形。这道题没有算式，是人和东西对不上，改画表。

<details>
<summary>点开看想法</summary>

小刚不拿语文、不拿数学，只剩英语，打 ✓。英语这一列，小明和小亮都叉掉。

小明不拿语文，英语又叉了，只剩数学，打 ✓。

小亮只剩语文。

小刚英语，小明数学，小亮语文。

验：三本各一本；小明没拿语文；小刚没拿语文也没拿数学。✓

小明、小刚、小丽各拿一个水果：苹果、香蕉、橘子。小丽拿苹果，小明不拿香蕉。三人各拿什么？

<details>
<summary>点开看想法</summary>

「小丽拿苹果」是直接的勾。苹果这一列、小丽这一行，剩下的都叉掉。

小明不拿香蕉，苹果又已经叉了，只剩橘子，打 ✓。

小刚只剩香蕉。

小丽苹果，小明橘子，小刚香蕉。

验：三个水果各一个；小丽拿的是苹果；小明没拿香蕉。✓

</details>

{% tab title="名字会骗人" %}
小白、小黑各拿一个球：白球、黑球。小白说：「我拿的不是白球。」两人各拿哪个球？

<details>
<summary>点开看想法</summary>

只有两行两列。小白不拿白球，打 ✗，只剩黑球，打 ✓。

黑球这一列叉掉小黑，小黑只剩白球。

小白拿黑球，小黑拿白球。

看见「小白」就以为他拿白球，正好和他说的相反。✓

</details>
