# 数线段、数角

浅奥母题。一条线上有几个点、一个点射出几条射线、格子里有几个正方形，骨头都是这一根：**按顺序数，短的长的都要数。**

## 一句话口诀

> **从左边第一个点出发，能连到的都数上；数完换下一个，数过的不再数。**

{% hint style="success" %}
挨着的是线段，隔着一个点、两个点的也是线段。只数最短的，长的就漏了。
{% endhint %}

## 为什么不是 4 条

这是孩子最容易错的地方。一条线上 5 个点，很多孩子数成 4 条：第 1 个到第 2 个，第 2 个到第 3 个，第 3 个到第 4 个，第 4 个到第 5 个。

错在**他只数了挨着的**。第 1 个点到第 3 个、第 4 个、第 5 个，中间虽然隔着点，照样是一条线段。

换个画面：5 个同学站成一排。不只是旁边两个人能拉手，隔着人也能拉手。手拉过了就不要再拉回来，不然同一条手数两次。

## 画出来

5 个点从左往右。每个点只往**右边**连，连完换下一个：

```
点：  1    2    3    4    5

从 1：1—2  1—3  1—4  1—5     4 条
从 2：     2—3  2—4  2—5     3 条
从 3：          3—4  3—5     2 条
从 4：               4—5     1 条
从 5：                       0 条，右边没有点了

一共 4 + 3 + 2 + 1 = 10 条
```

数角是同一件事。几条射线从一个点射出去，从最边上的一条数起，它和右边每一条都夹一个角，数完换下一条。4 条射线是 3 + 2 + 1 = 6 个角。

## 三步走

以「一条线上 5 个点」为例：

{% stepper %}
{% step %}
## 从最左边的点往右数

它能连到右边 4 个点，就是 4 条。长的那几条也要数。
{% endstep %}

{% step %}
## 换下一个点，只往右数

第 2 个点往右还有 3 条。往回连到第 1 个点的那条，刚才已经数过，不再数。

第 3 个点 2 条，第 4 个点 1 条，第 5 个点右边没有了。
{% endstep %}

{% step %}
## 加起来

    4 + 3 + 2 + 1 = 10（条）

检查：挨着的 4 条，隔一个点的 3 条，隔两个点的 2 条，整条 1 条。4 + 3 + 2 + 1 = 10。✓
{% endstep %}
{% endstepper %}

## 这道母题在考什么

- **按顺序数，不漏不重。** 从哪一头开始要固定，数过的不再数。这是后面数角、数正方形都在用的习惯。
- **大的里面套着小的。** 最短的线段只是其中一层。隔着点的长线段、两个小角拼成的大角，都要单独数。
- **越往后越少。** 5 个点是 4 + 3 + 2 + 1，不是 5 × 4。最后一个点没有新的可数。

## 什么时候想到它

题目里出现这些，基本就是它：

- 「一条线上有几个点，有几条线段」
- 「从一个点画几条射线，组成几个角」
- 「图里有几个三角形、几个正方形」，而且大的里面套着小的
