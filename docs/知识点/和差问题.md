# 和差

浅奥母题。糖、人数、绳子，只要同时给了**和**与**差**，骨头都是这一根。

## 一句话口诀

> **（和 + 差）÷ 2 = 大数；（和 − 差）÷ 2 = 小数。**

{% hint style="success" %}
先把多出来的那截拿掉，剩下两份一样长，再平分。
{% endhint %}

## 为什么不是和直接除以 2

这是孩子最容易错的地方。很多孩子会以为「两人共 60，那就每人 30」。

错在**两人不相等**。共 60 只说明两条线段接起来是 60，长的那条还多出来一截「差」。

换个画面想：哥哥和弟弟一共有 60 颗糖，哥哥比弟弟多 12 颗。你不能平均分，得先把多出来的 12 颗**暂时拿掉**，剩下两份一样多；算完再把 12 颗还回去。

## 画出来

```
小数：┃■■■■■■■■■┃
大数：┃■■■■■■■■■┃ 多出的「差」┃
      └──── 和 ────┘
```

把「差」从大数上切掉，两条就一样长了：

    一样长的两条 = 和 − 差
    小数 = （和 − 差）÷ 2
    大数 = 小数 + 差 = （和 + 差）÷ 2

## 三步走

以「甲、乙共 60，甲比乙多 12」为例：

{% stepper %}
{% step %}
## 去掉差，看剩下多少

    60 − 12 = 48
{% endstep %}

{% step %}
## 求小数

    48 ÷ 2 = 24
{% endstep %}

{% step %}
## 求大数

    24 + 12 = 36

检查：`36 + 24 = 60` ✓，`36 − 24 = 12` ✓。
{% endstep %}
{% endstepper %}

## 别和「和倍」搞混

{% columns %}
{% column %}
### 和差

两数相**加** 60，相**差** 12。

去掉差，再平分。
{% endcolumn %}

{% column %}
### 和倍

两数相**加** 60，大的是小的 3 倍。

数一共几份，再除以份数。
{% endcolumn %}
{% endcolumns %}

记法：**有「差」就减了再分；有「倍」就数份再分。**

## 什么时候想到它

题目里同时出现这两样东西，就是它：

- 一个**和**：「共 X」「一共 X」「两人相加是 X」
- 一个**差**：「甲比乙多 X」「相差 X」

## 换一身衣服

同一根骨头，出题人换了故事。先别算，指认「这是和差」，再动笔。

{% tabs %}
{% tab title="两班人数" %}
甲班乙班一共 86 人，甲班比乙班多 8 人。两班各多少人？

<details>
<summary>点开看想法</summary>

和 86，差 8。小数 =（86 − 8）÷ 2 = 39，大数 = 39 + 8 = 47。

验算：`47 + 39 = 86` ✓，`47 − 39 = 8` ✓

</details>
{% endtab %}

{% tab title="绳子剪两段" %}
一根绳子剪成两段，两段一共 36 米，长的比短的多 6 米。两段各多长？

<details>
<summary>点开看想法</summary>

和 36，差 6。短的 =（36 − 6）÷ 2 = 15，长的 = 15 + 6 = 21。

验算：`21 + 15 = 36` ✓，`21 − 15 = 6` ✓

</details>
{% endtab %}

{% tab title="两筐苹果" %}
两筐苹果共 50 千克，甲筐比乙筐少 6 千克。两筐各多少千克？

<details>
<summary>点开看想法</summary>

「少 6」就是差 6，乙是大数。乙 =（50 + 6）÷ 2 = 28，甲 = 28 − 6 = 22。

验算：`28 + 22 = 50` ✓，`28 − 22 = 6` ✓

</details>
{% endtab %}
{% endtabs %}
