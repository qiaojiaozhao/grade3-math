# 巧算

浅奥母题。连加、连减、25 和 125 的乘法，骨头都是这一根：**先找好朋友，再动笔。**

## 一句话口诀

> **先把凑成整十、整百的两个圈在一起，再算剩下的。**

{% hint style="success" %}
好朋友有三种：末位凑成 10 或 100 的两个数；25 和 4、125 和 8；连减时的两个减数。它们常常不挨着，别从左边一路算过去。
{% endhint %}

## 为什么不能从左边加起

这是孩子最容易错的地方。`347 + 158 + 253`，很多孩子从左边开始：

    347 + 158 = 505，505 + 253 = 758。

答案碰巧对，可是**又进位又难算**，数字一大就错。347 和 253 本是好朋友，被中间的 158 隔开了。从左边加，正好把好朋友拆开。

换个画面：三堆积木，两边的两堆拼起来刚好是一整层，中间那堆先放着。先拼整齐的两堆，比从左边一堆一堆垒要快，也不容易倒。

## 画出来

先看个位。7 和 3 凑成 10，中间的 8 凑不上。再看十位：4 + 5 = 9，加上个位进上来的 1，也是 10。所以末两位 47 + 53 = 100。

```
347 + 158 + 253
└── 好朋友 ──┘
347 + 253 = 300 + 200 + 100 = 600
600 + 158 = 758
```

三种好朋友，圈法一样：

| 看见 | 先圈谁 | 例子 |
| --- | --- | --- |
| 个位凑 10，末两位凑 100 | 这两个数 | 347 和 253 |
| 25 和 4，125 和 8 | 先乘这一对 | 25 × 4 = 100 |
| 一个数连减两个数 | 先把两个减数加起来 | 126 + 274 = 400 |

## 三步走

以「347 + 158 + 253」为例：

{% stepper %}
{% step %}
## 看个位，找出好朋友

7 和 3 凑成 10。347 和 253 是一对，158 先放着。
{% endstep %}

{% step %}
## 确认末两位是不是 100

    47 + 53 = 100
    347 + 253 = 600
{% endstep %}

{% step %}
## 再算剩下的

    600 + 158 = 758

检查：从左边加 `347 + 158 + 253` 也是 758。✓
{% endstep %}
{% endstepper %}

## 这道母题在考什么

- **先看再写。** 算式不是只能从左到右。先扫一眼个位，凑成 10 的两个先圈出来。这是后面所有巧算的习惯。
- **末两位凑 100，整百分开加。** 47 + 53 = 100 看出来了，300 + 200 就不用进位。
- **好朋友可以不挨着。** 隔着一个数也要先圈。乘法和连减用的是同一种圈法。

## 什么时候想到它

题目里出现这些，基本就是它：

- 三个或更多的数相加，有两个个位凑成 10
- 算式里有 25 和 4，或者 125 和 8，哪怕隔着一个数
- 一个数连着减两个数

68 + 47 + 32 = ？

个位 8 和 2 凑成 10。68 和 32 是好朋友：

    68 + 32 = 100

{% tab title="25 找 4" %}
25 × 7 × 4 = ？

<details>
<summary>点开看想法</summary>

25 和 4 是好朋友，先乘，中间的 7 先放着：

    25 × 4 = 100
    100 × 7 = 700

从左边乘是 25 × 7 = 175，再乘 4，容易错。

验算：175 × 4 = 700。✓

</details>
{% endtab %}

{% tab title="125 找 8" %}
125 × 6 × 8 = ？

<details>
<summary>点开看想法</summary>

125 和 8 是好朋友：

    125 × 8 = 1000
    1000 × 6 = 6000

验算：125 × 6 = 750，750 × 8 = 6000。✓

</details>
{% endtab %}

{% tab title="连减" %}
800 − 126 − 274 = ？

<details>
<summary>点开看想法</summary>

连减两个数，就是减去它们的和。先看两个减数：26 + 74 = 100，所以

    126 + 274 = 400
    800 − 400 = 400

验算：800 − 126 = 674，674 − 274 = 400。✓

</details>
{% endtab %}

{% tab title="借整还零" %}
467 − 298 = ？

<details>
<summary>点开看想法</summary>

298 差 2 就是 300。先当 300 减，多减的 2 要加回来：

    467 − 300 + 2 = 169

画面是付钱：买 298 元的东西付 3 张 100，店家找回 2 元。这一招和「好朋友凑整」是同一根骨头，专题 [搬、借、拆](../专题/搬借拆.md) 里讲透了。

验算：169 + 298 = 467。✓

</details>
{% endtab %}

{% tab title="照新规矩算" %}
规定 a ★ b = 2 × a + b。7 ★ 3 = ？

<details>
<summary>点开看想法</summary>

★ 不是普通的加减。先看规定：2 × a + b，a 是 7，b 是 3。

    2 × 7 + 3 = 17

不要算成 7 + 3 = 10，也不要算成 7 × 3 = 21。

</details>
