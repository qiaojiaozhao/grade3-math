# 数字谜

浅奥母题。加法竖式挖空、乘法竖式挖空，只要**空格要一个个填**，骨头都是这一根：**从个位看起，先把进位找出来。**

## 一句话口诀

> **从个位看起。个位对不上，就是进了 1。**

{% hint style="success" %}
进位的 1 不能丢。个位决定它有没有，十位算的时候要把它加上。
{% endhint %}

## 为什么从十位填会填错

这是孩子最容易错的地方。很多孩子看见十位上空着，就先猜十位。个位 6 加一个数，个位是 3，他觉得 6 加几不会变成 3，就卡住了。

错在忘了进位。6 加 7 是 13，个位写下 3，向十位进 1。个位对不上 6 本身能加出的数，就是因为满十进了一。

## 画出来

```
    □ 6
  + 2 □
  ------
    5 3
```

个位：6 + □ = 13，□ = 7，进 1。

十位：□ + 2 + 1 = 5，□ = 2。

    26 + 27 = 53

## 这道母题在考什么

- **从个位读竖式**：个位没有别人进给它，最好确定。
- **进位是 1，不是 0**：两个一位数相加，满十就进 1，三年级这里不会进 2。
- **填完整道算一遍**：空格都填上以后，把竖式重加一次。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 竖式里有 □ 或 ○
- 只给了和的某一位
- 求的是被挖掉的那个数字
