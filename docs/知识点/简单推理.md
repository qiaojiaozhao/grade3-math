# 图形推理

浅奥母题。△ ○ □ 换成苹果、星星也一样：同一个记号，在哪儿都是同一个数。

## 一句话口诀

> **两个算式摆一起，划掉一样多的，剩下的就露出来。**

{% hint style="success" %}
一样多的东西，可以一起划掉，也可以整包换掉。
{% endhint %}

## 这是什么题

算式里出现 △、○、□ 这些图形，每个图形代表一个数。规矩只有一条：**同一个图形，在哪儿都是同一个数。** 给你几个算式，让你把每个图形是几求出来。

```
□ + □ + □ + □ + △ + △ + △ = 58
△ + △ + △ + □ + □ + □ + □ + □ + □ = 72

求：△ = ?   □ = ?
```

## 两招

{% tabs %}
{% tab title="第一招：消去法" %}
两个算式里，如果某个图形**个数完全一样**，把大的减小的，这个图形就同时消失了。

拿上面那两个算式数一数：

| | □ 的个数 | △ 的个数 | 等于 |
| --- | --- | --- | --- |
| ① | 4 | 3 | 58 |
| ② | 6 | 3 | 72 |

△ 都是 **3 个，一样多**。用 ② 减 ①：

```
△ ：3 − 3 = 0 个   ← 划掉了
□ ：6 − 4 = 2 个
右边：72 − 58 = 14
```

所以 `□ + □ = 14`，**□ = 7**。

再回到 ①：4 个 □ 就是 `4 × 7 = 28`，剩下 `58 − 28 = 30` 是 3 个 △，**△ = 10**。

{% hint style="warning" %}
左边划掉什么，右边就必须跟着减什么。这是最容易漏的一步。
{% endhint %}
{% endtab %}

{% tab title="第二招：等量代换" %}
已经知道一小包东西值多少，就可以把它整包换成一个数，不用管里面每个是几。

```
△ + □ = 9
△ + △ + □ + □ + □ = 25
```

第二个算式别急着算，先**重新分组**，看能不能凑出整包的「△ + □」：

```
△ + △ + □ + □ + □
= (△ + □) + (△ + □) + □
=    9    +    9    + □
```

于是 `18 + □ = 25`，**□ = 7**，回头得 **△ = 2**。
{% endtab %}
{% endtabs %}

## 什么时候用哪招

| 看到什么 | 用哪招 |
| --- | --- |
| 两个算式里某个图形**个数相同** | 消去法：相减，把它划掉 |
| 已知某几个图形**合起来是多少** | 等量代换：整包换成那个数 |
| 图形有三种以上 | 先消去，减少图形种类，再代换 |
| 两个算式个数正好对称 | 也可以试试把它们**加**起来 |

两招常常连着用：先相减得到一个简单关系，再把这个关系当成整包代换回去。[配套例题](../题目/图形算式.md)就是这样。

## 孩子容易错在哪

- **只减左边，忘了减右边。** 左边划掉 3 个 △，右边的 72 也必须减 58。
- **数错个数。** `△ + △ + △` 是 3 个不是 2 个。动笔前先把个数标出来。
- **减反方向。** 要用大的减小的。先比一比 72 和 58 谁大。
- **求出一个就收手。** 题目问的是每个图形各是多少。

## 换一身衣服

{% tabs %}
{% tab title="换图形" %}
★ 和 ● 各代表多少？

```
★ + ★ + ● = 16
★ + ● + ● = 14
```

<details>
<summary>点开看想法</summary>

两式相减：★ − ● = 2。两式相加：3★ + 3● = 30，即 ★ + ● = 10。于是 ★ = 6，● = 4。

衣服换成星星，骨头还是「摆一起，划掉或加起来」。

</details>
