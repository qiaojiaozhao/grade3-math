# 巧求周长

浅奥母题。台阶、L 形、缺一个角的长方形，只要边是横平竖直的，骨头都是这一根：**凹进去的边推出去，还是原来那个长方形。**

## 一句话口诀

> **横的边往上推，竖的边往旁边推，推成一个长方形再算。**

{% hint style="success" %}
推出去的边，和凹进去的边一样长。周长没有变，只是换成好算的那一圈。
{% endhint %}

## 为什么一段段加会漏

这是孩子最容易错的地方。很多孩子看见台阶，就顺着每一小段加，凹进去的那一截常常漏掉，或者加着重了。

错在把周长当成「里面那些台阶的条数」。周长是绕外面走一圈。横着的边不管凹在哪一层，推到最上面还是那么长；竖着的边推到最旁边，也还是那么长。

## 画出来

```
┌──┐              ┌────────┐
│  └──┐           │        │
│     └──┐   →    │        │
└────────┘        └────────┘
```

外框长 12 厘米、宽 7 厘米：

    (12 + 7) × 2 = 38（厘米）

## 这道母题在考什么

- **看整圈，不看碎边**：周长是绕一圈，不是把看见的短边数一遍。
- **平移不改变长度**：边挪了位置，长短不变。这是后面割补面积的同一件事。
- **先认外框**：题目给的往往是能框住它的长和宽，不是每一级台阶的尺寸。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「台阶形」「凹凸」「缺一个角」
- 边都是横平竖直的
- 求的是周长，又给了最外面的长和宽

<details>
<summary>点开看想法</summary>

剪掉的那个角，少了两条外框，又多了两条一样长的新边，周长不变。

(9 + 4) × 2 = **26** 厘米。✓
