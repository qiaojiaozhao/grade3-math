# 还原

浅奥母题。卖桃子、剪布、给糖，骨头都是这一根：**题目从前往后讲，算的时候从后往前走。**

## 一句话口诀

> **从剩下的倒回去：多的先还，再翻倍。**

{% hint style="success" %}
「卖掉一半还多 1」——最后剩的不是半筐。先把多卖的 1 个放回去，这才是半筐，再复制一份。
{% endhint %}

## 为什么不能 10 × 2 × 2

这是孩子最容易错的地方。很多孩子会以为「剩 10，倒两次一半，就是 `10 × 2 × 2 = 40`」。

错在**那一次多卖的 1 个没还回去**。剩的 10 个，是半筐少 1，不是半筐。

换个画面：筐里最后剩 10 个。假如刚才只卖掉刚好一半，筐里应该跟卖掉的一样多。可他多拿了 1 个走，所以筐里少了 1。要把那 1 个先放回来，11 个才是半筐。

## 画出来

```
最后剩：        ● ● ● ● ● ● ● ● ● ●      （10，少 1）
先还 1 个：     ● ● ● ● ● ● ● ● ● ● ●    （11 = 半筐）
再翻倍：        11 对上另外 11  →  22

再还 1 个：     22 + 1 = 23               （半筐）
再翻倍：        23 对上另外 23  →  46
```

所以：

    （剩的 + 多卖的）× 2 = 上一次卖之前
    倒几次，就这样走几遍

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「卖掉一半还多 / 少」「剪去一半还剩」
- 「给了又拿」「吃了又剩」
- 求的是**原来有多少**

## 换一身衣服

{% tabs %}
{% tab title="剪布" %}
一段布，第一次剪去一半，第二次又剪去余下的一半，还剩 8 米。原来长多少米？

<details>
<summary>点开看想法</summary>

这次没有「多 1」，剩的就是半段，直接翻倍。

    8 × 2 = 16（第二次剪之前）
    16 × 2 = 32（原来）

验：32 剪一半剩 16，再剪一半剩 8。

</details>
{% endtab %}

{% tab title="给糖" %}
小明把糖给弟弟一半少 2 颗，自己还剩 16 颗。原来有多少颗？

<details>
<summary>点开看想法</summary>

「一半少 2」是少给了，剩的比半盒多 2。先拿掉多出来的 2，再翻倍。

    （16 − 2）× 2 = 28

验：28 的一半是 14，给 14 − 2 = 12，自己剩 16。

</details>
{% endtab %}
