# 盈亏

浅奥母题。分苹果、分铅笔、分图书，只要**同一份东西分两次、一次多一次少**，骨头都是这一根。

## 一句话口诀

> **多了加少了，除以两次分的差，先求人再求总数。**

{% hint style="success" %}
每人 3 个**多 2**、每人 5 个**少 4** → 人数 =（2 + 4）÷（5 − 3）= 3 人。
{% endhint %}

## 为什么不是直接用「多」或「少」

这是孩子最容易错的地方。很多孩子会看见「多 2」就以为只有 2 个人，或者把多 2 和少 4 随便减一下。

错在**要把两种分法的差距一次性补平**。每人从 3 个改成 5 个，每个人要多拿 2 个；原来多出来的 2 个不够，还缺 4 个，所以一共要补 `2 + 4 = 6` 个。这 6 个正好分给 `6 ÷ 2 = 3` 个人。

换个画面想：一排小朋友，每人碗里先放 3 颗糖，最后**多 2 颗**在桌上。改成每人 5 颗，每人要多 2 颗，3 个人就要多 6 颗——桌上那 2 颗不够，还得再拿 4 颗才够，所以一共差 6 颗。

## 画出来

```
方案① 每人 3 个：  ■ ■ ■   ■ ■ ■   ■ ■ ■   ……   ＋ 多 2
方案② 每人 5 个：  ■ ■ ■ ■ ■   ■ ■ ■ ■ ■   ……   − 少 4
                      ↑ 每人多 2 个 ↑
```

每人多 2 个，要把「多 2」和「少 4」一起补上：

    人数 =（多 + 少）÷（第二次每人 − 第一次每人）
    总数 = 第一次每人 × 人数 + 多
         = 第二次每人 × 人数 − 少

## 三步走

以「每人 3 个多 2，每人 5 个少 4」为例：

{% stepper %}
{% step %}
## 两次每人差多少

    5 − 3 = 2（个/人）
{% endstep %}

{% step %}
## 先求人数

    （2 + 4）÷ 2 = 3（人）
{% endstep %}

{% step %}
## 再求总数

    3 × 3 + 2 = 11（个）
    或 3 × 5 − 4 = 11（个）

检查：3 人每人 3 个多 2 ✓；3 人每人 5 个少 4 ✓。
{% endstep %}
{% endstepper %}

## 别和「平均分」搞混

{% columns %}
{% column %}
### 盈亏

每人 **3 个多 2**，每人 **5 个少 4**。

两种分法，一多一少。
{% endcolumn %}

{% column %}
### 平均分

**30 个苹果平均分给 6 人**，每人几个？

只分一次，没有「多」或「少」。
{% endcolumn %}
{% endcolumns %}

记法：**看见两种分法 + 多/少，就是盈亏；只分一次，不是。**

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「每人分 ⋯ **还多** ⋯」「每人分 ⋯ **还少** ⋯」
- **同一份东西**分了两次，方案不同
- 求**有多少人**或**有多少个**

## 换一身衣服

同一根骨头，出题人换了故事。先别算，指认「这是盈亏」，再动笔。

{% tabs %}
{% tab title="分练习本" %}
老师有练习本，每人发 4 本还多 3 本，每人发 6 本就少 5 本。有多少名同学？多少本练习本？

<details>
<summary>点开看想法</summary>

每人差 2 本。人数 =（3 + 5）÷ 2 = 4，本数 = 4 × 4 + 3 = 19。

验算：4 人每人 4 本多 3 ✓；4 人每人 6 本少 5 ✓

</details>
{% endtab %}

{% tab title="分气球" %}
若干气球分给小朋友，每人 2 个多 6 个，每人 3 个正好分完。有多少小朋友？多少个气球？

<details>
<summary>点开看想法</summary>

「正好分完」= 少 0。人数 =（6 + 0）÷（3 − 2）= 6，气球 = 6 × 2 + 6 = 18。

验算：6 人每人 2 个多 6 ✓；6 人每人 3 个正好 ✓

</details>
{% endtab %}

{% tab title="分糖果" %}
一包糖，每人 5 颗多 1 颗，每人 7 颗少 3 颗。几个小朋友？多少颗糖？

<details>
<summary>点开看想法</summary>

人数 =（1 + 3）÷（7 − 5）= 2，糖 = 2 × 5 + 1 = 11。

验算：2 人每人 5 颗多 1 ✓；2 人每人 7 颗少 3 ✓

</details>
{% endtab %}
{% endtabs %}
