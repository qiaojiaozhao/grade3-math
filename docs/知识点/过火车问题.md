# 过火车

浅奥母题。过桥、过隧道、队伍过门洞，骨头都是这一根：**东西自己有多长，也要走完。**

## 一句话口诀

> **车头进、车尾出，两段路加在一起。**

{% hint style="success" %}
车头刚出桥，车还在桥上——没过完。车尾也离开了，才算过完。
{% endhint %}

## 为什么不能只拿桥去除

这是孩子最容易错的地方。很多孩子会以为「桥 120 米，每秒 15 米，就是 `120 ÷ 15 = 8` 秒」。

错在**他把「过桥」当成「车头走完桥」**。车头出桥的时候，整列火车还压在桥上，后面那截车身还要再走一遍。

换个画面：你排成一队过校门。第一个人走进门，不算过完；最后一个人也走出门，才算整队过完。走过的路 = 队伍自己的长 + 门洞的长。

## 画出来

```
过电线杆（杆没有厚）：只走车身
  车头到杆 ……………… 车尾到杆     ← 180 米

过桥：
  车头进桥口 …………………… 车尾出桥口
  |---- 桥 120 ----|---- 车身 180 ----|
                   加在一起 300 米
```

所以：

    走过的路 = 车身 + 桥
    时间 = 走过的路 ÷ 每秒走多少

过一根电线杆、过一个人，杆和人都没有「厚」，就只加车身。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「火车过桥 / 过隧道 / 过山洞」
- 「从车头进到车尾出」「整列通过」
- 给了车长、桥长、速度，问要几秒

## 换一身衣服

{% tabs %}
{% tab title="过隧道" %}
一列火车长 200 米，每秒走 20 米，通过一座 100 米的隧道。要几秒？

<details>
<summary>点开看想法</summary>

隧道就是桥，换了个名字。

    200 + 100 = 300（米）
    300 ÷ 20 = 15（秒）

验：每秒 20 米，15 秒走 300 米，正好车身加隧道。

</details>
{% endtab %}

{% tab title="队伍过门" %}
一队小朋友排成 12 米长的队伍，每秒走 1 米，通过 8 米长的门洞。整队走完要几秒？

<details>
<summary>点开看想法</summary>

队伍就是火车，门洞就是桥。

    12 + 8 = 20（米）
    20 ÷ 1 = 20（秒）

验：第 1 个孩子进门洞，到最后 1 个孩子出门洞，中间要走出队伍长加门洞长。

</details>
{% endtab %}
