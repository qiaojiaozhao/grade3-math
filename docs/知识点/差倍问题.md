# 差倍

浅奥母题。两桶油、大小绳子，只要同时给了**差**与**倍数**，骨头都是这一根。

## 一句话口诀

> **差 ÷ (倍数 − 1) = 1 份。**

{% hint style="success" %}
把小的看成 1 份。大的是 4 倍，多出来的不是 4 份，是 3 份——有 1 份要和小数对齐抵消掉。
{% endhint %}

## 为什么要减 1

关键是**把小的那个看成 1 份**。

假设乙是 1 份，甲是乙的 4 倍，那甲就是 4 份：

```
乙：┃ 1份 ┃
甲：┃ 1份 ┃ 1份 ┃ 1份 ┃ 1份 ┃
     └对齐┘ └──── 多出 3 份 ────┘
```

甲比乙多出来的，不是 4 份，是 `4 − 1 = 3` 份。题目给的那个「差」，对应的正是这 3 份。

这个 `−1` 就是在说：**抵消掉和小数一样多的那一份。**

## 三步走

以「甲比乙多 126，甲是乙的 4 倍」为例：

{% stepper %}
{% step %}
## 数出差是几份

    4 − 1 = 3（份）
{% endstep %}

{% step %}
## 求出 1 份

    126 ÷ 3 = 42
{% endstep %}

{% step %}
## 还原两个数

    小的（1 份）= 42
    大的（4 份）= 42 × 4 = 168

检查：`168 − 42 = 126` ✓，`168 ÷ 42 = 4` ✓。
{% endstep %}
{% endstepper %}

## 别和「和倍」搞混

{% columns %}
{% column %}
### 差倍

两数相**差** 126，大的是小的 4 倍。

`126 ÷ (4 − 1)`
{% endcolumn %}

{% column %}
### 和倍

两数相**加** 210，大的是小的 4 倍。

`210 ÷ (4 + 1)`
{% endcolumn %}
{% endcolumns %}

记法：**求和就加，求差就减。**

## 什么时候想到它

题目里同时出现这两样东西，就是它：

- 一个**倍数**关系：「甲是乙的 4 倍」「甲比乙多 3 倍」
- 一个**差**：「甲比乙多 126」，或者能先算出来的差

有时候差不会直接给你，要先自己求出来 —— 比如 [倒油问题](../题目/倒油问题.md) 里，差得先用 [移多补少](移多补少.md) 算出来。两道母题可以叠在一道题上。

## 换一身衣服

{% tabs %}
{% tab title="直接给差" %}
甲比乙多 24 本，甲是乙的 3 倍。甲、乙各多少本？

<details>
<summary>点开看想法</summary>

差是 3 − 1 = 2 份。1 份 = 24 ÷ 2 = 12。乙 12，甲 36。

验算：`36 − 12 = 24` ✓，`36 ÷ 12 = 3` ✓

</details>
{% endtab %}

{% tab title="大小绳子" %}
大绳比小绳长 18 米，大绳是小绳的 4 倍。两根绳子各多长？

<details>
<summary>点开看想法</summary>

衣服换成绳子，骨头还是差倍。差是 3 份。1 份 = 18 ÷ 3 = 6。小绳 6 米，大绳 24 米。

验算：`24 − 6 = 18` ✓，`24 ÷ 6 = 4` ✓

</details>
{% endtab %}
