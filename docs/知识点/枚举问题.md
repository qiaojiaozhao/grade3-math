# 枚举

浅奥母题。组两位数、组号码、选组长，只要是**把所有情况列出来**，骨头都是这一根：**先定第一个，再定第二个。**

## 一句话口诀

> **先定十位，再定个位。一个十位写完，再换下一个。**

{% hint style="success" %}
想到哪写到哪，就会漏掉一种，或把同一种写两遍。位置定死了，格子就填满了。
{% endhint %}

## 为什么想到哪写到哪会漏

这是孩子最容易错的地方。很多孩子用 1、2、3 组两位数，先写出 12、23、31，觉得写完了。21、13、32 还在后面。

错在没有顺序。先把十位钉死：十位是 1 的时候，个位只能是 2 或 3。这一格写完，再把十位换成 2。

每个数字只用一次，所以个位不能再写和十位一样的那个。

## 画出来

```
十位 1：  12   13
十位 2：  21   23
十位 3：  31   32
```

所以：

    2 + 2 + 2 = 6（个）

## 这道母题在考什么

- **按顺序，不靠灵感**：列情况是一种画法，不是碰运气。
- **先定一个位置**：位置钉死，剩下的选择就少，不容易重。
- **数自己写出来的行**：答案是列完之后数，不是猜一个数。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「能组成多少个」「有几种」
- 给了很少几个数字或几种颜色
- 求的是种数，不是某一个具体的数
