# 植树

浅奥母题。路边种树、报数、握手、锯木头，骨头都是这一根：**从一头走到另一头，两头算不算，差的就是那 1。**

## 一句话口诀

> **点过去，头和尾都要点。**

{% hint style="success" %}
用手从 7 点到 10：7、8、9、10，点了 **4** 下。10 − 7 = 3 只是中间的空档。
{% endhint %}

## 为什么不是直接减

这是孩子最容易错的地方。很多孩子会以为「从 7 到 10」就是 `10 − 7 = 3`。

错在**减完只剩下中间的空档**。两头的人还站着，所以还要加 1。

换个画面：4 个人排一排，他们中间只有 3 段空。人比空档多 1。

## 画出来

```
数：    7     8     9     10
        ●-----●-----●-----●
段：       1     2     3
```

所以：

    两头都算：个数 = 尾 − 头 + 1
    只算一头：个数 = 尾 − 头
    围成一圈：个数 = 段数（头和尾是同一个）

## 三种种法

{% tabs %}
{% tab title="两端都种" %}
小路 20 米，每隔 5 米一棵，**两端都种**。

```
●----●----●----●----●
  5    5    5    5
```

段数 = 20 ÷ 5 = 4，棵数 = 4 + 1 = **5**。

握手那道题也是这一招：从「最后握的 7」数到「男生人数」，两头都算。
{% endtab %}

{% tab title="只种一端" %}
同样 20 米、每隔 5 米，只在开头种、结尾不种。

段数还是 4，棵数就是 4，**不再加 1**。

锯木头也是：锯 3 段，只要锯 2 刀。刀在缝上，不在头上。
{% endtab %}

{% tab title="种成圈" %}
圆形花坛一周 30 米，每隔 5 米一棵。

头和尾重合，加 1 会把同一棵数两遍。棵数 = 段数 = 30 ÷ 5 = **6**。
{% endtab %}
{% endtabs %}

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「从……到……，有几个」
- 「每隔几米种一棵」「两端都种 / 一端不种 / 围成圈」
- 握手、报到、排队，人数一档一档少下去
- 求的是**有几个数、几棵树、几个人**

## 换一身衣服

{% tabs %}
{% tab title="报数" %}
从 8 报到 15，一共报了几个数？

<details>
<summary>点开看想法</summary>

两头都算：15 − 8 + 1 = 8。

8、9、10、11、12、13、14、15，数一遍就是 8 个。

</details>
{% endtab %}

{% tab title="路灯" %}
一条街 40 米，两端都装灯，每隔 8 米一盏。要装几盏？

<details>
<summary>点开看想法</summary>

段数 = 40 ÷ 8 = 5，两端都装：5 + 1 = 6 盏。

</details>
{% endtab %}
