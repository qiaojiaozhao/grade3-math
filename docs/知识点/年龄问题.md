# 年龄问题

浅奥母题。妈妈和孩子、爸爸和儿子、老师和学生，只要在比**两个人的年龄**，骨头都是这一根：**两个人一起长大，差不变。**

{% hint style="info" %}
**第一单元 [画线段图](../单元/画线段图.md) · 第 5 课 / 共 5 课**　上一课：[移多补少](移多补少.md)　下一单元：[倒推与假设](../单元/倒推与假设.md)
{% endhint %}

## 一句话口诀

> **两个人一起长一岁，高出的那一截不变。**

{% hint style="success" %}
年龄差不变，倍数在变。先用不变的差，求出「那一年」，再倒回今年。
{% endhint %}

## 为什么不能只让一个人长

这是孩子最容易错的地方。题目问「妈妈 36 岁，小明 8 岁，几年后妈妈是小明的 3 倍」，很多孩子会这样算：

    36 ÷ 3 = 12，小明长到 12 岁就行，12 − 8 = 4 年。

错在**他只让小明长大，妈妈停住了**。4 年后小明 12 岁，妈妈也长了 4 岁，是 40 岁，不是 36。40 不是 12 的 3 倍。

换个画面：两个人站在台阶上，每过一年，两个人**一起**往上走一级。谁也不会多走、少走。所以两个人之间差的那几级台阶，永远一样多。

## 画出来

把两个人的年龄画成两根条子。在小的那根头顶画一条线，大的那根**高出线的那一截**就是年龄差：

```
            今年              6 年后
妈妈  ┃▓▓▓▓┃████████┃      ┃▓▓▓▓┃░░┃████████┃
小明  ┃▓▓▓▓┃               ┃▓▓▓▓┃░░┃
                └ 差 28 ┘             └ 差 28 ┘
                              ░ 是这 6 年各长的
```

两根条子每年各长一截，长得一样多。**橙色那截（差）只会跟着往上走，不会变长也不会变短。**

也可以画成一条时间轴，所有数字必须落在**同一年**才能比：

```
         3 年前     今年     6 年后
小明        5   ─►   8   ─►   14
妈妈       33   ─►  36   ─►   42
差         28       28        28    ← 不变
```

## 这道母题在考什么

年龄题没有自己的新公式。它真正考的是四件事，都会一直用到五六年级：

{% columns %}
{% column %}
### 1. 找不变的量

年龄在变、倍数在变，**差不变**。一道题里先找「什么不会变」，这是整个小学奥数最重要的习惯之一。
{% endcolumn %}

{% column %}
### 2. 对齐到同一年

「几年后是 3 倍」说的是那一年。今年的数和那一年的数**不能直接比**。先画时间轴，把数字对到同一年。
{% endcolumn %}
{% endcolumns %}

{% columns %}
{% column %}
### 3. 变成学过的母题

差不变 + 倍数 → [差倍](差倍问题.md)。今年的和 + 差 → [和差](和差问题.md)。那一年的和 + 倍数 → [和倍](和倍问题.md)。年龄题只是给它们换了衣服。
{% endcolumn %}

{% column %}
### 4. 和每年涨几岁

两个人的年龄**和**每过一年涨 **2** 岁，三个人涨 3 岁。差不变，和会变——别弄反。
{% endcolumn %}
{% endcolumns %}

{% hint style="info" %}
倍数为什么会变？今年妈妈 36、小明 8，妈妈是小明的 4 倍多；6 年后是 3 倍；再过很多年，两人都老了，倍数越来越接近 1。差不变，小的那个越来越大，倍数就越来越小。
{% endhint %}

## 三步走

以「妈妈 36 岁，小明 8 岁，几年后妈妈是小明的 3 倍」为例：

{% stepper %}
{% step %}
## 求出不变的差

    36 − 8 = 28（岁）

过多少年都是 28。
{% endstep %}

{% step %}
## 在「那一年」画份数，用差倍

那一年小明是 1 份，妈妈是 3 份，妈妈多出 `3 − 1 = 2` 份。这 2 份就是 28。

    1 份 = 28 ÷ (3 − 1) = 14（岁）

那一年小明 14 岁，妈妈 42 岁。
{% endstep %}

{% step %}
## 倒回今年，求几年

    14 − 8 = 6（年）

检查：6 年后妈妈 `36 + 6 = 42`，小明 `8 + 6 = 14`，`42 = 14 × 3` ✓。
{% endstep %}
{% endstepper %}

## 常见的四种问法

| 题目给了什么 | 先变成 | 例子 |
| --- | --- | --- |
| 今年两人的年龄，问几年后 / 几年前是几倍 | 差不变 + [差倍](差倍问题.md) | 妈妈 36、小明 8，几年后是 3 倍 |
| 今年的年龄和、年龄差 | [和差](和差问题.md) | 父子和 50，差 26 |
| 某一年是几倍，另一年的年龄和 | 先把和对到那一年，再 [和倍](和倍问题.md) | 今年和 40，2 年前是 3 倍 |
| 问几年后 / 几年前的年龄和 | 和每年涨「人数」岁 | 今年和 44，5 年后和是多少 |

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「今年几岁」「几年后」「几年前」「明年」「去年」
- 「是谁的几倍」「比谁大几岁」，而且**不在同一年**
- 求的是「几年后」「今年几岁」「那时几岁」

## 换一身衣服

{% tabs %}
{% tab title="几年前是几倍" %}
爸爸今年 43 岁。3 年前，爸爸的年龄是女儿的 4 倍。女儿今年几岁？

<details>
<summary>点开看想法</summary>

「4 倍」说的是 3 年前。先把爸爸对到 3 年前：

    43 − 3 = 40（岁）    3 年前的爸爸
    40 ÷ 4 = 10（岁）    3 年前的女儿
    10 + 3 = 13（岁）    今年的女儿

验算：3 年前爸爸 40、女儿 10，`40 = 10 × 4` ✓。

</details>
{% endtab %}

{% tab title="今年的和与差" %}
爸爸和儿子今年的年龄和是 50 岁，爸爸比儿子大 26 岁。两人今年各几岁？10 年后两人差几岁？

<details>
<summary>点开看想法</summary>

今年的和与差，就是 [和差](和差问题.md)：

    爸爸 = (50 + 26) ÷ 2 = 38（岁）
    儿子 = (50 − 26) ÷ 2 = 12（岁）

10 年后差还是 **26 岁**。差不变，不用再算。

验算：`38 + 12 = 50` ✓，`38 − 12 = 26` ✓。

</details>
{% endtab %}

{% tab title="年龄和涨几岁" %}
妈妈今年 35 岁，小红今年 9 岁。5 年后，两人的年龄和是多少？

<details>
<summary>点开看想法</summary>

今年的和是 `35 + 9 = 44`。每过一年，**两个人各长 1 岁**，和涨 2 岁：

    44 + 2 × 5 = 54（岁）

容易错成 `44 + 5 = 49`，那是只让一个人长了。

验算：5 年后妈妈 40、小红 14，`40 + 14 = 54` ✓。

</details>
{% endtab %}

{% tab title="和与倍不在同一年" %}
今年父子的年龄和是 40 岁。2 年前，爸爸的年龄是儿子的 3 倍。两人今年各几岁？

<details>
<summary>点开看想法</summary>

「3 倍」说的是 2 年前，所以和也要对到 2 年前。两个人各少 2 岁，和少 4 岁：

    40 − 2 × 2 = 36（岁）     2 年前的年龄和
    36 ÷ (3 + 1) = 9（岁）    2 年前的儿子
    9 + 2 = 11（岁）          今年的儿子
    40 − 11 = 29（岁）        今年的爸爸

验算：2 年前爸爸 27、儿子 9，`27 = 9 × 3` ✓。

</details>
{% endtab %}

{% tab title="⭐ 当我像你这么大" %}
学生问老师几岁。老师说：「我像你这么大的时候，你才 3 岁；你像我这么大的时候，我已经 42 岁了。」老师今年几岁？

<details>
<summary>点开看想法</summary>

拔高题，还是差不变。把四个年龄排在一条线上，相邻两个都差**一个年龄差**：

```
你 3 岁 ── 你今年 ── 我今年 ── 我 42 岁
      一个差    一个差    一个差
```

从 3 到 42 一共是 3 个年龄差：

    (42 − 3) ÷ 3 = 13（岁）   年龄差
    42 − 13 = 29（岁）        老师今年
    29 − 13 = 16（岁）        学生今年

验算：13 年前老师 16、学生 3 ✓；13 年后学生 29、老师 42 ✓。

</details>
{% endtab %}
{% endtabs %}
