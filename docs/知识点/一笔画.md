# 一笔画

浅奥母题。田、日、口、五角星，只要问**能不能笔不离纸、线不重复地画完**，骨头都是这一根。

## 一句话口诀

> **数单数条线的点。0 个或 2 个，才能一笔画。**

{% hint style="success" %}
0 个，从哪开始都能回到起点。2 个，必须从一个单数点出发，到另一个单数点结束。4 个及以上，一定画不完。
{% endhint %}

## 为什么画了半天还不知道行不行

这是孩子最容易错的地方。很多孩子对着「田」字从角上起笔，走到中间卡住，换个角再试，试完也不确定是自己走错了，还是根本不能画。

错在没有先数点。每条线有两头。一个点如果汇了 3 条、5 条这种单数条线，笔走进去就出不来，除非它是起点或终点。所以这种点只能有 0 个或 2 个。

「田」字四个角各汇 2 条，是双数。四条边的中点各汇 3 条，是单数。正中间汇 4 条。单数点有 4 个，不能一笔画。

## 画出来

```
角 ·————·————· 角      角：2 条，双
  |    |    |
  ·————·————·        边中点：3 条，单
  |    |    |        正中：4 条，双
角 ·————·————· 角
```

单数点 4 个。**不能**一笔画。

## 这道母题在考什么

- **先判断再下笔**：能不能画，由点决定，不由试的次数决定。
- **只数单数点**：双数点走进去还能走出来，不用管。
- **0 和 2 是两扇门**：没有单数点就能转一圈回来；有两个，就有固定的一头一尾。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「一笔画」「笔不离纸」
- 「每条线只走一次」
- 给了一个由线段搭成的图形
