# 周期

浅奥母题。彩灯、排队报数、星期几，只要有一段在**一遍遍重复**，骨头都是这一根。

## 一句话口诀

> **一组一组圈起来。多出来几个，从头数几个；一个不多，就是最后一个。**

{% hint style="success" %}
余数是 0，不是「没有位置」，也不是下一组的第一个。刚好用完一组，就停在这一组的最后一个。
{% endhint %}

## 为什么余数是 0 不是下一个

这是孩子最容易错的地方。彩灯按红、黄、蓝重复，问第 51 盏。很多孩子会这样算：

    51 ÷ 3 = 17 组，余 0。
    余 0 就是没有，从下一个开始，是红色。

错在**他多指了一盏**。17 组刚好把 51 盏用完，第 51 盏就是第 17 组的最后一盏，蓝色。再往后那盏红，是第 52 盏。

换个画面：3 个小朋友一组排队，51 个人正好 17 组，一个人都不剩。队伍的最后一个人，是第 17 组的最后一个，不是第 18 组的第一个——第 18 组还没人。

## 画出来

51 盏不用都画。先画一组，标上第几个；再画最后一组，把盏号填进去：

```
一组：  红     黄     蓝
       第 1 个 第 2 个 最后一个

第 17 组： 红      黄      蓝
          第 49   第 50   第 51  ← 问的是这盏
```

    51 ÷ 3 = 17（组）……0
    余 0 → 这一组的最后一个 → 蓝

余数不是 0 的时候，多出来的几盏还在**下一组的头上**。第 50 盏：`50 ÷ 3 = 16` 组余 2，就是第 17 组的第 2 个，黄。

## 三步走

以「红、黄、蓝重复，第 51 盏什么颜色」为例：

{% stepper %}
{% step %}
## 圈出一组，标上第几个

红是第 1 个，黄是第 2 个，蓝是最后一个。一组 3 盏。
{% endstep %}

{% step %}
## 除一下，看余数

    51 ÷ 3 = 17（组）……0

余 0：一盏都没多出来。
{% endstep %}

{% step %}
## 余 0 就指最后一个

第 17 组的最后一盏是蓝。第 51 盏是**蓝色**。

检查：17 × 3 = 51，第 51 盏刚好是第 17 个蓝。下一个红是第 52 盏。✓
{% endstep %}
{% endstepper %}

## 这道母题在考什么

- **几个一组地数。** 接着 [买赠](买赠问题.md) 的「先圈一组」。买赠问有几组，周期问落在这一组的第几个。
- **余数是多出来的个数。** 余 2 就从这一组的头上数 2 个，不是「余数 2 等于第 2 种颜色」这么背。先把一组标上 1、2、3，再对号。
- **刚好除尽，停在最后一个。** 余数 0 是「用完了」，不是「空的」，也不是从头再来。这是这道题唯一要单独练的地方。

## 什么时候想到它

题目里出现这些说法，基本就是它：

- 「按这个顺序重复」「红黄蓝红黄蓝」「循环」
- 「第几个是什么颜色」「报几」「星期几」
- 一组里的东西**顺序固定**，问很后面的某一个

{% tab title="报数" %}
小朋友按 1、2、3、1、2、3……报数。第 21 个同学报的是几？

<details>
<summary>点开看想法</summary>

一组是 1、2、3，3 个一组。

    21 ÷ 3 = 7（组）……0

余 0，是这一组的最后一个，报 **3**。不是报 1，也不是报 0。

验算：7 × 3 = 21，每组最后一个都报 3。✓

</details>
{% endtab %}

{% tab title="两个两个重复" %}
珠子按「红、红、蓝、蓝」重复串。第 40 颗是什么颜色？

<details>
<summary>点开看想法</summary>

先把一组标清楚：第 1 个红，第 2 个红，第 3 个蓝，第 4 个（最后一个）蓝。一组 4 颗。

    40 ÷ 4 = 10（组）……0

余 0，是最后一个，**蓝**。

验算：10 × 4 = 40，每组第 4 颗都是蓝。✓

</details>
{% endtab %}

{% tab title="过了多少天" %}
今天是星期三。再过 21 天是星期几？再过 23 天呢？

<details>
<summary>点开看想法</summary>

星期 7 天一组。21 天：

    21 ÷ 7 = 3（组）……0

余 0，刚好走完 3 个星期，还是**星期三**。不是「星期 0」。

23 天多出来 2 天，从星期三往后数 2 天：星期四、星期五。是**星期五**。

验算：21 是 7 的倍数，星期不变；23 − 21 = 2，三加 2 是五。✓

</details>
{% endtab %}
