# 浅奥母题地图

三年级奥数看起来题很多，骨架只有这些。**衣服可以换，骨头不能换。** 糖、油、鸡兔、书，都是同一根骨头套了不同的皮。

这些骨头排成**六个单元**。每个单元只学会一张图，每一课只比上一课多一个新想法。

{% hint style="info" %}
陪孩子用的顺序：按单元从上往下学 → 每一课先看动画 → 把口诀念出来 → 做例题 → 合上页面，换一道「换了衣服」的题讲给你听 → 一个单元学完，做单元末尾的「考考自己」。
{% endhint %}
