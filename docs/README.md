# 三年级奥数 · 看得懂的知识站

这里沉淀孩子学过的奥数知识点。每个知识点都配一句能记住的口诀和一张图；每道例题都尽量配一个**可以点着看的动画**，让孩子先看明白，再动笔算。

## 怎么陪孩子用

给孩子讲一道题时，建议按这个顺序：

1. 先读**例题**页的题面，让孩子自己想一分钟。
2. 点开页面里的**互动动画**，点「自动播放」，看一遍。
3. 回到**知识点**页，把这道题用到的口诀念一遍。
4. 合上页面，让孩子自己把算式写一遍，再用页面末尾的验算对答案。

关键是第 2 步：**孩子卡住，多半不是不会算，而是脑子里没有画面。**
