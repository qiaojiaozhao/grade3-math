# 浅奥母题地图

三年级奥数看起来题很多，骨架只有这几种。**衣服可以换，骨头不能换。** 糖、油、鸡兔、书，都是同一根骨头套了不同的皮。

{% hint style="info" %}
陪孩子用的顺序：打开这张地图 → 让他猜是哪道母题 → 点进去看口诀和画面 → 做例题 → 合上页面，让他自己换一道「换了衣服」的题讲给你听。
{% endhint %}
