# 第一单元系统课：一张图，五种问法

{% hint style="info" %}
**第一单元 [画线段图](画线段图.md) · 系统课**　五课学完再上这一节，把五课串成一根线。也可以放在单元开头当预习，先看全貌。大约 40 分钟。
{% endhint %}

## 这节课只带走一句话

> **先画两根条子，再问：多出来的那一截是什么？**

第一单元的五课，公式各不相同：`(和 − 差) ÷ 2`、`和 ÷ (倍 + 1)`、`差 ÷ (倍 − 1)`……孩子一课一课学，很容易背成五个互不相干的咒语，一换题就对不上号。

其实五课是**同一张图**。区别只在于题目告诉你什么、藏起来什么。这节课用同一对数把五道题摆在一起，孩子会自己发现：**五道题的答案都是 14。**

第一遍只看，不讲。看完问孩子一句：「为什么五道题答案都一样？」答不上来没关系，这节课就是来回答它的。

## 第一步：把字翻译成条子

线段图不是画得像，是**翻译得对**。题目里的每一种说法，都有固定的画法：

| 题目里说 | 画成什么 | 样子 |
| --- | --- | --- |
| 甲有多少、乙有多少 | 两根条子，**左边对齐**，小的在上 | `┃■■■┃` |
| 一共、合起来、两人相加 | 右边一个大括号，把两根都括进去 | `}` 一共 |
| 多、少、相差、比……大 | 在小的末尾画竖线，大的**超出线的那一截** | `┃■■■┃▓▓┃` |
| 是几倍 | 大的切成几段，**每段和小的一样长** | `┃■■■┃■■■┃■■■┃` |
| 给、拿、倒过去 | 一截从一根**搬到**另一根 | `▓ →` |
| 过了几年、各加一样多 | 两根**各接上一样长**的一截 | `┃■■■┃░░┃` |

画图有四条规矩，第一次画就要养成：

1. **左边对齐。** 不对齐就看不出多出来的那一截。
2. **一样多的画一样长。** 「3 倍」的三段必须等长，不然份数就数错了。
3. **先画小的。** 小的是 1 份，别的都拿它来量。
4. **问号标上去。** 要求的那段标「?」，算完回头看是不是它。

{% hint style="success" %}
练法：家长念一句话，孩子只画图、不算。「甲比乙多 5」「甲是乙的 4 倍」「甲给乙 3 个」……画对十句，比做十道题管用。
{% endhint %}

## 第二步：一对兄弟，五个问题

哥哥有 **42** 颗糖，弟弟有 **14** 颗。先画出来：

```
弟弟：┃■■■■■■┃
哥哥：┃■■■■■■┃▓▓▓▓▓▓▓▓▓▓▓▓┃
      └ 一样长 ┘└ 多出来的一截 28 ┘
```

出题人每次只告诉你其中几个数，藏起别的。下面每一问，**先指出多出来的那一截是什么，再算。**

{% stepper %}
{% step %}
## 第 1 问 · 和差：那一截是一段长度，先拿走

> 兄弟俩一共 56 颗，哥哥比弟弟多 28 颗。弟弟有几颗？

```
弟弟：┃■■■■■■┃               ┐
哥哥：┃■■■■■■┃▓▓▓▓▓▓▓▓▓▓▓▓┃ ┘ 一共 56
              └─ 先拿走 28 ─┘
```

不能直接 `56 ÷ 2`，因为两根不一样长。把多出来的 28 拿走，剩下两根一样长：

    (56 − 28) ÷ 2 = 14（颗）

→ 复习 [第 1 课 和差](../知识点/和差问题.md)
{% endstep %}

{% step %}
## 第 2 问 · 和倍：那一截是几份，连弟弟一起数

> 兄弟俩一共 56 颗，哥哥是弟弟的 3 倍。弟弟有几颗？

```
弟弟：┃ ① ┃                  ┐
哥哥：┃ ② ┃ ③ ┃ ④ ┃          ┘ 一共 56 = 4 份
```

「3 倍」就是哥哥切成 3 段、每段和弟弟一样长。一共 `3 + 1 = 4` 份：

    56 ÷ (3 + 1) = 14（颗）

→ 复习 [第 2 课 和倍](../知识点/和倍问题.md)
{% endstep %}

{% step %}
## 第 3 问 · 差倍：那一截是几份，只数多出来的

> 哥哥比弟弟多 28 颗，哥哥是弟弟的 3 倍。弟弟有几颗？

```
弟弟：┃   ┃
哥哥：┃   ┃ ① ┃ ② ┃
          └ 多 28 = 2 份 ┘
```

这回没有「一共」，只有多出来的那一截。竖线右边是 `3 − 1 = 2` 份：

    28 ÷ (3 − 1) = 14（颗）

→ 复习 [第 3 课 差倍](../知识点/差倍问题.md)
{% endstep %}

{% step %}
## 第 4 问 · 移多补少：那一截劈两半，送一半

> 哥哥 42 颗，弟弟 14 颗。哥哥给弟弟几颗，两人就一样多？

```
弟弟：┃■■■■■■┃▓▓▓▓▓▓┃ ← 送过来的
哥哥：┃■■■■■■┃▓▓▓▓▓▓┃ ← 留下的
```

多出来的 28 劈成两半，一半留给自己，一半送给弟弟。送的是**半截**：

    28 ÷ 2 = 14（颗）

→ 复习 [第 4 课 移多补少](../知识点/移多补少.md)
{% endstep %}

{% step %}
## 第 5 问 · 一起长：那一截不变

> 哥哥 42 颗，弟弟 14 颗。妈妈给两人各发同样多的糖，各发几颗后，哥哥正好是弟弟的 2 倍？

```
弟弟：┃■■■■■■┃░░░░░░┃
哥哥：┃■■■■■■┃░░░░░░┃▓▓▓▓▓▓▓▓▓▓▓▓┃
              └ 各发 ┘└ 还是 28 ─┘
```

两人各加一样多，多出来的那一截**一点不变**，还是 28。2 倍时，这一截正好是 1 个弟弟，所以弟弟要长到 28：

    28 ÷ (2 − 1) = 28（颗），28 − 14 = 14（颗）

换成年龄就是：爸爸 42 岁、儿子 14 岁，**14 年后**爸爸是儿子的 2 倍。

→ 复习 [第 5 课 年龄](../知识点/年龄问题.md)
{% endstep %}
{% endstepper %}

## 第三步：五道题摆在一起

| 第几问 | 题目告诉你 | 多出来的那一截是 | 怎么处理 | 算式 |
| --- | --- | --- | --- | --- |
| 1 和差 | 一共 + 多多少 | 一段长度 | **拿走**，剩下平分 | (56 − 28) ÷ 2 |
| 2 和倍 | 一共 + 几倍 | 几份 | 连小的一起**数份** | 56 ÷ (3 + 1) |
| 3 差倍 | 多多少 + 几倍 | 几份 | 只数**多出来的份** | 28 ÷ (3 − 1) |
| 4 移多补少 | 两人各多少，要一样多 | 一段长度 | **劈两半**，送一半 | 28 ÷ 2 |
| 5 年龄 | 两人一起长 | 不变的那一截 | 先求**那一年**，再倒回来 | 28 ÷ (2 − 1) − 14 |

答案都是 14，因为五道题问的是同一件事：**弟弟那根条子有多长。**

### 一个 +1，一个 −1，到底为什么

和倍、差倍最容易搞混，看图就不会：

{% columns %}
{% column %}
### 和倍 +1

「一共」包括弟弟，所以**弟弟那 1 份也要数上**。

哥哥 3 份 + 弟弟 1 份 = 4 份。
{% endcolumn %}

{% column %}
### 差倍 −1

「多出来的」不包括和弟弟一样长的那段，所以**要去掉 1 份**。

哥哥 3 份 − 和弟弟一样的 1 份 = 2 份。
{% endcolumn %}
{% endcolumns %}

### 什么变，什么不变

第 4 问和第 5 问是一对，正好反过来。这是整个小学奥数最重要的习惯之一：**先找不变的量。**

| | 一共 | 多出来的那一截 |
| --- | --- | --- |
| 移多补少：你给我、我给你 | **不变**（糖没多也没少） | 变，送出 1 截，差距缩小 2 截 |
| 年龄：两人一起长 | 变，每过一年和涨 2 | **不变** |

## 第四步：五个坑，一课一个

| 课 | 孩子会这么想 | 错在哪 | 看图就明白 |
| --- | --- | --- | --- |
| 和差 | 一共 56，每人 28 | 两人不一样多 | 先拿走多出来的一截 |
| 和倍 | 56 ÷ 3 | 忘了数弟弟那 1 份 | 一共是 3 + 1 份 |
| 差倍 | 28 ÷ 3 | 多出来的不是 3 份 | 竖线右边只有 3 − 1 份 |
| 移多补少 | 多 28，就给 28 | 只算了一边 | 给 28 的话哥哥反而少了，只给半截 |
| 年龄 | 只让弟弟长 | 两人一起在长 | 那一截跟着走，不变 |

{% hint style="warning" %}
还有一个文字坑：「哥哥比弟弟**多 2 倍**」是「哥哥是弟弟的 **3 倍**」。多出来的是 2 份，哥哥一共 3 份。
{% endhint %}

### 第二关：画出来，再算

就是第一关的六道题。**先画图，指出多出来的那一截是什么**，再列式。

{% tabs %}
{% tab title="1" %}
篮球和足球一共 48 个，篮球是足球的 5 倍。各多少个？

<details>
<summary>点开看答案</summary>

一共 `5 + 1 = 6` 份。足球 `48 ÷ 6 = 8`（个），篮球 `8 × 5 = 40`（个）。

验：`40 + 8 = 48` ✓，`40 = 8 × 5` ✓
</details>
{% endtab %}

{% tab title="2" %}
桃树比梨树多 36 棵，桃树是梨树的 4 倍。各多少棵？

<details>
<summary>点开看答案</summary>

多出来的是 `4 − 1 = 3` 份。梨树 `36 ÷ 3 = 12`（棵），桃树 `12 × 4 = 48`（棵）。

验：`48 − 12 = 36` ✓
</details>
{% endtab %}

{% tab title="3" %}
两根绳子一共长 30 米，一根比另一根长 4 米。各长多少米？

<details>
<summary>点开看答案</summary>

拿走多出来的 4 米：短的 `(30 − 4) ÷ 2 = 13`（米），长的 `13 + 4 = 17`（米）。

验：`17 + 13 = 30` ✓，`17 − 13 = 4` ✓
</details>
{% endtab %}

{% tab title="4" %}
小红比小明多 18 张画片。小红给小明几张，两人就一样多？

<details>
<summary>点开看答案</summary>

多出来的那一截劈两半，送一半：`18 ÷ 2 = 9`（张）。

验：小红少 9、小明多 9，差距缩小 18，正好一样多 ✓
</details>
{% endtab %}

{% tab title="5" %}
奶奶今年 65 岁，孙子今年 9 岁。几年前，奶奶的年龄是孙子的 9 倍？

<details>
<summary>点开看答案</summary>

差 `65 − 9 = 56` 不变。那一年奶奶比孙子多 `9 − 1 = 8` 份：

    56 ÷ 8 = 7（岁）   那一年的孙子
    9 − 7 = 2（年）

**2 年前**。验：2 年前奶奶 63、孙子 7，`63 = 7 × 9` ✓
</details>
{% endtab %}

{% tab title="6 ⚠️" %}
甲乙一共 60 本书，乙比甲多 2 倍。各多少本？

<details>
<summary>点开看答案</summary>

乙是甲的 3 倍，一共 `3 + 1 = 4` 份。甲 `60 ÷ 4 = 15`（本），乙 `15 × 3 = 45`（本）。

验：`45 − 15 = 30`，正好是甲的 2 倍 ✓
</details>
{% endtab %}
{% endtabs %}

### 第三关：两课合起来

一道题里藏着两课。先想「什么不变」，画一张图。

{% tabs %}
{% tab title="倒过去 + 和倍" %}
甲仓有 50 吨粮，乙仓有 30 吨。从甲仓运几吨到乙仓，乙仓就是甲仓的 3 倍？

<details>
<summary>点开看想法</summary>

运来运去，**一共不变**，还是 `50 + 30 = 80` 吨。运完以后是和倍：

    80 ÷ (3 + 1) = 20（吨）   运完后的甲仓
    50 − 20 = 30（吨）        要运走的

验：甲 20、乙 `30 + 30 = 60`，`60 = 20 × 3` ✓
</details>
{% endtab %}

{% tab title="倒过去 + 和差" %}
两筐苹果一共 60 千克。从甲筐拿 8 千克放进乙筐，两筐就一样重。原来各多少千克？

<details>
<summary>点开看想法</summary>

「拿 8 就一样」，说明原来差 `8 × 2 = 16`（移多补少反过来用）。再用和差：

    甲 = (60 + 16) ÷ 2 = 38（千克）
    乙 = 60 − 38 = 22（千克）

验：`38 − 8 = 30`，`22 + 8 = 30` ✓
</details>
{% endtab %}

{% tab title="年龄 + 和倍" %}
爸爸和儿子今年的年龄和是 44 岁。4 年后，爸爸的年龄是儿子的 3 倍。两人今年各几岁？

<details>
<summary>点开看想法</summary>

「3 倍」说的是 4 年后，和也要对到 4 年后。两人各长 4 岁，和涨 8 岁：

    44 + 4 × 2 = 52（岁）    4 年后的和
    52 ÷ (3 + 1) = 13（岁）  4 年后的儿子
    13 − 4 = 9（岁）         今年的儿子
    44 − 9 = 35（岁）        今年的爸爸

验：4 年后爸爸 39、儿子 13，`39 = 13 × 3` ✓
</details>
{% endtab %}

{% tab title="⭐ 三个人" %}
甲、乙、丙一共 90 本书。甲比乙多 5 本，乙比丙多 5 本。三人各多少本？

<details>
<summary>点开看想法</summary>

画三根条子，拿乙当标准：

```
丙：┃■■■■■■┃       ← 比乙少一截 5
乙：┃■■■■■■■┃
甲：┃■■■■■■■┃▓┃   ← 比乙多一截 5
```

甲多的那一截正好补给丙（移多补少），三人就都和乙一样多：

    乙 = 90 ÷ 3 = 30（本）
    甲 = 30 + 5 = 35（本），丙 = 30 − 5 = 25（本）

验：`35 + 30 + 25 = 90` ✓
</details>
{% endtab %}
{% endtabs %}

## 这节课在考什么

- **翻译能力。** 把「一共」「多」「几倍」「给」「过几年」一句句翻成图。五课的公式都是从图里读出来的，图画对了，公式可以忘。
- **找 1 份。** 五道题最后都在找小的那根有多长。先找标准量，再求别的，这是以后分数、比例的底子。
- **找不变的量。** 倒过去和不变，一起长差不变。先问「什么没变」，两课合起来的题就拆开了。
