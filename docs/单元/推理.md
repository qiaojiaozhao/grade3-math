# 推理

**第六单元。** 两个本事：**一样多的东西可以互相换**，**条件一多就画一张表**。

课内对应三年级上册综合实践「曹冲称象的故事」：称不了大象，就换成一样重的石头——这就是等量代换。

## 这一单元的两张图

一样多的可以换，也可以一起划掉：

```
△ + △ + ○ = 16
△ + ○     = 10
划掉一样的 △ + ○，剩下 △ = 6
```

条件一多就画表：确定的打 ✓，不可能的打 ✗。

```
        红   黄   蓝
小红    ✗    ✗    ✓
小兰    ✗    ✓    ✗
小芳    ✓    ✗    ✗
```

△ + △ = 12，△ + ○ = 10。△ 和 ○ 各是几？

<details>
<summary>点开看答案</summary>

**图形推理**：两个 △ 是 12，一个 △ 是 6；再换进第二个算式，○ = 10 − 6 = 4。

</details>

{% tab title="2" %}
小红、小兰、小芳分别穿红、黄、蓝三种颜色的衣服。小红不穿红的也不穿黄的，小兰不穿红的。三人各穿什么颜色？

<details>
<summary>点开看答案</summary>

**逻辑推理**：画表。小红只剩蓝；小兰不穿红、蓝又被拿走，只剩黄；小芳是红。

小红蓝、小兰黄、小芳红。

</details>
{% endtab %}

{% tab title="3" %}
1 到 9 这 9 张数字卡片，能不能分成两堆，让两堆的和一样大？

<details>
<summary>点开看答案</summary>

**奇偶**：1 + 2 + … + 9 = 45，是单数。两堆一样大，总和必须是双数。所以**不能**。
