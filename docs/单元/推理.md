# 推理

**第六单元。** 两个本事：**一样多的东西可以互相换**，**条件一多就画一张表**。

课内对应三年级上册综合实践「曹冲称象的故事」：称不了大象，就换成一样重的石头——这就是等量代换。

## 这一单元的两张图

一样多的可以换，也可以一起划掉：

```
△ + △ + ○ = 16
△ + ○     = 10
划掉一样的 △ + ○，剩下 △ = 6
```

条件一多就画表：确定的打 ✓，不可能的打 ✗。

```
        红   黄   蓝
小红    ✗    ✗    ✓
小兰    ✗    ✓    ✗
小芳    ✓    ✗    ✗
```

## 学完考考自己

{% tab title="1" %}
△ + △ = 12，△ + ○ = 10。△ 和 ○ 各是几？

<details>
<summary>点开看答案</summary>

**图形推理**：两个 △ 是 12，一个 △ 是 6；再换进第二个算式，○ = 10 − 6 = 4。

</details>
{% endtab %}

{% tab title="2" %}
小明、小刚、小亮各拿一本：语文、数学、英语。小明不拿语文，小刚不拿语文、也不拿数学。三人各拿哪本？

<details>
<summary>点开看答案</summary>

**逻辑推理**：小刚只剩英语；小明不拿语文，英语又被叉掉，只剩数学；小亮是语文。

小刚英语、小明数学、小亮语文。

</details>
{% endtab %}

{% tab title="3" %}
1 到 9 这 9 张数字卡片，能不能分成两堆，让两堆的和一样大？

<details>
<summary>点开看答案</summary>

**奇偶**：1 + 2 + … + 9 = 45，是单数。两堆一样大，总和必须是双数。所以**不能**。

</details>
