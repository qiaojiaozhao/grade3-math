# 画线段图

**第一单元，一共 5 课。** 三年级应用题有一半在这里。这一单元只教一件本事：**把数量画成两根条子，比高矮。**

## 这一单元的那张图

```
小的：┃■■■■■■■■┃
大的：┃■■■■■■■■┃■■■■┃
      └─ 一样长 ─┘└ 多出来的一截 ┘
```

每一课都在问同一个问题：**多出来的那一截是什么？**

- 是一段长度 → 去掉它，剩下两份一样长（和差）
- 是几份 → 数清楚一共几份、多几份（和倍、差倍）
- 倒来倒去 → 看那一截怎么变（移多补少）
- 过了几年 → 那一截根本不变（年龄）

## 按这个顺序学

每一课只比上一课多一个新想法：

| 第几课 | 母题 | 口诀 | 比上一课多了什么 | 例题 |
| --- | --- | --- | --- | --- |
| 1 | [和差](../知识点/和差问题.md) | （和 ± 差）÷ 2 | 第一次画两根条子：先切掉多出来的一截 | [兄弟分糖](../题目/兄弟分糖.md) · [大衣裤子和鞋](../题目/大衣裤子和鞋.md) |
| 2 | [和倍](../知识点/和倍问题.md) | 和 ÷（倍 + 1）= 1 份 | 多出来的不再是一截长度，而是**几份** | [甲乙两堆书](../题目/甲乙两堆书.md) |
| 3 | [差倍](../知识点/差倍问题.md) | 差 ÷（倍 − 1）= 1 份 | 给的是差，要数**多出来的**是几份 | [倒油问题](../题目/倒油问题.md) |
| 4 | [移多补少](../知识点/移多补少.md) | 倒过去 1 份，差距缩小 2 份 | 条子会动：一边少、一边多 | [倒油问题](../题目/倒油问题.md) |
| 5 | [年龄](../知识点/年龄问题.md) | 两个人一起长一岁，高出的那一截不变 | 条子一起长：找那个**不变**的差 | [妈妈和小明](../题目/妈妈和小明.md) |

## 五课怎么分清

题目里总有两个条件。**看第二个条件是什么**，就知道是哪一课：

| 第一个条件 | 第二个条件 | 是哪一课 |
| --- | --- | --- |
| 一共多少 | 相差多少 | 和差 |
| 一共多少 | 是几倍 | 和倍 |
| 相差多少 | 是几倍 | 差倍 |
| 拿多少给另一边 | 就一样多 | 移多补少 |
| 今年几岁 | 几年后 / 几年前 | 年龄 |

{% hint style="warning" %}
「多 2 倍」是「是 3 倍」。看见「倍」，先别往和差上靠。
{% endhint %}

## 学完考考自己

五道题，数字差不多，骨头各不相同。先说出是哪一课，再算。

{% tabs %}
{% tab title="1" %}
两筐苹果一共 56 千克，甲筐比乙筐多 8 千克。两筐各多少千克？

<details>
<summary>点开看答案</summary>

**和差**：一共 + 相差。

甲 = (56 + 8) ÷ 2 = 32（千克），乙 = 56 − 32 = 24（千克）。验：32 − 24 = 8 ✓

</details>
{% endtab %}

{% tab title="2" %}
两筐苹果一共 56 千克，甲筐是乙筐的 3 倍。两筐各多少千克？

<details>
<summary>点开看答案</summary>

**和倍**：一共 + 是几倍。一共 3 + 1 = 4 份。

乙 = 56 ÷ 4 = 14（千克），甲 = 14 × 3 = 42（千克）。验：42 + 14 = 56 ✓

</details>
{% endtab %}

{% tab title="3" %}
甲筐比乙筐多 28 千克，甲筐是乙筐的 3 倍。两筐各多少千克？

<details>
<summary>点开看答案</summary>

**差倍**：相差 + 是几倍。多出来的是 3 − 1 = 2 份。

乙 = 28 ÷ 2 = 14（千克），甲 = 14 × 3 = 42（千克）。验：42 − 14 = 28 ✓

</details>
{% endtab %}

{% tab title="4" %}
甲筐 40 千克，乙筐 16 千克。从甲筐拿多少千克给乙筐，两筐就一样多？

<details>
<summary>点开看答案</summary>

**移多补少**：差 40 − 16 = 24，倒过去 1 份差距缩小 2 份。

要拿 24 ÷ 2 = 12（千克）。验：40 − 12 = 28，16 + 12 = 28 ✓

</details>
{% endtab %}

{% tab title="5" %}
爸爸今年 40 岁，儿子今年 12 岁。几年后，爸爸的年龄是儿子的 3 倍？

<details>
<summary>点开看答案</summary>

**年龄**：差 40 − 12 = 28 不变，那一年差是 3 − 1 = 2 份。

那年儿子 28 ÷ 2 = 14 岁，14 − 12 = **2 年后**。验：2 年后爸爸 42 = 14 × 3 ✓

</details>
{% endtab %}
{% endtabs %}
