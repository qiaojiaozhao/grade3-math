# 数清楚

**第三单元。** 这一单元不考算，考**有没有漏、有没有多数一遍**。两个本事：**画一条线数点和段**，**几个一组数有几组**。

## 这一单元的两张图

点和段：两头都种，点比段多 1。

```
●────●────●────●────●
  1    2    3    4        4 段，5 个点
```

几个一组：先圈出一组，再数有几组。

```
[●●●●●○] [●●●●●○] [●●●●●○] ……
  5 买 1 送，6 人一组
```

## 学完考考自己

{% tab title="1" %}
一条 40 米长的路，一边每隔 5 米种一棵树，两头都种。一共种几棵？

<details>
<summary>点开看答案</summary>

**植树**：先数段，40 ÷ 5 = 8 段；两头都种，棵数比段数多 1。

8 + 1 = 9（棵）。

</details>
{% endtab %}

{% tab title="2" %}
饮料「买三送一」。20 个人每人一瓶，最少买几瓶？

<details>
<summary>点开看答案</summary>

**买赠**：3 + 1 = 4 人一组，20 ÷ 4 = 5 组，每组买 3 瓶。

5 × 3 = 15（瓶）。验：买 15，每 3 瓶送 1，送 5 瓶，15 + 5 = 20 ✓

</details>
{% endtab %}

{% tab title="3" %}
一列火车长 100 米，每秒走 20 米，穿过一条 300 米的隧道，从车头进到车尾出要几秒？

<details>
<summary>点开看答案</summary>

**过火车**：走过的路是车身加隧道。

(100 + 300) ÷ 20 = 20（秒）。

</details>
{% endtab %}

{% tab title="4" %}
彩灯按红、黄、蓝重复。第 51 盏是什么颜色？

<details>
<summary>点开看答案</summary>

**周期**：3 盏一组。51 ÷ 3 = 17 组，余数是 0。

余 0 不是下一个红，是这一组的最后一个：**蓝**。

</details>
{% endtab %}

{% tab title="5" %}
全班 40 人，每人至少参加一项。跳绳 26 人，踢毽 22 人。两项都参加的有几人？

<details>
<summary>点开看答案</summary>

**重叠**：26 + 22 = 48，比全班多 48 − 40 = 8。

两项都参加的是 **8** 人。验：只跳绳 18，只踢毽 14，都参加 8，18 + 14 + 8 = 40。✓

</details>
{% endtab %}

{% tab title="6" %}
用 2、5、7、8 组成两位数，每个数字只用一次。能组成几个？

<details>
<summary>点开看答案</summary>

**枚举**：每个十位下面还剩 3 个个位。4 × 3 = **12** 个。

</details>
{% endtab %}
