# 数清楚

**第三单元。** 这一单元不考算，考**有没有漏、有没有多数一遍**。两个本事：**画一条线数点和段**，**几个一组数有几组**。

## 这一单元的两张图

点和段：两头都种，点比段多 1。

```
●────●────●────●────●
  1    2    3    4        4 段，5 个点
```

几个一组：先圈出一组，再数有几组。

```
[●●●●●○] [●●●●●○] [●●●●●○] ……
  5 买 1 送，6 人一组
```

## 还在写的课

这一单元接下来会补上这几课，都是秋季常考：

| --- | --- | --- |
| 周期 | 除一下看余数，余数落在第几个 | 余数是 0 时，以为落在第 0 个，其实是最后一个 |

一条 40 米长的路，一边每隔 5 米种一棵树，两头都种。一共种几棵？

<details>
<summary>点开看答案</summary>

**植树**：先数段，40 ÷ 5 = 8 段；两头都种，棵数比段数多 1。

8 + 1 = 9（棵）。

</details>
{% endtab %}

{% tab title="2" %}
饮料「买三送一」。20 个人每人一瓶，最少买几瓶？

<details>
<summary>点开看答案</summary>

**买赠**：3 + 1 = 4 人一组，20 ÷ 4 = 5 组，每组买 3 瓶。

5 × 3 = 15（瓶）。验：买 15，每 3 瓶送 1，送 5 瓶，15 + 5 = 20 ✓

</details>
{% endtab %}

{% tab title="3" %}
一列火车长 100 米，每秒走 20 米，穿过一条 300 米的隧道，从车头进到车尾出要几秒？

<details>
<summary>点开看答案</summary>

**过火车**：走过的路是车身加隧道。

(100 + 300) ÷ 20 = 20（秒）。

</details>
{% endtab %}
