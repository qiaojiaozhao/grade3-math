# 巧算

**第四单元。** 浅奥一半的分数在计算里。这一单元只教一个习惯：**先看数，再动笔。**

课内对应三年级上册「混合运算」和「多位数乘一位数」两个单元。

## 这一单元的那张图

在算式里找「好朋友」：两个数凑在一起刚好是整十、整百、整千。

```
347 + 158 + 253
 └──── 凑成 600 ────┘
= 600 + 158 = 758
```

三年级要记住的好朋友：

| 加法 | 乘法 |
| --- | --- |
| 个位凑 10：3 和 7、4 和 6 | 2 × 5 = 10 |
| 凑整百：347 和 253 | 25 × 4 = 100 |
| 连减：减去两个数，就是减去它们的和 | 125 × 8 = 1000 |

25 × 9 × 4 = ？

<details>
<summary>点开看答案</summary>

**巧算**：25 找 4。25 × 4 = 100，100 × 9 = **900**。

验：25 × 9 × 4 = 900。✓

{% tab title="3" %}
900 − 175 − 225 = ？

<details>
<summary>点开看答案</summary>

**巧算**：连减先加两个减数。75 + 25 = 100，175 + 225 = 400。900 − 400 = **500**。

验：900 − 175 = 725，725 − 225 = 500。✓

</details>
{% endtab %}

{% tab title="4" %}
在 □ 里填 +、− 或 ×，不添括号：2 □ 6 □ 3 = 15。

<details>
<summary>点开看答案</summary>

**巧填算符**：2 + 6 + 3 = 11，15 更大，要有乘法。2 × 6 + 3 = **15**。

</details>
{% endtab %}

{% tab title="5" %}
竖式：3□ + □5 = 62。两个 □ 各是几？

<details>
<summary>点开看答案</summary>

**数字谜**：个位 □ + 5 的个位是 2，所以是 12，□ = 7，进 1。十位 3 + □ + 1 = 6，□ = 2。

**37 + 25 = 62**。

</details>
