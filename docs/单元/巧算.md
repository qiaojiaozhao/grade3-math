# 巧算

**第四单元。** 浅奥一半的分数在计算里。这一单元只教一个习惯：**先看数，再动笔。**

课内对应三年级上册「混合运算」和「多位数乘一位数」两个单元。

## 这一单元的那张图

在算式里找「好朋友」：两个数凑在一起刚好是整十、整百、整千。

```
347 + 158 + 253
 └──── 凑成 600 ────┘
= 600 + 158 = 758
```

三年级要记住的好朋友：

| 加法 | 乘法 |
| --- | --- |
| 个位凑 10：3 和 7、4 和 6 | 2 × 5 = 10 |
| 凑整百：347 和 253 | 25 × 4 = 100 |
| 连减：减去两个数，就是减去它们的和 | 125 × 8 = 1000 |

定义新运算先不单独开课，挂在巧算的「换一身衣服」里：★ 被规定成一种新算法，照着规矩算，别用平常的加减乘除。
