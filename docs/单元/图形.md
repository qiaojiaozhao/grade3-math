# 图形

**第五单元。** 两个本事：**数图形要按顺序数**，**求周长把凹进去的边推出去**。

课内对应三年级上册「线和角」单元。

## 这一单元的两张图

数线段：从第一个点出发，往右连完，再换下一个点。

```
A────B────C────D
从 A 出发：AB、AC、AD   3 条
从 B 出发：BC、BD       2 条
从 C 出发：CD           1 条
一共 3 + 2 + 1 = 6 条
```

巧求周长：台阶形的边推出去，正好拼成一个长方形。

```
┌──┐              ┌────────┐
│  └──┐           │        │
│     └──┐   →    │        │
└────────┘        └────────┘
周长 = 推成的长方形的周长
```

## 学完考考自己

{% tabs %}
{% tab title="1" %}
一条线上有 6 个点，一共有几条线段？

<details>
<summary>点开看答案</summary>

**数线段**：从第 1 个点 5 条，然后 4、3、2、1。

5 + 4 + 3 + 2 + 1 = **15** 条。只数挨着的是 5 条。

</details>
{% endtab %}

{% tab title="2" %}
从一个点出发画 4 条射线，一共组成几个角？

<details>
<summary>点开看答案</summary>

**数角**：和数线段一样，从第一条射线 3 个角，然后 2、1。

3 + 2 + 1 = **6** 个。

</details>
{% endtab %}

{% tab title="3" %}
一个台阶形的图形，最外面刚好能框进一个长 8 厘米、宽 5 厘米的长方形，每一级台阶都是横平竖直的。它的周长是多少？

<details>
<summary>点开看答案</summary>

横着的边往上推、竖着的边往右推，正好拼成那个长方形。

(8 + 5) × 2 = **26** 厘米。

</details>
{% endtab %}
