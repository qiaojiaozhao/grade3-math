# 有序数：一个顺序全数清

{% hint style="info" %}
**专题 · 数线段、数角、数三角形、数长方形、握手、枚举**　写给家长和孩子一起看。先学完 [数线段、数角](../知识点/数线段数角.md) 再来更顺。大约 40 分钟。
{% endhint %}

## 这一篇只带走一句话

> **从第一个出发，能连的都数上；数完换下一个，数过的不再数。**

这一类题不考算，考**有没有漏、有没有多数一遍**。孩子算错，几乎都是这两种：

- **漏了**：只数挨着的，隔着点的长线段、跨过去的大角全丢了。
- **多数了一遍**：你和我握手算一次，他按 5 × 4 算成了两次。

所以每道题只问两句话：**我在数什么？分不分先后？**

第一遍只看，不讲。看完问孩子：「5 个人握手，为什么不是 5 × 4 = 20 次？」

## 底层思维：为什么是 4 + 3 + 2 + 1

5 个人握手，孩子有两种错法，刚好一多一少。

**错法一：算成 4 次。**他想「第 1 个和第 2 个、第 2 个和第 3 个……」——只让挨着的人握手。可是第 1 个和第 3 个、第 4 个、第 5 个照样要握。

**错法二：算成 20 次。**每人要和另外 4 个人握，5 × 4 = 20。可是你和我握的那一次，在「你的 4 次」里数过，在「我的 4 次」里又数了一遍，**每次握手都被数了两遍**。

正确的数法是**定一个顺序，只往一边数**：

```
          1    2    3    4    5

从第 1 个：1—2  1—3  1—4  1—5      4 次
从第 2 个：     2—3  2—4  2—5      3 次
从第 3 个：          3—4  3—5      2 次
从第 4 个：               4—5      1 次
从第 5 个：                        0 次，右边没人了

一共 4 + 3 + 2 + 1 = 10 次
```

**越往后越少**，因为前面握过的不再握。这就是「数过的不再数」。

{% hint style="success" %}
**动手验一遍。**叫上家里 4 个人（含孩子一共 5 个），真握一遍，每握一次记一道。记满 10 道就停不下来了——因为真的没有第 11 次。
{% endhint %}

## 第一类 · 都是 4 + 3 + 2 + 1

这四道题长得完全不一样，算出来是同一个数。看懂这一点，这一类题就通了。

### 例 1　5 个人握手

> 联欢会上有 5 个人，每两个人握一次手。一共握了多少次手？

{% stepper %}
{% step %}
## 从第 1 个人开始

他和右边 4 个人各握一次，4 次。
{% endstep %}

{% step %}
## 换下一个，只往右数

第 2 个人和第 1 个握过了，不再握，只和右边 3 个人握，3 次。

第 3 个人 2 次，第 4 个人 1 次，第 5 个人右边没人了。
{% endstep %}

{% step %}
## 加起来

    4 + 3 + 2 + 1 = 10（次）
{% endstep %}
{% endstepper %}

**答案：10 次。**

### 例 2　一条线上 5 个点

> 一条直线上有 5 个点，一共可以数出多少条线段？

把 5 个人换成 5 个点，握手换成连线段，**题还是那道题**。

{% stepper %}
{% step %}
## 先看孩子漏了什么

只数挨着的：1—2、2—3、3—4、4—5，4 条。

隔着一个点的 1—3、隔着两个点的 1—4、整条的 1—5，照样都是线段。
{% endstep %}

{% step %}
## 按长短数一遍，不会漏

```
挨着的（隔 0 个点）：1—2  2—3  3—4  4—5    4 条
隔 1 个点：          1—3  2—4  3—5         3 条
隔 2 个点：          1—4  2—5               2 条
隔 3 个点：          1—5                    1 条
```
{% endstep %}

{% step %}
## 加起来

    4 + 3 + 2 + 1 = 10（条）
{% endstep %}
{% endstepper %}

**答案：10 条。**

### 例 3　一个点射出 5 条射线

> 从一个点射出 5 条射线，一共可以数出多少个角？

把 5 条射线**当成 5 个点**。两条射线夹一个角，就是两个点连一条线段。

{% stepper %}
{% step %}
## 从最边上那条数起

它和右边每一条都夹一个角，4 个。
{% endstep %}

{% step %}
## 换下一条

第 2 条往右 3 个，第 3 条 2 个，第 4 条 1 个。

    4 + 3 + 2 + 1 = 10（个）
{% endstep %}
{% endstepper %}

**答案：10 个角。**

{% hint style="warning" %}
**卡点：只数相邻两条夹的角。**那样只有 4 个，跨过去的大角全漏了。两个小角拼成的大角，也是一个角。
{% endhint %}

### 例 4　数三角形

> 三角形的底边上有 5 个点，顶点和这 5 个点都连起来。图中一共有多少个三角形？

这道题看着是图形题，其实还是例 2。

{% stepper %}
{% step %}
## 看清一个三角形由什么组成

每个三角形都是：**顶点 + 底边上的两个点**。

顶点是固定的，变的只有底边那两个点。
{% endstep %}

{% step %}
## 那就是数底边的线段

底边上选两个点 = 底边有几条线段。

    4 + 3 + 2 + 1 = 10（个）
{% endstep %}
{% endstepper %}

**答案：10 个三角形。**

{% hint style="success" %}
**这是这一类题最值钱的一句：数三角形就是数底边的线段。**顶点不动，只要底边选两个点。孩子一旦看懂，这类题从「数图形」变成「数线段」，难度掉一半。
{% endhint %}

## 第二类 · 要相乘：数长方形

### 例 5　数长方形

> 一个长方形被分成 2 行 4 列，一共 8 个小格。图中一共有多少个长方形？

{% stepper %}
{% step %}
## 先只看一行

一行里的长方形，只要在**上边那条线**上挑两个点，左右两条边就定了。

一行 4 格，上边有 5 个点：

    4 + 3 + 2 + 1 = 10（种）

一行 4 格，就是在数线段。
{% endstep %}

{% step %}
## 再看竖着能挑几种

2 行有 3 条横线，挑两条定上下边：

    2 + 1 = 3（种）
{% endstep %}

{% step %}
## 横的每一种配竖的每一种

横着 10 种，每一种都能配竖着的 3 种：

    10 × 3 = 30（个）
{% endstep %}
{% endstepper %}

**答案：30 个长方形。**

{% hint style="warning" %}
**卡点：把 10 和 3 加起来。**长方形要同时定左右边和上下边，是「先挑横的，再挑竖的」两件事都做，所以是乘，不是加。
{% endhint %}

## 第三类 · 不能相乘：数正方形

这是这一类题唯一的例外，也是边界。

### 例 6　数正方形

> 一个大正方形被分成 3 行 3 列，一共 9 个小方格。图中一共有多少个正方形？

{% stepper %}
{% step %}
## 先想清楚为什么不能相乘

长方形能相乘，是因为横着挑完，竖着还能自由挑。

正方形四条边**一样长**。横着挑了 2 格宽，竖着就只能是 2 格高，**被定死了**，没得挑。
{% endstep %}

{% step %}
## 按边长一层一层数

```
边长 1 格：横 3 个位置 × 竖 3 个位置 = 9 个
边长 2 格：横 2 个位置 × 竖 2 个位置 = 4 个
边长 3 格：横 1 个位置 × 竖 1 个位置 = 1 个
```
{% endstep %}

{% step %}
## 加起来

    9 + 4 + 1 = 14（个）
{% endstep %}
{% endstepper %}

**答案：14 个正方形。**

{% hint style="warning" %}
**卡点：只数了 9 个小方格。**大的里面套着小的——2 格宽的、整块的，都要单独数。这和「只数挨着的线段」是同一个毛病。
{% endhint %}

## 第四类 · 分先后要翻倍：枚举

### 例 7　组两位数

> 用 1、2、3、4、5 这五个数字组成两位数，每个两位数里数字不重复。一共能组成多少个？

{% stepper %}
{% step %}
## 先问一句：分不分先后

握手的时候，你和我握、我和你握，**是同一次**。

可是 12 和 21，**是两个不同的数**。这一类要分先后。
{% endstep %}

{% step %}
## 先定十位，再定个位

十位有 5 种挑法。十位定下来以后，个位只能从剩下的 4 个里挑：

    5 × 4 = 20（个）
{% endstep %}

{% step %}
## 换个角度验一遍

两两搭配有 10 对，每对分先后能排 2 个：

    10 × 2 = 20（个）✓
{% endstep %}
{% endstepper %}

**答案：20 个。**

## 六道题摆在一起

| 题 | 我在数什么 | 怎么数 | 一共 |
| --- | --- | --- | --- |
| 5 个人握手 | 人是点，握手是连线 | 4+3+2+1 | **10 次** |
| 5 个点 | 点是点，线段是连线 | 4+3+2+1 | **10 条** |
| 5 条射线 | 射线是点，角是夹出来的 | 4+3+2+1 | **10 个** |
| 底边 5 个点 | 就是数底边的线段 | 4+3+2+1 | **10 个** |
| 2 行 4 列 | 横挑一次，竖挑一次 | 10 × 3 | **30 个** |
| 5 张卡组两位数 | 分先后 | 10 × 2 | **20 个** |

前四道是同一道题换了四身衣服。后两道多了一步：长方形要相乘，枚举要翻倍。

## 怎么认出是哪一类

| 题目里说 | 是哪一类 | 先做什么 |
| --- | --- | --- |
| 握手、互寄、比赛对阵 | 4+3+2+1 | 不分先后，只往一边数 |
| 一条线上几个点，数线段 | 4+3+2+1 | 按长短数，长的也算 |
| 一个点几条射线，数角 | 4+3+2+1 | 射线当成点 |
| 顶点连底边，数三角形 | 4+3+2+1 | 改成数底边的线段 |
| 几行几列，数长方形 | 相乘 | 横挑一次 × 竖挑一次 |
| 几行几列，数正方形 | 按边长 | 一层一层数再相加 |
| 组数、排顺序、谁先谁后 | 翻倍 | 先定高位，再定低位 |

## 这一课在考什么

- **定一个顺序。** 不漏不重靠的不是细心，是**有没有定下「从哪头开始、往哪边数」**。这是后面学排列、学概率的起点。
- **大的里面套着小的。** 最短的线段、最小的方格只是其中一层。隔着点的长线段、套在外面的大正方形，都要单独数。
- **分不分先后。** 握手不分先后，组数分先后。同一堆东西，这一句问清楚了，答案才不会差一倍。
