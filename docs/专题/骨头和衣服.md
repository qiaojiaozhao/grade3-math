# 骨头搞清楚，衣服随便换

{% hint style="info" %}
**专题 · 和差、差倍、和倍**　写给家长和孩子一起看。先学完第一单元的 [和差](../知识点/和差问题.md)、[和倍](../知识点/和倍问题.md)、[差倍](../知识点/差倍问题.md) 再来，大约 40 分钟。
{% endhint %}

## 这一篇只带走一句话

> **先找一样大的那一块，再数题目给的数里有几块。**

孩子做这类题，最怕「换了一身衣服」。昨天讲的是哥哥弟弟分糖，今天变成买衣服、插花、爸爸和儿子，他就认不出来了，又开始从头猜。

衣服是故事：钱、花、年龄、书、糖……骨头是故事底下那个不变的关系。和差、差倍、和倍这三类题，骨头其实是同一根：

```
题目给的那个数  =  一块有多大  ×  有几块
```

三样东西，题目总会告诉你两样，剩下那样就能求出来。难的从来不是除法，是**先找到那「一样大的一块」**。块找对了，数一数有几块，算式自己就出来了。

## 第一道 · 和差：大衣裤子和鞋

> 李明用 420 元买了一件大衣、一条裤子和一双鞋。大衣比裤子贵 80 元，大衣和裤子一共比鞋贵 220 元。每件东西多少钱？

**一样大的那一块：一双鞋的钱。**

{% stepper %}
{% step %}
## 先捆成一包

三样东西一起想会乱。先把大衣和裤子**捆成一包**，题目就只剩两样：一包和鞋。

```
一包：┃■■■■■┃▓▓▓▓▓▓▓▓▓▓▓┃
鞋：  ┃■■■■■┃
            └ 多出来的 220 ┘
```
{% endstep %}

{% step %}
## 拿掉多出来的那一截

一包比鞋贵 220，这 220 是**一包长出来的那一截**，不是鞋的钱。从总价里把它拿掉：

    420 − 220 = 200（元）

剩下两段一样长，**200 元正好是两双鞋**：

    鞋 = 200 ÷ 2 = 100（元）
    一包 = 100 + 220 = 320（元）
{% endstep %}

{% step %}
## 解开一包，再来一次

一包里是大衣和裤子，一共 320，大衣贵 80。还是那一招，拿掉多的，剩下两块一样大：

    裤子 = (320 − 80) ÷ 2 = 120（元）
    大衣 = 120 + 80 = 200（元）
{% endstep %}
{% endstepper %}

**答案：大衣 200 元，裤子 120 元，鞋 100 元。** 验：`200 + 120 + 100 = 420` ✓，`200 − 120 = 80` ✓，`320 − 100 = 220` ✓

{% hint style="warning" %}
**卡点：把 220 当成鞋的价钱。** 孩子看见「比鞋贵 220」，脑子里就冒出「鞋 220」。让他指着图说：220 是哪一截？是一包**多出来的**那一截。拿掉它，剩下的才是两双鞋。
{% endhint %}

## 第二道 · 差倍的骨头：插花

> 将月季花插入一些花瓶中。如果每瓶插 6 朵，那么缺少 14 朵；如果每瓶改插 4 朵，那么缺少 2 朵。花瓶有多少个，月季花有多少朵？

**一样大的那一块：每个花瓶两次差的 2 朵。**

这道题课本里叫盈亏，骨头和差倍是同一根：**把差出来的那一截，切成一样大的小块。**

{% stepper %}
{% step %}
## 画两根条子

整根条子是要插的花，手里的月季是一条黄线，两次一样多：

```
每瓶 6 朵：┃■■■■■■■■■■■┃░░░░░░░░┃   超出黄线 14（缺）
每瓶 4 朵：┃■■■■■■■■■■■┃░┃           超出黄线 2（缺）
                        ↑ 手里的月季
```
{% endstep %}

{% step %}
## 看上面那根长出来多少

两根条子都从同一条黄线往外超。上面超 14，下面超 2，上面比下面**长出 `14 − 2 = 12` 朵**。

这 12 朵是哪来的？每个花瓶从 4 朵改成 6 朵，**每瓶多要 2 朵**，所有花瓶的这 2 朵摞起来，就是长出来的那一截。
{% endstep %}

{% step %}
## 切成一块一块的 2 朵

    12 ÷ (6 − 4) = 6（个）    花瓶
    6 × 6 − 14 = 22（朵）     月季

验：`6 × 4 − 2 = 22` ✓
{% endstep %}
{% endstepper %}

**答案：6 个花瓶，22 朵月季。**

### 它为什么和差倍是同一根骨头

{% columns %}
{% column %}
### 差倍

哥哥是弟弟的 3 倍，哥哥比弟弟多 28 颗。

一块 = 弟弟。哥哥比弟弟多 `3 − 1 = 2` 块。

    28 ÷ 2 = 14（颗）
{% endcolumn %}

{% column %}
### 插花

每瓶 6 朵缺 14，每瓶 4 朵缺 2。

一块 = 每瓶差的 `6 − 4 = 2` 朵。差出来 12 朵。

    12 ÷ 2 = 6（个）
{% endcolumn %}
{% endcolumns %}

两道题都只看**差出来的那一截**，都是同一个式子 `差出来的 = 一块 × 块数`，只是倒过来用：差倍知道差出来几块，求一块多大；插花知道一块多大，求差出来几块。

{% hint style="warning" %}
**卡点：两次都缺，还用加法。** 学过「一多一少要相加」的孩子，会算成 `(14 + 2) ÷ 2 = 8`。但这道题一朵都没多。看条子：两根都从黄线往外超，长出来的是 `14 − 2`。**两次都缺（或者两次都多）用减，一多一少才用加。**
{% endhint %}

## 第三道 · 和倍：父子年龄（难）

> 父子两人今年的年龄和是 52 岁。8 年前，爸爸的年龄是儿子的 5 倍。父子两人今年各几岁？

**一样大的那一块：8 年前的儿子。**

这道题难在两件衣服叠在一起穿：外面是年龄，里面是和倍。和是**今年**的，倍数是 **8 年前**的，两个数不在同一年，不能直接用。

{% stepper %}
{% step %}
## 先把「和」对齐到 8 年前

倒回 8 年，**爸爸少 8 岁，儿子也少 8 岁**，两个人一共少了 2 个 8：

```
今年：  爸爸 ┃■■■■■■■■■■■■■■■┃▒▒▒▒┃
        儿子 ┃■■■■┃▒▒▒▒┃
                       └ 各倒回 8 ┘
```

    52 − 8 × 2 = 36（岁）    8 年前的年龄和
{% endstep %}

{% step %}
## 8 年前是几块

8 年前爸爸是儿子的 5 倍：儿子 1 块，爸爸 5 块，一共 `5 + 1 = 6` 块。

```
8 年前：爸爸 ┃ ② ┃ ③ ┃ ④ ┃ ⑤ ┃ ⑥ ┃
        儿子 ┃ ① ┃                    一共 36 = 6 块
```

    36 ÷ (5 + 1) = 6（岁）    8 年前的儿子
{% endstep %}

{% step %}
## 再一起长回今年

    儿子今年 = 6 + 8 = 14（岁）
    爸爸今年 = 52 − 14 = 38（岁）

验：8 年前爸爸 30 岁、儿子 6 岁，`30 = 6 × 5` ✓；今年 `38 + 14 = 52` ✓
{% endstep %}
{% endstepper %}

**答案：爸爸 38 岁，儿子 14 岁。**

{% hint style="warning" %}
**卡点：只减一个 8。** 孩子会写 `52 − 8 = 44`，忘了两个人都在长。这里有个好用的自查信号：`44 ÷ 6` **除不尽**。年龄题、和倍题算到除不尽，八成是哪一步对错了年份或者漏了一个人。
{% endhint %}

## 三道题摆在一起

| 题 | 衣服 | 一样大的那一块 | 题目给的数 | 有几块 | 算式 |
| --- | --- | --- | --- | --- | --- |
| 和差 | 买衣服 | 一双鞋的钱 | 拿掉 220 后的 200 | 2 块 | 200 ÷ 2 = 100 |
| 差倍的骨头 | 插花 | 每瓶差的 2 朵 | 差出来的 12 | 求出来是 6 块 | 12 ÷ 2 = 6 |
| 和倍 | 父子年龄 | 8 年前的儿子 | 对齐后的和 36 | 6 块 | 36 ÷ 6 = 6 |

三道题的算式都是「一个数 ÷ 另一个数」，一点都不难。真正的功夫都在除号**之前**：

- 和差要先**拿掉**多出来的一截，剩下的才一样大；
- 插花要先**减出**差出来的一截，才能切块；
- 年龄要先**对齐**到同一年，块才数得对。

## 怎么认出骨头：把衣服脱下来

题目换了衣服，先把这些说法「翻译」回骨头：

| 题目里说 | 脱掉衣服是 | 先做什么 |
| --- | --- | --- |
| 「一共」「合起来」「和是」 | 所有块加起来 | 数清一共几块 |
| 「比……贵 / 多 / 大」 | 多出来的一截 | 和差：先拿掉它 |
| 「是……的几倍」 | 大的切成几块，每块和小的一样长 | 小的算 1 块 |
| 「比……多几倍」 | 「多 2 倍」= 是 3 倍 | 先改成「是几倍」 |
| 「每…几个，多 / 缺几个」两次 | 两根条子比长短 | 看差出来的那一截 |
| 「几年前」「几年后」 | 和、倍不在同一年 | 先对齐到同一年 |
| 三样东西 | 太多了 | 先捆两样成一包 |

{% hint style="success" %}
练法：家长随便编一道题，孩子不算，只回答两个问题：**一样大的那一块是什么？题目给的数里有几块？** 两个都答对，这道题就做完了一大半。
{% endhint %}

## 孩子容易错在哪

| 题 | 孩子会这么想 | 错在哪 | 看图就明白 |
| --- | --- | --- | --- |
| 和差 | 比鞋贵 220，鞋就是 220 | 220 是多出来的一截 | 拿掉它，剩下两双鞋 |
| 和差 | 一包 320 就停了 | 一包里还有两样东西 | 解开再做一次和差 |
| 插花 | 两次都缺，`14 + 2` | 只有一多一少才加 | 两根都从黄线往外超 |
| 和倍 | 「5 倍」就 ÷ 5 | 忘了儿子自己那 1 块 | 一共 5 + 1 块 |
| 年龄 | `52 − 8` | 两个人都倒回 8 年 | 减 2 个 8，除不尽就是错了 |

## 换一身衣服，自己试

每组两道，骨头和上面一样，衣服换了。先说「一样大的那一块」是什么，再算。

### 和差

{% tabs %}
{% tab title="书包文具盒水壶" %}
书包、文具盒和水壶一共 150 元。书包比文具盒贵 30 元，书包和文具盒一共比水壶贵 90 元。各多少钱？

<details>
<summary>点开看答案</summary>

一块 = 水壶的钱。拿掉多出来的 90：`150 − 90 = 60`，是两个水壶，水壶 `60 ÷ 2 = 30`（元），一包 `30 + 90 = 120`（元）。

解开一包：文具盒 `(120 − 30) ÷ 2 = 45`（元），书包 `45 + 30 = 75`（元）。

验：`75 + 45 + 30 = 150` ✓，`120 − 30 = 90` ✓
</details>
{% endtab %}

{% tab title="两根绳子" %}
两根绳子一共长 46 米，一根比另一根长 8 米。各长多少米？

<details>
<summary>点开看答案</summary>

一块 = 短的那根。拿掉长出来的 8 米：短的 `(46 − 8) ÷ 2 = 19`（米），长的 `19 + 8 = 27`（米）。

验：`19 + 27 = 46` ✓
</details>
{% endtab %}
{% endtabs %}

### 差倍的骨头

{% tabs %}
{% tab title="发练习本" %}
老师发练习本，每人 5 本缺 8 本；每人 4 本缺 4 本。有几个同学，几本练习本？

<details>
<summary>点开看答案</summary>

一块 = 每人两次差的 `5 − 4 = 1` 本。两次都缺，差出来 `8 − 4 = 4` 本：

    4 ÷ 1 = 4（人）
    4 × 5 − 8 = 12（本）

验：`4 × 4 − 4 = 12` ✓
</details>
{% endtab %}

{% tab title="邮票" %}
爷爷的邮票比小明多 45 张，爷爷的邮票是小明的 4 倍。各有多少张？

<details>
<summary>点开看答案</summary>

一块 = 小明的邮票。爷爷比小明多 `4 − 1 = 3` 块：

    45 ÷ 3 = 15（张）   小明
    15 × 4 = 60（张）   爷爷

验：`60 − 15 = 45` ✓
</details>
{% endtab %}
{% endtabs %}

### 和倍

{% tabs %}
{% tab title="母女年龄" %}
妈妈和女儿今年的年龄和是 50 岁。5 年后，妈妈的年龄是女儿的 4 倍。两人今年各几岁？

<details>
<summary>点开看答案</summary>

先对齐到 5 年后：两人各长 5 岁，和是 `50 + 5 × 2 = 60`（岁）。一块 = 5 年后的女儿，一共 `4 + 1 = 5` 块：

    60 ÷ 5 = 12（岁）   5 年后的女儿
    12 − 5 = 7（岁）    今年的女儿
    50 − 7 = 43（岁）   今年的妈妈

验：5 年后妈妈 48、女儿 12，`48 = 12 × 4` ✓
</details>
{% endtab %}

{% tab title="两筐苹果 ⭐" %}
两筐苹果一共 90 千克。从甲筐拿 15 千克放进乙筐，乙筐就是甲筐的 2 倍。两筐原来各多少千克？

<details>
<summary>点开看答案</summary>

拿来拿去，**一共不变**，还是 90。拿完以后，一块 = 那时的甲筐，一共 `2 + 1 = 3` 块：

    90 ÷ 3 = 30（千克）   拿完后的甲筐
    30 + 15 = 45（千克）  原来的甲筐
    90 − 45 = 45（千克）  原来的乙筐

验：甲 `45 − 15 = 30`，乙 `45 + 15 = 60`，`60 = 30 × 2` ✓
</details>
{% endtab %}
{% endtabs %}
