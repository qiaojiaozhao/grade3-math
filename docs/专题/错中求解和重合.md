# 错中求解和重合：多算的那一截

{% hint style="info" %}
**专题 · 错中求解、重合问题**　写给家长和孩子一起看。重合这一半，先学完 [重叠](../知识点/重叠问题.md) 再来更顺；错中求解不用预习。大约 40 分钟。
{% endhint %}

## 这一篇只带走一句话

> **先找出算多了（或算少了）的那一截：多了减掉，少了补上。**

这两类题看着不挨边。错中求解是「小马粗心把数看错了」，重合是「两根电线叠在一起」「有人两样都参加」。可是孩子在这两类题里犯的错是一样的：**不知道哪一截被多算了、哪一截被少算了**。

- 看错数：错的那个数比真的多几（或少几），结果就跟着差几。
- 叠在一起：两段加起来，叠住的那截被算了两遍，多算了一次。

所以两类题都只问一件事：**哪一截算错了？往哪边错的？**找到了，补回去就是答案，不用从头重算。

## 底层思维：加法是接，减法是剪

孩子算错中求解，最常见的是**凭感觉补**：看大了就减，看小了就加。加数、被减数这样补是对的，一碰到减数就补反了。

不靠感觉，靠画面：

```
加法：两段接成一根          ┃■■■■■ 加数 ■■■■■┃▒▒▒ 另一个加数 ▒▒▒┃ = 和
减法：一根条子剪掉一段      ┃■■■■ 剩下的 ■■■■┃░░░ 剪掉的 ░░░┃     = 被减数
```

- **加数**是接上去的一段。看长了，整根就长了。
- **被减数**是整根条子。看长了，剪掉的没变，多出来的全留在剩下的那段里——结果也长了。
- **减数**是剪掉的那段。看长了，就是**多剪了**，剩下的反而短了。

| 看错的是 | 它在画面里是 | 看大了，结果 | 看小了，结果 |
| --- | --- | --- | --- |
| 加数 | 接上去的一段 | 跟着大 | 跟着小 |
| 被减数 | 整根条子 | 跟着大 | 跟着小 |
| 减数 | 剪掉的那段 | **反而小** | **反而大** |

找出差了几，再看往哪边差，补回去，三步做完。

## 第一类 · 错中求解

### 例 1　看错加数

> 小桐在计算一道加法题时，将其中一个加数 272 看成了 227，算出的结果是 545。这道题的正确结果是多少？

{% stepper %}
{% step %}
## 差了几

    272 − 227 = 45

他把加数**看小了 45**。
{% endstep %}

{% step %}
## 往哪边差

加数是接上去的一段，画短了 45，整根就短了 45。算出的 545 **比正确结果小 45**。

```
看错的：┃■■ 227 ■■┃▒▒ 另一个加数 ▒▒┃            = 545
真的：  ┃■■ 227 ■■┃45┃▒▒ 另一个加数 ▒▒┃        = ?
```
{% endstep %}

{% step %}
## 补回去

    545 + 45 = 590
{% endstep %}
{% endstepper %}

**答案：590。** 验：另一个加数是 `545 − 227 = 318`，`272 + 318 = 590` ✓

### 例 2　看错被减数

> 菱玥在计算 716 − △ − 228 时，把 716 看成了 761，得到的结果是 379。这道题的正确结果是多少？

{% stepper %}
{% step %}
## 差了几

    761 − 716 = 45

被减数**看大了 45**。
{% endstep %}

{% step %}
## 往哪边差

被减数是整根条子。剪掉的 △ 和 228 没变，条子却多看了 45，多的这 45 全留在剩下的那段里。结果**也大了 45**。

```
看错的：┃■■■ 379 ■■■┃░ 剪 △ ░┃░ 剪 228 ░┃    = 761
真的：  ┃■■ ? ■■┃░ 剪 △ ░┃░ 剪 228 ░┃         = 716
```
{% endstep %}

{% step %}
## 补回去

    379 − 45 = 334
{% endstep %}
{% endstepper %}

**答案：334。** 验：△ 是 `761 − 228 − 379 = 154`，`716 − 154 − 228 = 334` ✓

这道题也能**先求 △ 再重算**，书上的提示就是这个方法。两种都对；先找差了几，算得更少，也不用管 △ 是多少。

### 例 3　看错减数（难）

> 小马由于粗心，把减数个位上的 5 看成了 0，把减数十位上的 1 看成了 4，得到的结果是 222。你知道正确的结果是多少吗？

这道题有两个坑叠在一起：十位上的数字要看成几十，减数补的方向是反的。

{% stepper %}
{% step %}
## 差了几：十位上的 1 是 10

```
         十位   个位
真的：    1      5      → 10 和 5
看成：    4      0      → 40 和 0
```

- 十位：10 看成 40，**多看了 30**（不是 3）；
- 个位：5 看成 0，**少看了 5**。

多 30、少 5，抵掉 5，减数一共**多看了 25**：

    30 − 5 = 25
{% endstep %}

{% step %}
## 往哪边差：减数看大，结果反而小

减数是剪掉的那段。看大了 25，就是**多剪了 25**，剩下的反而短了 25。

```
看错的：┃■■ 222 ■■┃░░░ 剪掉看错的减数 ░░░┃
真的：  ┃■■ 222 ■■┃25┃░░ 剪掉真的减数 ░░┃
```
{% endstep %}

{% step %}
## 补回去

    222 + 25 = 247
{% endstep %}
{% endstepper %}

**答案：247。** 验：随便编一个合适的被减数试试。比如真的减数是 15、被减数是 262：`262 − 15 = 247`；看错成 40：`262 − 40 = 222` ✓

{% hint style="warning" %}
**卡点：减数看大了，就把结果减小。** 孩子凭感觉——「看大了，就减回来」——算成 `222 − 25 = 197`。加数、被减数这样补是对的，减数正好反过来。让他指着条子说：减数是哪一段？是**剪掉的**那段。剪多了，剩下的是多了还是少了？
{% endhint %}

{% hint style="warning" %}
**卡点：十位的 1 看成 4，当成差 3。** 数字在十位上，1 就是 10，4 就是 40。差的是 30。题目说「某一位上的数字看错了」，先把这一位换成**它真正代表的数**再相减。
{% endhint %}

## 第二类 · 重合问题

书上的提示是：**当两个数量有部分重合时，两个数量之和与总量的差就是重合部分。**换成画面：两段叠在一起，加起来的时候，**叠住的那截被算了两遍**。

### 例 4　两根电线

> 李叔叔从 B 处往 D 处架设了一根长 327 米的电线，王叔叔从 C 处往 A 处架设了一根长 431 米的电线，已知 B 处到 C 处的距离是 115 米，那么 A 处到 D 处的距离是多少米？

```
A ┃■■■■■■■■■■ A 到 C 431 ■■■■■■■■■■┃
            B ┃▒▒▒▒▒▒▒▒ B 到 D 327 ▒▒▒▒▒▒▒▒▒┃ D
              └─ BC 115 ─┘
              两根电线都盖着这一段
```

{% stepper %}
{% step %}
## 先加起来

    431 + 327 = 758（米）

这 758 米里，B 到 C 这一段，A 到 C 那根算了一次，B 到 D 那根又算了一次——**算了两遍**。
{% endstep %}

{% step %}
## 多算的那一截减掉

    758 − 115 = 643（米）
{% endstep %}
{% endstepper %}

**答案：A 到 D 是 643 米。** 验：A 到 B 是 `431 − 115 = 316`，C 到 D 是 `327 − 115 = 212`，`316 + 115 + 212 = 643` ✓

### 例 5　跳高和跳远

> 运动会上，参加跳高和跳远的运动员一共有 32 人，既参加跳高又参加跳远的有 8 人，只参加跳高的有 11 人，只参加跳远的有多少人？

{% stepper %}
{% step %}
## 先排成一排

32 人里每个人**只数一次**。按参加了什么，把 32 人排成三段：

```
┃■■ 只跳高 11 ■■┃▓▓ 都参加 8 ▓▓┃▒▒ 只跳远 ? ▒▒┃
└──────────────── 一共 32 人 ────────────────┘
  └──── 参加跳高 ────┘
                  └──── 参加跳远 ────┘
```
{% endstep %}

{% step %}
## 剩下的就是只跳远

    32 − 11 − 8 = 13（人）
{% endstep %}
{% endstepper %}

**答案：只参加跳远的有 13 人。** 验：参加跳高的是 `11 + 8 = 19`，参加跳远的是 `8 + 13 = 21`，`19 + 21 − 8 = 32` ✓

{% hint style="warning" %}
**卡点：看清问的是「只」。** 这道题孩子会犯两种错。一是算出 `32 − 11 = 21` 就停了，可 21 是**参加跳远的**，里面还有 8 个两样都参加的。二是把 8 减了两次，`32 − 11 − 8 − 8 = 5`，可 32 里那 8 人只数过一次。画成一排三段，「只跳高」「都参加」「只跳远」各占一段，就不会多减也不会少减。
{% endhint %}

## 五道题摆在一起

| 题 | 哪一截算错了 | 往哪边错 | 补回去 |
| --- | --- | --- | --- |
| 看错加数 | 加数短了 45 | 结果小了 45 | 545 + 45 = **590** |
| 看错被减数 | 条子长了 45 | 结果大了 45 | 379 − 45 = **334** |
| 看错减数 | 多剪了 25 | 结果小了 25 | 222 + 25 = **247** |
| 两根电线 | BC 算了两遍 | 多算了 115 | 758 − 115 = **643 米** |
| 跳高跳远 | 32 人每人只算一次 | 不多不少 | 32 − 11 − 8 = **13 人** |

前三道是「看错了一截」，后两道是「叠住了一截」。做法都一样：**先别从头算，先找那一截**。

## 怎么认出是哪一类

| 题目里说 | 是哪一类 | 先做什么 |
| --- | --- | --- |
| 「看成了」「抄错了」「粗心」 | 错中求解 | 算出差了几，再看是加数、被减数还是减数 |
| 「个位上的……十位上的……」看错 | 错中求解 | 先把这一位换成真正代表的数（十位的 1 是 10） |
| 两段路、两根线、两张纸「有一段重合」 | 重合 | 两段加起来，减掉重合的那段 |
| 「既……又……」「两样都」 | 重合 | 画成一排三段，「只」的单独一段 |
| 「只参加」「只喜欢」 | 重合 | 从总数里减掉其他段 |

## 孩子容易错在哪

| 题 | 孩子会这么想 | 错在哪 | 看图就明白 |
| --- | --- | --- | --- |
| 看错减数 | 减数看大了，`222 − 25` | 减数看大是多剪了，剩下的反而少 | 剪掉的那段变长，剩下的就变短 |
| 看错减数 | 十位 1 看成 4，差 3 | 十位上的 1 是 10 | 写成 10 和 40 再比 |
| 看错减数 | 只管十位，忘了个位 | 个位也看错了，少了 5 | 多 30 少 5，一共多 25 |
| 看错加数 | 把 545 当成另一个加数 | 545 是和 | 两段接成一根，545 是整根 |
| 电线 | `431 + 327 = 758` 就停了 | BC 算了两遍 | 两根电线都盖着 BC |
| 跳高跳远 | `32 − 11 = 21` | 21 里还有都参加的 8 人 | 一排三段，只跳远是最后一段 |

减数看小了 `63 − 36 = 27`，是**少剪了** 27，剩下的反而多了 27：

{% tab title="两位都看错 ⭐" %}
小刚把被减数个位上的 3 看成 8，十位上的 6 看成 0，得到 245。正确结果是多少？

<details>
<summary>点开看答案</summary>

被减数：十位 60 看成 0，少看了 60；个位 3 看成 8，多看了 5。一共少看了 `60 − 5 = 55`。

被减数是整根条子，看小了 55，结果也小了 55：

    245 + 55 = 300

验：比如真的被减数是 363，减数就是 `308 − 245 = 63`，`363 − 63 = 300` ✓

## 这一课在考什么

- **不从头重算。** 看错数的题，找到「差了几」就能直接补，不用先求出那个不知道的数。这是一种「只看变化」的眼光，后面学方程、学平均数都要用。
- **一位数字代表多少。** 十位上的 1 是 10，百位上的 1 是 100。数位一搞错，差了几就全错。
- **重复算了的要扣掉。** 两段叠在一起、有人两样都参加，加起来都会多算一次。这是三年级「集合」的起点。
