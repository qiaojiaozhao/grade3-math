# 新课模板

加一道新题时，复制下面的内容到 `题目/<题目名>.md`，把方括号里的字换掉。写完别忘了在 [SUMMARY.md](../SUMMARY.md) 的「例题」下面加一行。

写的时候记住一件事：**先让孩子看见，再让他算。** 每一步都问一句「为什么」，而不是直接给算式。

---

```markdown
# [题目名]

## 题目

> [照抄题面，把关键数字加粗]

## 先看动画

[打开互动动画](../demos/[动画文件名].html)

[一句话说明这个动画要让孩子看见什么。]

## 用到的知识点

- [知识点 A](../知识点/[知识点A].md)：[这道题里怎么用到它]
- [知识点 B](../知识点/[知识点B].md)：[这道题里怎么用到它]

## 一步步想

### 第一步：[这一步在求什么]

[讲清楚为什么能这样想，别直接甩算式。]

    [算式] = [结果]

### 第二步：[这一步在求什么]

[同上。]

    [算式] = [结果]

## 答案

**[答案]**

## 验算

把答案代回题目，两个条件都要对得上：

1. [条件一]：[算式] ✓
2. [条件二]：[算式] ✓

## 孩子容易错在哪

- [常见错误一，以及为什么会这么想]
- [常见错误二]
```

---

## 如果要配动画

动画是一个独立的 HTML 文件，放进 `demos/`，双击就能打开。可以照着 [倒油问题的动画](../demos/倒油问题-移多补少与差倍.html) 改，它的结构是：

- 一个 `scenes` 数组，每一项是一幕，写清楚这一幕**要让孩子看见什么**；
- 「自动播放」把所有幕连起来放，「重播这一段」让孩子把某一幕再看一遍；
- 数字先藏成 `?`，等孩子看懂图形关系了，最后一幕才揭晓。

新增动画后，记得在 [README.md](../README.md) 的动画列表和 [index.html](../index.html) 的卡片里各加一条。
